<Syntaxkarte id="sk-while-and" nr="1" titel="while mit and: begrenzte Versuche">

```python
versuche = 0
geraten = 0
while geraten != 5 and versuche < 3:
    geraten = int(input("Tipp: "))
    versuche = versuche + 1
print(versuche)
```

- Die Eingaben 1, 2, 3 ergeben `3`: Die Schleife endet nach 3 Versuchen. Die Eingabe 5 ergibt `1`: Der Tipp stimmt.
- `and`: Beide Bedingungen müssen stimmen, damit die Schleife weiterläuft. Sie endet, sobald eine nicht mehr stimmt.
- Beide Variablen der Bedingung, `geraten` und `versuche`, brauchen vor der Schleife einen Startwert.

</Syntaxkarte>

<Syntaxkarte id="sk-weiter" nr="2" titel="Text einlesen: Noch einmal?">

```python
weiter = "ja"
while weiter == "ja":
    print("Runde")
    weiter = input("Noch einmal? (ja/nein) ")
```

- Die Eingaben `ja`, `ja`, `nein` ergeben dreimal `Runde`.
- `input` liefert Text, `==` vergleicht Text mit Text. Der Text steht in Anführungszeichen.
- `weiter` braucht vor der Schleife einen Wert, der sie startet.

</Syntaxkarte>

<Syntaxkarte id="sk-mitte" nr="3" titel="Die Mitte">

```python
print(int((1 + 100) / 2))
print(int((51 + 100) / 2))
print(int((3 + 4) / 2))
```

- Ausgabe: `50`, `75`, `3`.
- `/` ergibt eine Kommazahl, `int` schneidet die Nachkommastellen ab (Termin 08).
- Das brauchst du für die Knobelaufgabe am Ende.

</Syntaxkarte>

<Syntaxkarte id="sk-ord" nr="4" titel="ord und chr (nur lesen)">

```python
print(ord("A"))
print(chr(66))
```

- Ausgabe: `65` und `B`.
- `ord` nennt die Nummer eines Zeichens, `chr` das Zeichen zu einer Nummer. Das sind genau die Nummern aus dem Baustein „Zeichen sind Zahlen“.
- Du liest es nur. Selbst schreiben musst du es nicht, und es kommt in keiner Aufgabe und nicht in der Klausur vor.

</Syntaxkarte>

<p class="l-task__intro">Das ist dein Spiel aus Stufe 3, nur mit festem `geheim` und festen Tipps. Die Funktion `hinweis` kennst du:</p>

```python data-run="no"
def hinweis(geraten, geheim):
    if geraten < geheim:
        return "Zu klein"
    elif geraten > geheim:
        return "Zu groß"
    else:
        return "Richtig!"
```

<p class="l-task__intro">Das Programm:</p>

```python data-run="no"
geheim = 64
geraten = 0
versuche = 0
while geraten != geheim:
    geraten = int(input("Dein Tipp (1 bis 100): "))
    versuche = versuche + 1
    print(hinweis(geraten, geheim))
print(f"Versuche: {versuche}")
```

<p class="l-task__intro">Es bekommt nacheinander die Tipps 80, 50, 70 und 64. Trag nach jeder Runde `geraten`, `versuche` und die Ausgabe dieser Runde ein. Die Schlusszeile gehört nicht dazu.</p>
