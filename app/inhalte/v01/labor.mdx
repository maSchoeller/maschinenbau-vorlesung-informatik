<Werkzeugkasten>

<Syntaxkarte id="sk-print" nr="1" titel="print: etwas ausgeben">

```python
print("Hallo")
print("Kilometer:", 148)
```

- Text steht in Anführungszeichen, Zahlen stehen ohne.
- Mehrere Dinge trennst du mit Komma. `print` setzt ein Leerzeichen dazwischen.
- Jedes `print` beginnt eine neue Zeile.

</Syntaxkarte>

<Syntaxkarte id="sk-var" nr="2" titel="Variable: einen Wert merken">

```python
strecke = 18.5
tage = 4
print(strecke, tage)
```

- Links der Name, rechts der Wert: `name = wert`.
- Kommazahlen schreibst du mit Punkt: `18.5`.
- Namen: Kleinbuchstaben, Ziffern, Unterstrich. Kein Leerzeichen, keine Umlaute.

</Syntaxkarte>

<Syntaxkarte id="sk-rechnen" nr="3" titel="Rechnen und das Ergebnis merken">

```python
strecke = 18.5
tage = 4
woche = strecke * 2 * tage
print("Kilometer pro Woche:", woche)
```

- Rechenzeichen: `+`, `-`, `*` (mal), `/` (geteilt). Punkt vor Strich gilt, Klammern gehen auch.
- Erst wird die rechte Seite ausgerechnet, dann kommt das Ergebnis in die Variable links.
- `/` liefert immer eine Kommazahl: `10 / 2` ergibt `5.0`.

</Syntaxkarte>

<Syntaxkarte id="sk-input" nr="4" titel="Zahl einlesen">

```python data-stdin="18.5\n4"
strecke = float(input("Einfache Strecke in km: "))
tage = int(input("Tage pro Woche: "))
print(strecke, tage)
```

- `input("Frage: ")` zeigt die Frage und wartet auf eine Eingabe.
- `float(…)` macht daraus eine Kommazahl, `int(…)` eine ganze Zahl. Ohne das ist die Eingabe Text, und mit Text kannst du nicht rechnen.
- Hier auf der Seite trägst du die Eingaben vorher ins Feld „Eingaben“ ein, eine Zeile je `input`.

</Syntaxkarte>

<Station id="a-fehler" titel="Fehler finden" teil="A" min="7" data-seen="manual">

<p class="l-task__intro">Programme, die du nicht selbst geschrieben hast, musst du prüfen können. Lies das Programm Zeile für Zeile und vergleiche es mit der Aufgabe.</p>

<Fehlersuche titel="Pizza teilen" fehler="3 4">

Eine Pizza kostet 24 Euro, drei Personen teilen sie. Das Programm soll ausrechnen, was jede Person zahlt. Erwartet wird 8.0. In zwei Zeilen steckt ein Fehler.

```text
preis = float(input("Preis der Pizza in Euro: "))
personen = int(input("Anzahl Personen: "))
anteil = preis * personen
print("Jeder zahlt:", Anteil)
```

#### Fehler 1: falsch gerechnet (Zeile 3)

Geteilt wird mit `/`, hier steht `*`. Das ist die gefährlichere Sorte Fehler: Das Programm läuft und liefert ein falsches Ergebnis, 72.0 statt 8.0. Du findest ihn nur, wenn du vorher im Kopf überschlägst, was herauskommen muss.

#### Fehler 2: Name falsch geschrieben (Zeile 4)

Angelegt wurde `anteil` mit kleinem a, ausgegeben werden soll `Anteil` mit großem A. Diesen Fehler meldet Python selbst: `NameError: name 'Anteil' is not defined`.

So ist es richtig:

```python data-stdin="24\n3"
preis = float(input("Preis der Pizza in Euro: "))
personen = int(input("Anzahl Personen: "))
anteil = preis / personen
print("Jeder zahlt:", anteil)
```

</Fehlersuche>
