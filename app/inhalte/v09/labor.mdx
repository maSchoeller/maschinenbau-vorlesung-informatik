<Syntaxkarte id="sk-random" nr="1" titel="random: Zufallszahl">

```python
import random

zahl = random.randint(1, 100)
print(zahl)
```

- Ausgabe: eine Zahl von 1 bis 100. Bei jedem Lauf wird neu gezogen, meist kommt eine andere Zahl.
- `import random` steht ganz oben. `random.randint(1, 100)` zieht eine ganze Zahl, beide Grenzen gehören dazu. Bei `range` ist das anders: Dort gehört der Stoppwert nicht dazu.
- Die Zahl wird einmal gezogen und in einem Namen gespeichert, hier `zahl`.
- Ohne `import` meldet Python `NameError: name 'random' is not defined`. Dann fehlt oben das `import random`.
- Diese zwei Zeilen brauchst du in der Klausur ohne Vorlage.

</Syntaxkarte>

<Syntaxkarte id="sk-zerlegen" nr="2" titel="Programm in Funktionen">

```python
def frage(text):
    return int(input(text))

def melde(x):
    print(f"Ergebnis: {x}")

a = frage("Erste Zahl: ")
b = frage("Zweite Zahl: ")
melde(a + b)
```

- Die Eingaben 3 und 4 ergeben `Ergebnis: 7`.
- Die Funktionen stehen oben, das Hauptprogramm steht unten.
- Das Hauptprogramm liest sich wie die Beschreibung: erste Zahl fragen, zweite Zahl fragen, Ergebnis melden.
- Eine Funktion, eine Aufgabe: Was hineingeht, sind die Parameter. Was herauskommt, ist der Rückgabewert.

</Syntaxkarte>

<p class="l-task__intro">Aufgabe: Ein langes Programm soll in Funktionen zerlegt werden. Die Ausgabe darf sich dabei nicht ändern. Wieder gilt: **erst der Plan, dann der Code.** Hier ist das Programm vorher, 14 Zeilen ohne den Kommentar hintereinander:</p>

```python
# Getränkeautomat: 1 = Cola, 2 = Wasser, 3 = Saft
wahl = int(input("Getränk (1 Cola, 2 Wasser, 3 Saft): "))
geld = float(input("Geld in Euro: "))
if wahl == 1:
    preis = 2.5
elif wahl == 2:
    preis = 1.0
else:
    preis = 2.0
if geld >= preis:
    rest = geld - preis
    print(f"Bitte sehr. Wechselgeld: {rest:.2f} Euro")
else:
    fehlt = preis - geld
    print(f"Es fehlen {fehlt:.2f} Euro")
```

<Schritte>

1. **Der Ablauf in Worten:** Getränk und Geld einlesen. Den Preis zum Getränk bestimmen. Die Antwort bilden. Ausgeben.
2. **Was wird eine Funktion?** Der Preis und die Antwort, weil jeweils etwas hineingeht und etwas herauskommt: eine Nummer hinein und ein Preis heraus, Geld und Preis hinein und ein Text heraus. Eingabe und Ausgabe bleiben im Hauptprogramm.
3. **Die Pläne:** Der Hauptplan hat zwei Rechtecke mit Doppellinien, je eines für `preis_von` und `antwort`. Jede Funktion hat ihren eigenen kleinen Plan: Start mit dem Namen, die Verzweigung, am Ende die Rückgabe.
4. **Der Code:** Erst die zwei Funktionen, dann das Hauptprogramm mit vier Zeilen. Die Funktionen stehen vor dem Aufruf.
5. **Probe:** Mit den Eingaben 1 und 3 erscheint `Bitte sehr. Wechselgeld: 0.50 Euro`, genau wie beim langen Programm: Die Cola kostet 2.5, und 3 minus 2.5 ist 0.5.
6. **Selbsterklärung:** Ändere in `preis_von` den Preis der Cola auf 3.0 und lass das Programm mit 1 und 3 laufen. Vermute: Was erscheint jetzt? Probier es aus und lies dann Schritt 7.
7. **Auflösung:** Du musstest nur in `preis_von` etwas ändern, im Hauptprogramm und in `antwort` nicht. Es erscheint `Bitte sehr. Wechselgeld: 0.00 Euro`. Das ist der Vorteil: Jede Aufgabe steht an genau einer Stelle.

</Schritte>

<p class="k-small k-muted">Im Code darfst du `text = …` und `print(text)` zu `print(hinweis(…))` zusammenziehen.</p>

```text class="a-gap__src" data-run="no"
@@import@@ random

def hinweis(geraten, geheim):
    if geraten @@<@@ geheim:
        @@return@@ "Zu klein"
    elif geraten @@>@@ geheim:
        return "Zu groß"
    else:
        return "Richtig!"

geheim = random.@@randint@@(1, 100)
geraten = int(input("Dein Tipp (1 bis 100): "))
print(@@hinweis@@(geraten, geheim))
```
