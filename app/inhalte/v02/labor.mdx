<Syntaxkarte id="sk-vergleich" nr="1" titel="Vergleichen: wahr oder falsch">

```python
punkte = 48
print(punkte >= 50)
print(punkte == 48)
```

- Ausgabe: `False`, dann `True`.
- Fünf Zeichen: `<`, `>`, `<=`, `>=`, `==`.
- `==` fragt, ob zwei Werte gleich sind. `=` legt einen Wert ab.

</Syntaxkarte>

<Syntaxkarte id="sk-if" nr="2" titel="if und else: einer von zwei Wegen">

```python
punkte = 48
if punkte >= 50:
    print("Bestanden")
else:
    print("Nicht bestanden")
```

- Ausgabe: `Nicht bestanden`.
- Doppelpunkt hinter der Bedingung und hinter `else`.
- Vier Leerzeichen Einrückung. Genau ein Weg läuft.

</Syntaxkarte>

<Syntaxkarte id="sk-fstring" nr="3" titel="f-String: zwei Nachkommastellen">

```python
preis = 9.5
print(f"Ticket: {preis:.2f} Euro")
```

- Ausgabe: `Ticket: 9.50 Euro`.
- Das `f` steht direkt vor dem Anführungszeichen, der Name in `{}`.
- `:.2f` hinter dem Namen zeigt genau zwei Nachkommastellen.

</Syntaxkarte>

<Station id="a-fehler" titel="Fehler finden" teil="A" min="7" data-seen="manual">

<p class="l-task__intro">Lies das Programm Zeile für Zeile und vergleiche es mit der Aufgabe. Einen der beiden Fehler meldet Python, den anderen nicht.</p>

<Fehlersuche titel="Eis kaufen" fehler="3 7">

Eine Kugel kostet 1,50 Euro, du hast 5 Euro. Das Programm zeigt den Preis mit zwei Nachkommastellen und sagt, ob das Geld reicht. Erwartet bei 2 Kugeln: `Preis: 3.00 Euro`, dann `Geld reicht`. In zwei Zeilen steckt ein Fehler.

```text
kugeln = int(input("Wie viele Kugeln? "))
preis = kugeln * 1.5
print("Preis: {preis:.2f} Euro")
if preis <= 5:
    print("Geld reicht")
else:
print("Zu teuer")
```

#### Fehler 1: Einrückung fehlt (Zeile 7)

Die Zeile unter `else:` ist nicht eingerückt. Diesen Fehler meldet Python selbst: `IndentationError: expected an indented block after 'else' statement on line 6`.

#### Fehler 2: das f fehlt (Zeile 3)

Vor dem Anführungszeichen fehlt das `f`. Das findest nur du: Das Programm läuft und schreibt `Preis: {preis:.2f} Euro` wörtlich hin.

So ist es richtig:

```python data-stdin="2"
kugeln = int(input("Wie viele Kugeln? "))
preis = kugeln * 1.5
print(f"Preis: {preis:.2f} Euro")
if preis <= 5:
    print("Geld reicht")
else:
    print("Zu teuer")
```

Bei 2 Kugeln: `Preis: 3.00 Euro`, `Geld reicht`. Bei 4 Kugeln: `Preis: 6.00 Euro`, `Zu teuer`.

</Fehlersuche>

</Station>
