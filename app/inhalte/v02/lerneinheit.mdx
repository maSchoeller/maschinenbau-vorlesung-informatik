<Abschnitt id="wahr-falsch" nr="1" titel="Wahr oder falsch">

Eine Cola kostet 1,50 Euro. Du hast 2 Euro. Der Satz „Mein Geld reicht“ stimmt. Hast du nur 1 Euro, stimmt er nicht.

So ein Satz heißt <Begriff e="Eine Aussage ist ein Satz, der entweder stimmt oder nicht stimmt. „Mein Geld reicht“ ist eine Aussage, „Wie spät ist es?“ nicht.">Aussage</Begriff>: ein Satz, der stimmt oder nicht stimmt. „Wie spät ist es?“ ist keine Aussage. Ob eine Aussage stimmt, heißt ihr **Wahrheitswert**: wahr oder falsch, dazwischen gibt es nichts. Python schreibt `True` und `False`, mit großem Anfangsbuchstaben und ohne Anführungszeichen.

Ein Vergleich ist eine Aussage über Zahlen. Dafür gibt es fünf Zeichen:

<div class="k-tablewrap">
<table class="k-types">
<thead><tr><th scope="col">Zeichen</th><th scope="col">Bedeutung</th><th scope="col">Beispiel</th><th scope="col">Wahrheitswert</th></tr></thead>
<tbody>
<tr><td><code>{"<"}</code></td><td>kleiner als</td><td><code>{"1 < 1.5"}</code></td><td>wahr</td></tr>
<tr><td><code>{">"}</code></td><td>größer als</td><td><code>{"1.5 > 1.5"}</code></td><td>falsch</td></tr>
<tr><td><code>{"<="}</code></td><td>kleiner oder gleich</td><td><code>{"1.5 <= 1.5"}</code></td><td>wahr</td></tr>
<tr><td><code>{">="}</code></td><td>größer oder gleich</td><td><code>{"2 >= 1.5"}</code></td><td>wahr</td></tr>
<tr><td><code>{"=="}</code></td><td>gleich</td><td><code>{"6 == 6"}</code></td><td>wahr</td></tr>
</tbody>
</table>
</div>

In Aufgaben steht der Vergleich meist als Satz. So wird daraus ein Zeichen:

<div class="k-tablewrap">
<table class="k-types">
<thead><tr><th scope="col">Im Satz</th><th scope="col">Als Zeichen</th></tr></thead>
<tbody>
<tr><td>mindestens 16</td><td><code>{">= 16"}</code></td></tr>
<tr><td>höchstens 50</td><td><code>{"<= 50"}</code></td></tr>
<tr><td>unter 10</td><td><code>{"< 10"}</code></td></tr>
<tr><td>mehr als 30</td><td><code>{"> 30"}</code></td></tr>
<tr><td>genau 6</td><td><code>{"== 6"}</code></td></tr>
</tbody>
</table>
</div>

<Explorable name="vergleich" titel="Reicht das Geld?">

Stell mit dem Regler ein, wie viel Geld du hast, und wähl ein Vergleichszeichen. Die Cola kostet fest 1,50 Euro. Vermute zuerst: Du hast genau 1,50 Euro. Bei welchen der fünf Zeichen ist die Aussage wahr?

<Ohne>

Für den Baustein wird JavaScript benötigt. Beispiel: Mit 2,00 Euro und dem Zeichen >= lautet die Aussage 2.0 >= 1.5. Sie ist wahr, Python schreibt True. Mit 1,00 Euro ist 1.0 >= 1.5 falsch, also False.

</Ohne>

</Explorable>

<details class="k-deep">
<summary>Auflösung</summary>

Bei genau 1,50 Euro sind drei Zeichen wahr: `<=`, `>=` und `==`.

</details>

Ein Wert genau auf der Grenze heißt <Begriff e="Der Grenzfall ist der Wert, der genau auf der Grenze einer Bedingung liegt, zum Beispiel genau 1,50 Euro bei einem Preis von 1,50 Euro. Dort unterscheiden sich >= und >.">Grenzfall</Begriff>. Dort unterscheiden sich `>=` und `>`.

Python rechnet Vergleiche aus wie Rechnungen. `print` zeigt das Ergebnis:

```python
geld = 2
preis = 1.5
print(geld >= preis)
print(geld < preis)
```

Ausgabe: `True`, dann `False`.

<div class="k-try">

### Vorhersage: der Grenzfall

<Vorhersage>

Was geben die beiden letzten Zeilen aus?

- [x] False, dann True
- True, dann True
- False, dann False
- True, dann False

`False`, dann `True`. 1.5 ist nicht größer als 1.5, aber größer oder gleich.

</Vorhersage>

```python
geld = 1.5
preis = 1.5
print(geld > preis)
print(geld >= preis)
```

</div>

<Hinweis art="merke">

Probier eine Grenze immer mit drei Werten aus: einem darunter, einem **genau auf der Grenze** und einem darüber.

</Hinweis>

Zum Schluss noch ein Wort: NICHT. Es dreht eine Aussage um. Aus wahr wird falsch, aus falsch wird wahr. Ist A die Aussage „Das Geld reicht“, dann ist NICHT A die Aussage „Das Geld reicht nicht“. Die kleine Tabelle listet jeden Fall auf. So eine Tabelle heißt <Begriff e="Eine Wahrheitstabelle listet alle Fälle auf, die eine Aussage annehmen kann, und daneben das Ergebnis. Für NICHT A sind es zwei Zeilen.">Wahrheitstabelle</Begriff>:

<div class="k-tablewrap">
<table class="k-types">
<thead><tr><th scope="col">A</th><th scope="col">NICHT A</th></tr></thead>
<tbody>
<tr><td>wahr</td><td>falsch</td></tr>
<tr><td>falsch</td><td>wahr</td></tr>
</tbody>
</table>
</div>

Wie man zwei Aussagen mit UND und ODER verknüpft, kommt in Termin 03.

<Abschnitt id="raute" nr="2" titel="Die Raute: ein Plan mit zwei Wegen">

Der Automat soll zwei verschiedene Dinge tun können: eine Cola herausgeben oder sagen, dass das Geld nicht reicht. Mit Parallelogramm und Rechteck geht es nur geradeaus. Dafür gibt es das vierte Symbol:

<div class="k-tablewrap">
<table class="k-types">
<thead><tr><th scope="col">Symbol</th><th scope="col">Name</th><th scope="col">Bedeutung</th></tr></thead>
<tbody>
<tr><td>Raute</td><td>Verzweigung</td><td>eine Frage mit zwei Ausgängen, ja und nein</td></tr>
</tbody>
</table>
</div>

In der Raute steht eine <Begriff e="Eine Bedingung ist eine Aussage, die der Ablauf prüft, zum Beispiel geld >= 1.5. Ist sie wahr, geht es den ja-Weg, sonst den nein-Weg.">Bedingung</Begriff> als Frage, zum Beispiel `geld >= 1.5?`. Eine Bedingung ist eine Aussage, die der Ablauf prüft. Die Raute hat einen Eingang und zwei Ausgänge: **ja**, wenn die Aussage wahr ist, und **nein**, wenn sie falsch ist.

<Plan titel="Getränkeautomat">

```text
Eingabe: geld
Entscheidung: geld >= 1.5?
  ja:
    Ausgabe: "Cola kommt"
  nein:
    Ausgabe: "Zu wenig Geld"
Ausgabe: "Danke"
```

</Plan>

Mit 2 Euro gibt der Plan „Cola kommt“ und „Danke“ aus. Mit 1 Euro „Zu wenig Geld“ und „Danke“.

<Explorable name="weiche" titel="Der Plan des Getränkeautomaten">

Wähl einen Betrag und schau, welchen Weg der Ablauf nimmt. Vermute zuerst: Findest du einen Betrag, bei dem beide Wege leuchten, oder einen, bei dem keiner leuchtet?

<Ohne>

Für den Baustein wird JavaScript benötigt. Beispiel: Bei 1,00 Euro ist 1.0 >= 1.5 falsch. Der Ablauf nimmt den Weg nein und gibt „Zu wenig Geld“ aus, danach „Danke“.

</Ohne>

</Explorable>

Drei Regeln für die Raute:

- Es wird **genau ein Weg** gegangen: nie beide, nie keiner.
- Danach treffen sich die Wege wieder. Was darunter steht, passiert **immer**.
- Es bleibt bei einem Ende.

Einen Plan mit Raute liest du so: Wert einsetzen, Frage beantworten, dem Pfeil folgen. In die Raute schreibst du die Bedingung so, wie sie später in Python steht. Von Hand darfst du auch ≤ und ≥ schreiben.

<div class="k-try">

### Vorhersage: Plan lesen

<Vorhersage>

Was gibt der Plan bei der Eingabe 25 aus?

- [x] 29
- 25
- 4
- 34

29. 25 >= 30 ist falsch, also Weg nein: versand = 4. Danach laufen die Wege zusammen: 25 + 4 = 29.

</Vorhersage>

<Plan titel="Versandkosten">

```text
Eingabe: bestellwert
Entscheidung: bestellwert >= 30?
  ja:
    versand = 0
  nein:
    versand = 4
gesamt = bestellwert + versand
Ausgabe: gesamt
```

</Plan>

</div>

<Abschnitt id="if-else" nr="3" titel="if und else: aus der Raute wird Code">

Jetzt wird aus der Raute Code. Die Übersetzung ist fest:

- Die Raute wird `if Bedingung:`. Der ja-Weg steht eingerückt darunter.
- Der nein-Weg steht eingerückt unter `else:`. `else` hat keine eigene Bedingung: Es ist der Fall, in dem die Aussage falsch ist.
- Hinter der Bedingung und hinter `else` steht ein **Doppelpunkt**.
- Die <Begriff e="Die Einrückung sind die Leerzeichen am Anfang einer Zeile. In Python zeigen sie, welche Zeilen zu einem Weg gehören. Üblich sind vier Leerzeichen.">Einrückung</Begriff> ist vier Leerzeichen breit. Sie zeigt, welche Zeilen zu einem Weg gehören. Nach dem Doppelpunkt rückt der Editor die nächste Zeile selbst ein.
- `else` steht auf derselben Höhe wie `if`.
- Was nicht eingerückt ist, läuft immer. Das ist die Stelle, an der die Wege im Plan zusammenlaufen.

Links der Plan aus Abschnitt 2, rechts das Programm. Vergleiche Symbol für Symbol und Zeile für Zeile:

<div class="v01-paar">

<Plan titel="Getränkeautomat">

```text
Eingabe: geld
Entscheidung: geld >= 1.5?
  ja:
    Ausgabe: "Cola kommt"
  nein:
    Ausgabe: "Zu wenig Geld"
Ausgabe: "Danke"
```

</Plan>

<div>

```python data-stdin="2"
geld = float(input("Eingeworfen in Euro: "))
if geld >= 1.5:
    print("Cola kommt")
else:
    print("Zu wenig Geld")
print("Danke")
```

<p class="k-small k-muted">Führ das Programm mit 2, mit 1 und mit dem Grenzfall 1.5 aus. Mit „Schritt für Schritt“ siehst du, welche Zeile übersprungen wird.</p>

</div>

</div>

Bei 2 Euro und bei 1,50 Euro kommen `Cola kommt` und `Danke`, bei 1 Euro `Zu wenig Geld` und `Danke`.

In einer Bedingung steht oft `==`. Das ist nicht dasselbe wie `=`: **`=` legt einen Wert ab, `==` fragt, ob zwei Werte gleich sind.** `wurf = 6` merkt sich die 6, `if wurf == 6:` fragt, ob eine 6 gewürfelt wurde.

<div class="k-try">

### Vorhersage: Was gehört zum Weg?

<Vorhersage>

Was gibt das Programm aus?

- [x] Gewonnen, dann Ende
- Gewonnen, dann Nochmal würfeln, dann Ende
- nur Gewonnen
- Gewonnen, dann Verloren, dann Nochmal würfeln, dann Ende

`Gewonnen`, dann `Ende`. Die zwei eingerückten Zeilen unter `else` gehören zum nein-Weg und werden übersprungen. `print("Ende")` ist nicht eingerückt und läuft immer.

</Vorhersage>

```python
wurf = 6
if wurf == 6:
    print("Gewonnen")
else:
    print("Verloren")
    print("Nochmal würfeln")
print("Ende")
```

</div>

<Hinweis art="achtung">

Die zwei häufigsten Fehler bei `if` und `else`, mit der Meldung von Python:

- Doppelpunkt vergessen: `SyntaxError: expected ':'`
- Einrückung vergessen: `IndentationError: expected an indented block after 'if' statement on line 2`

Die Zeilennummer sagt dir, wo du suchen musst.

</Hinweis>

</Abschnitt>

<Abschnitt id="f-string" nr="4" titel="Ausgabe formatieren: der f-String">

Das Programm „Verdienst im Nebenjob“ aus dem Training von Termin 01 gibt `Verdienst: 162.0` aus. Ein Automat, der 50 Cent zurückgibt, schriebe `Rückgeld: 0.5 Euro`. Geld schreibt man aber mit zwei Stellen hinter dem Komma.

Dafür gibt es den <Begriff e="Ein f-String ist ein Text mit einem f vor dem Anführungszeichen. In geschweiften Klammern stehen Namen, Python setzt dort ihre Werte ein. Mit :.2f erscheint eine Zahl mit zwei Nachkommastellen.">f-String</Begriff>:

- Ein `f` direkt vor dem Anführungszeichen macht aus dem Text einen f-String.
- In geschweiften Klammern `{}` steht ein Variablenname. Python setzt dort den Wert ein.
- `{rueckgeld:.2f}`: Doppelpunkt, Punkt, 2, f. Die Zahl erscheint mit genau zwei Nachkommastellen, gerundet oder mit Nullen aufgefüllt. Die Variable selbst ändert sich nicht, nur die Anzeige.
- Ohne das `f` erscheinen die Klammern wörtlich in der Ausgabe. Python meldet keinen Fehler.

```python
rueckgeld = 0.5
print("Rückgeld:", rueckgeld, "Euro")
print(f"Rückgeld: {rueckgeld} Euro")
print(f"Rückgeld: {rueckgeld:.2f} Euro")
```

Ausgabe: `Rückgeld: 0.5 Euro`, `Rückgeld: 0.5 Euro`, `Rückgeld: 0.50 Euro`. Erst `:.2f` macht die zwei Stellen.

Im Plan ändert sich dabei nichts: Das Parallelogramm „Ausgabe: verdienst“ bleibt. Wie die Zahl aussieht, legt der Code fest.

<div class="k-try">

```

</div>

<Frage id="vergleiche" typ="mc" punkte="4" titel="Vergleiche prüfen (mehrere richtig)">

Welche Vergleiche sind wahr? Kreuze alle richtigen an.

- [x] `7 >= 7`
- `3 > 5`
- [x] `4 <= 9`
- `6 == 9`
- [x] `2 < 2.5`

Bei <code>{">="}</code> und <code>{"<="}</code> zählt der gleiche Wert mit. <code>==</code> ist nur bei gleichen Werten wahr.

</Erklaerung>

</Frage>

<Frage id="satz-zeichen" typ="mc" punkte="2" titel="Vom Satz zum Zeichen">

In einen Aufzug dürfen höchstens 8 Personen. Welcher Vergleich ist genau dann wahr, wenn alles in Ordnung ist?

- [x] `personen <= 8`
- `personen < 8`
- `personen >= 8`
- `personen == 8`

<Erklaerung>

„Höchstens 8“ heißt: 8 ist noch erlaubt. Probier den Grenzfall: Bei 8 ist <code>{"personen <= 8"}</code> wahr, <code>{"personen < 8"}</code> wäre falsch.

</Erklaerung>

Welche Zahl gibt der Plan bei der Eingabe 10 aus?

  nein:

Ausgabe: gesamt
```

</Plan>

<Erklaerung>

</Erklaerung>

- Zu schnell, dann In Ordnung, dann Gute Fahrt
