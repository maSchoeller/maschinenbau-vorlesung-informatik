<Syntaxkarte id="sk-text" nr="1" titel="str, bool und Text zusammensetzen">

```python
name = "Lea"
print("Hallo " + name)
print(type(name))
print(type(5 > 3))
print(name == "Lea")
```

- Ausgabe: `Hallo Lea`, `<class 'str'>`, `<class 'bool'>`, `True`.
- Text steht in Anführungszeichen. `+` hängt Text aneinander, das Leerzeichen gehört in den Text.
- `==` vergleicht Text mit Text.
- Ein Vergleich ergibt `True` oder `False`. Das ist ein `bool`.

</Syntaxkarte>

<Syntaxkarte id="sk-umwandeln" nr="2" titel="Umwandeln: int, float, str">

```python
zahl = int("5")
print(zahl + 3)
print(float("2.5") * 2)
print("Punkte: " + str(12))
print(int(3.7))
```

- Ausgabe: `8`, `5.0`, `Punkte: 12`, `3`.
- `input()` liefert Text: Wandle um, bevor du rechnest.
- `int` schneidet ab, es rundet nicht.
- Text plus Zahl ist ein `TypeError`.

</Syntaxkarte>

<Syntaxkarte id="sk-lokal" nr="3" titel="Namen in der Funktion">

```python
def quadrat(x):
    ergebnis = x * x
    return ergebnis

zahl = quadrat(4)
print(zahl)
print(ergebnis)
```

- Ausgabe: `16`, dann die Meldung `NameError: name 'ergebnis' is not defined`.
- `x` und `ergebnis` gibt es nur in der Funktion.
- Hinein per Parameter, heraus per `return`.

</Syntaxkarte>

<Syntaxkarte id="sk-rest" nr="4" titel="Rest und True und False zurückgeben">

```python
print(7 % 2)
print(8 % 2)

def ist_gerade(n):
    if n % 2 == 0:
        return True
    else:
        return False

print(ist_gerade(8))
print(ist_gerade(7))
if ist_gerade(10):
    print("gerade")
```

- Ausgabe: `1`, `0`, `True`, `False`, `gerade`.
- `%` ist der Rest beim Teilen. Gerade heißt: Rest 0 beim Teilen durch 2.
- In jedem Zweig steht ein `return`.
- Der Aufruf darf direkt in der Bedingung stehen.

</Syntaxkarte>

Schreibe die Funktion `schraube(d, l)`, die eine Schraube mit Schaftdurchmesser `d` und Schaftlänge `l` zurückgibt (alles in mm). Das Hauptprogramm steht schon da.

Die Werkzeuge:

- `zylinder(durchmesser, laenge)` ist ein Zylinder mit diesem Durchmesser und dieser Länge.
- `verschiebe(körper, dx, dy, dz)` setzt einen Körper um `dx` nach rechts, `dy` nach hinten und `dz` nach oben (alles in mm, immer mit allen drei Zahlen). `verschiebe(körper, 40, 0, 0)` ist nach rechts, `verschiebe(körper, 0, 0, 10)` nach oben.

Der Plan der Funktion steht in Worten da, geschrieben wird der Code:

<Station id="a-fehler" titel="Fehler finden: Preis mit Steuer" teil="A" min="7" data-seen="manual">

<p class="l-task__intro">Lies das Programm Zeile für Zeile und vergleiche es mit der Aufgabe. Ein Fehler meldet Python, den anderen findest nur du, zum Beispiel mit einer Probe.</p>

<Fehlersuche titel="Preis mit Steuer" fehler="5 9">

Das Programm rechnet einen Nettopreis in den Preis mit 19 Prozent Steuer um. Bei 100 Euro wird `Brutto: 119.00 Euro` erwartet. In zwei Zeilen steckt ein Fehler.

```text
# Rechnet einen Nettopreis in den Preis mit 19 Prozent Steuer um.
def brutto(netto):
    steuer = netto * 0.19
    endpreis = netto + steuer
    return steuer

n = float(input("Netto in Euro: "))
b = brutto(n)
print(f"Brutto: {endpreis:.2f} Euro")
```

#### Fehler 1: Name draußen unbekannt (Zeile 9)

Python meldet `NameError: name 'endpreis' is not defined`. `endpreis` gibt es nur in der Funktion. Draußen steht das Ergebnis in `b`.

#### Fehler 2: falscher Wert zurückgegeben (Zeile 5)

Die Funktion gibt nur die Steuer zurück, nicht den Preis mit Steuer. Python meldet dazu nichts. Mit Fehler 1 behoben steht bei 100 Euro `Brutto: 19.00 Euro` da. Zurückgegeben werden muss `endpreis`.

So ist es richtig:

```python data-stdin="100"
# Rechnet einen Nettopreis in den Preis mit 19 Prozent Steuer um.
def brutto(netto):
    steuer = netto * 0.19
    endpreis = netto + steuer
    return endpreis

n = float(input("Netto in Euro: "))
b = brutto(n)
print(f"Brutto: {b:.2f} Euro")
```

Probe: Es erscheint `Brutto: 119.00 Euro`. Mit 50 erscheint `Brutto: 59.50 Euro`, mit 0 erscheint `Brutto: 0.00 Euro`.

</Fehlersuche>

<div class="a-task__text">

Eine Zahl ist vollkommen, wenn die Summe ihrer Teiler (ohne sie selbst) die Zahl ergibt. 6 hat die Teiler 1, 2 und 3: 1 + 2 + 3 ist 6. Eingelesen wird eine Grenze (höchstens 100). Ausgegeben werden alle vollkommenen Zahlen von 2 bis zur Grenze, je eine in einer Zeile. Dafür schreibst du `ist_teilbar(zahl, teiler)` und `teilersumme(n)`, die `ist_teilbar` aufruft. Beispiel: Die Grenze 30 ergibt 6 und 28.
