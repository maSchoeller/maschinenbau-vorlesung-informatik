<Syntaxkarte id="sk-for-range" nr="1" titel="for i in range: genau so oft">

```python
for i in range(1, 4):
    print(i)
print("fertig")
```

- Ausgabe: `1`, `2`, `3`, `fertig`.
- `range(1, 4)` ergibt 1, 2, 3. Der Stoppwert gehört nicht dazu. Für 1 bis n schreibst du `range(1, n + 1)`.
- `range(4)` mit nur einer Zahl beginnt bei 0: 0, 1, 2, 3.
- Im Rumpf steht kein `i = i + 1`, das macht `for` selbst.

</Syntaxkarte>

<Syntaxkarte id="sk-if-ohne-else" nr="2" titel="if ohne else: nur wenn">

```python
punkte = 9
if punkte >= 8:
    print("gut")
print("weiter")
```

- Ausgabe: `gut`, `weiter`. Mit `punkte = 5` erscheint nur `weiter`.
- Ohne `else` passiert bei „falsch“ nichts. Es geht unter dem `if` weiter.

</Syntaxkarte>

<Schritte>

1. **Der Ablauf in Worten:** n einlesen, dann n Zeiten einlesen und addieren, am Ende durch n teilen.
2. **Wie oft?** Das steht nach der ersten Eingabe fest: n-mal. Also passt `for`.
3. **Wo steht was?** Der Startwert `summe = 0` steht vor der Schleife. Einlesen und Addieren stehen im Rumpf. Teilen und Ausgeben stehen nach der Schleife.
4. **Der Plan:** Raute „i von 1 bis n?“, darunter der Rumpf, dann der Pfeil zurück zur Raute. Bei „nein“ geht es weiter zum Teilen.
5. **Der Code:** `range(1, n + 1)`, weil der Stoppwert nicht dazugehört. Das `i` steht in der Eingabeaufforderung, so siehst du, welcher Tag dran ist.
6. **Probe:** Mit 3, 25, 31, 22 erscheint `Im Schnitt 26.0 Minuten`, denn 78 durch 3 ist 26. Mit 1, 17 erscheint `Im Schnitt 17.0 Minuten`: Bei n = 1 läuft der Rumpf genau einmal.
7. **Selbsterklärung:** Was passiert bei 0 Tagen? Erst ausprobieren, dann lesen: Python meldet `ZeroDivisionError: division by zero`: Die Schleife läuft nie, `summe` bleibt 0, und durch 0 teilen geht nicht. Deshalb steht in der Aufgabe „mindestens 1“.

</Schritte>

<Station id="a-fehler" titel="Fehler finden: Sommertage" teil="A" min="6" data-seen="manual">

<p class="l-task__intro">Lies das Programm Zeile für Zeile und vergleiche es mit der Aufgabe. Ein Fehler meldet Python, den anderen findest nur du, zum Beispiel mit einer Probe.</p>

<Fehlersuche titel="Sommertage" fehler="1 3">

Eingelesen werden die Höchsttemperaturen einer Woche (ganze Zahlen). Gezählt wird, an wie vielen Tagen es mindestens 25 Grad warm war, das sind Sommertage. Bei 22, 25, 28, 19, 30, 24, 26 wird 4 erwartet. In zwei Zeilen steckt ein Fehler.

```text
for i in range(1 8):
    temp = int(input(f"Höchstwert Tag {i}: "))
    anzahl = 0
    if temp >= 25:
        anzahl = anzahl + 1
print(f"Sommertage: {anzahl}")
```

#### Fehler 1: Komma fehlt (Zeile 1)

Zwischen 1 und 8 fehlt das Komma. Python meldet `SyntaxError: invalid syntax. Perhaps you forgot a comma?`.

#### Fehler 2: Startwert im Rumpf (Zeile 3)

`anzahl = 0` steht im Rumpf, also beginnt `anzahl` jeden Tag wieder bei 0. Mit den Beispielwerten kommt 1 heraus, nur der letzte Tag (26) zählt. Python meldet dazu nichts. Der Startwert gehört vor die Schleife.

So ist es richtig:

```python data-stdin="22\n25\n28\n19\n30\n24\n26"
anzahl = 0
for i in range(1, 8):
    temp = int(input(f"Höchstwert Tag {i}: "))
    if temp >= 25:
        anzahl = anzahl + 1
print(f"Sommertage: {anzahl}")
```

Probe: Es erscheint `Sommertage: 4`. Die 25 zählt mit, denn die Grenze ist erlaubt. Mit `>` statt `>=` wären es nur 3.

</Fehlersuche>

</Station>
