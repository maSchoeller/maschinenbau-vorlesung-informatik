Eine Variable ist ein Name für einen Wert. Mit dem Gleichheitszeichen gibst du einem Wert einen Namen. Das nennt man Zuweisung, und es ist keine Gleichung. Python liest sie von rechts nach links: Erst wird die rechte Seite berechnet, dann bekommt das Ergebnis den Namen auf der linken Seite. Danach kannst du den Namen überall verwenden, wo du den Wert brauchst.
