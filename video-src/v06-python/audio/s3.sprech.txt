Rückwärts zählst du mit dem Schritt minus eins. rehndsch von fünf, null, minus eins ergibt fünf, vier, drei, zwei, eins. Die null fehlt: Der Stoppwert gehört nie dazu. Andere negative Schritte liest du nur. rehndsch von zehn, null, minus drei ergibt zehn, sieben, vier und eins. Achtung: Zählst du gegen den Schritt, läuft der Rumpf nie. rehndsch von fünf, null hat keine Zahl, und Python schweigt. Ein Schritt von null meldet einen ValueError.
