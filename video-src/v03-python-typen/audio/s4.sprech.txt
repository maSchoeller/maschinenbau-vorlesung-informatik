Jetzt: Abschneiden gegen Runden. int schneidet die Nachkommastellen ab, in Richtung null: int von zwei Punkt neun ist zwei, int von minus zwei Punkt neun ist minus zwei. round rundet: round von zwei Punkt neun ist drei. Genau bei einem halben rundet Python zur nächsten geraden Zahl: round von zwei Punkt fünf ist zwei, round von drei Punkt fünf ist vier. Das nennt man Banker's Rounding.
