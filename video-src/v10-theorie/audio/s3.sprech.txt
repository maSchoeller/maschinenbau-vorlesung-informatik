Der Rechner kennt nur Zahlen. Darum ist auch jeder Buchstabe eine Zahl. Diese Zuordnung heißt Code. Ein einfacher Code ist Asky. Er hat sieben Bit, das sind hundertachtundzwanzig Zeichen. Das große A ist die fünfundsechzig. In Bits ist das eins null null null null null eins. Das B ist die sechsundsechzig, das C die siebenundsechzig, und so geht es weiter. Das kleine a ist die siebenundneunzig, in Bits eins eins null null null null eins. Zwischen groß und klein liegen immer zweiunddreißig.
