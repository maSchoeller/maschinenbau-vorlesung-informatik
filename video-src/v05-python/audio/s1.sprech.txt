Ein Struktogramm lässt sich fast mechanisch in Python übersetzen: Block für Block. Links das Struktogramm, rechts der Code, und gleiche Farbe heißt: gehört zusammen. Aus jeder Eingabe wird eine Zeile: float von input liest eine Kommazahl ein. Die Namen der Variablen übernimmst du aus dem Struktogramm, dann findet jeder die Stelle wieder. Dieses Muster wendest du ab jetzt bei jeder Aufgabe an.
