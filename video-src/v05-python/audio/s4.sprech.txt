Wir prüfen die Eingabe zuerst, denn bei einer Spannung von null bricht die Division ab. Python meldet einen Zero Division Error, und danach kommt keine Ausgabe mehr. Ein if vor der Rechnung fängt solche Werte ab: Plausibel heißt, der Wert ist physikalisch möglich. Auch eine negative Spannung ergibt keinen Sinn, deshalb prüfen wir spannung kleiner gleich null. So schützt ein einziges if das ganze Programm vor unsinnigen Werten.
