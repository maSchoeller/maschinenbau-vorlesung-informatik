PAP-Editor

Baue einen Programmablaufplan aus Symbolen. Der Plan ist immer gültig, und daneben entsteht der Python-Code, den du direkt ausführen kannst. Umgekehrt macht „Code → PAP“ aus Python einen Plan.

Die Symbole und ihr Python-Code

Der Editor kennt die Symbole nach DIN 66001. Start und Ende setzt er automatisch. Du fügst Symbole mit dem + im Plan ein, klickst ein Symbol an, um den Text zu ändern, und verschiebst oder löschst es im Bedienfeld unter dem Plan.

    Tastatur: Tab springt in den Plan, ↑ ↓ wechseln das Symbol, Enter bearbeitet den Text, + oder Einfg fügt danach ein (mit Umschalt davor), Alt+↑/↓ verschiebt, Entf löscht, Strg+Z macht rückgängig, Strg+Y stellt wieder her.

    Gespeichert wird nur in diesem Browser (unter „Gespeicherte PAPs“). Dein letzter Stand bleibt als Entwurf erhalten. Beim Rückübersetzen („Code → PAP“) versteht der Editor Zuweisungen, input, print, if/elif/else, while, for … in range(…) und Funktionsaufrufe.

    Aufgabe zum Ausprobieren

    Summe der geraden Zahlen

    Zeichne einen Programmablaufplan, der eine ganze Zahl n einliest und die Summe aller geraden Zahlen von 1 bis n ausgibt. Für n = 10 ist das 2 + 4 + 6 + 8 + 10 = 30. Benutze eine Zählschleife und eine Verzweigung. Der Anfang steht schon im Plan.

    1. Die Eingabe muss eine ganze Zahl sein (Datentyp „ganze Zahl (int)“), sonst kann range nicht damit arbeiten.
    2. Die Zählschleife läuft von 1 bis n: i in range(1, n + 1). In der Schleife prüft eine Verzweigung, ob i gerade ist.
    3. Gerade heißt: Rest 0 bei Division durch 2, in Python i % 2 == 0. Nur im Ja-Weg wird addiert: summe = summe + i. Die Ausgabe steht hinter der Schleife.
