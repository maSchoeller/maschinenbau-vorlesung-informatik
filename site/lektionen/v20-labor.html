Werkzeugkasten

Heute neu in Python: Klassen und Objekte. Eine Klasse bündelt die Maße eines Bauteils (Attribute) und die Rechnungen damit (Methoden). Dazu kommt das Hilfsmodul bauteil3d, das aus Maßen ein 3D-Modell macht.

Merke

Diese acht Karten sind dein Spickzettel, bis es sitzt. Du erreichst sie in jeder Aufgabe über den Knopf „Werkzeugkasten“ oben. Führe jede Karte aus und ändere etwas daran: Was passiert, wenn du ein Maß änderst oder eine Klammer weglässt?

Syntax-Karte 1

Klasse mit __init__ schreiben und ein Objekt erzeugen

class Welle:
    """Eine einfache Welle: Durchmesser d und Länge l in mm."""

    def __init__(self, d, l):
        self.d = d          # Attribut d: Durchmesser in mm
        self.l = l          # Attribut l: Länge in mm


w = Welle(20, 100)          # Objekt erzeugen: __init__ läuft automatisch
print(w.d, w.l)             # Attribute lesen: 20 100
print(type(w))              # w ist ein Objekt der Klasse Welle
  • class Welle: legt den Bauplan an. Der Name beginnt per Konvention mit einem Großbuchstaben. Darunter, eingerückt, stehen die Methoden.
  • __init__ ist der Konstruktor: Er läuft jedes Mal, wenn ein Objekt entsteht, und speichert die Maße. Vor und hinter init stehen jeweils zwei Unterstriche.
  • self steht in jeder Methode als erster Parameter. self.d = d heißt: „Speichere den Wert d als Attribut d in diesem Objekt.“ Beim Aufruf Welle(20, 100) lässt du self weg.
  • Ohne self. wäre d nur eine lokale Variable (V07), die nach dem Ende von __init__ verschwindet.
Syntax-Karte 2

Objekte erzeugen, Attribut lesen und ändern

class Welle:
    def __init__(self, d, l):
        self.d = d
        self.l = l


w1 = Welle(20, 100)
w2 = Welle(30, 50)          # zweites, unabhängiges Objekt
w1.l = 120                  # Attribut ändern: nur w1 ist betroffen
print(w1.l, w2.l)           # 120 50

w3 = w1                     # kein neues Objekt, nur ein zweiter Name (V08)
w3.l = 80
print(w1.l)                 # 80, weil w1 und w3 dasselbe Objekt sind
  • Jeder Aufruf Welle(...) erzeugt ein neues Objekt mit eigenen Attributen. w1 und w2 beeinflussen sich nicht.
  • Attribute liest du mit objekt.attribut und änderst du mit objekt.attribut = neuer_wert.
  • w3 = w1 kopiert nicht, sondern gibt demselben Objekt einen zweiten Namen. Das kennst du von Listen aus V08.
Syntax-Karte 3

Methode mit Rückgabe

import math


class Welle:
    def __init__(self, d, l):
        self.d = d                      # in mm
        self.l = l                      # in mm

    def volumen(self):
        """Volumen in mm³ (Zylinder)."""
        return math.pi / 4 * self.d ** 2 * self.l


w = Welle(20, 100)
v = w.volumen()                         # Klammern nicht vergessen
print(f"{v:.0f} mm³ = {v / 1000:.1f} cm³")
  • Eine Methode ist eine Funktion (V07) in der Klasse. Der erste Parameter ist immer self; über self.d und self.l kommt sie an die Maße des Objekts.
  • Aufruf: w.volumen(). Python setzt w als self ein, du übergibst nichts dafür.
  • Mit return gibt die Methode das Ergebnis zurück, genau wie eine Funktion. Ohne return wäre der Wert None.
  • Einheiten gehören in den Kommentar oder Docstring: Maße in mm, Volumen in mm³.
Syntax-Karte 4

Methode mit Default-Parameter

import math


class Welle:
    def __init__(self, d, l):
        self.d = d
        self.l = l

    def volumen(self):
        return math.pi / 4 * self.d ** 2 * self.l          # mm³

    def masse(self, dichte=7.85):
        """Masse in kg; Dichte in g/cm³ (Standard: Stahl)."""
        return self.volumen() / 1000 * dichte / 1000        # mm³ -> cm³ -> g -> kg


w = Welle(20, 100)
print(f"Stahl:     {w.masse():.3f} kg")
print(f"Aluminium: {w.masse(2.70):.3f} kg")
print(f"Aluminium: {w.masse(dichte=2.70):.3f} kg")
  • dichte=7.85 ist ein Default-Wert (V07): Ohne Angabe rechnet die Methode mit Stahl.
  • Eine Methode darf eine andere Methode desselben Objekts aufrufen: self.volumen(). Das self. davor ist Pflicht.
  • Einheitenkette: mm³ geteilt durch 1000 ergibt cm³; cm³ mal g/cm³ ergibt g; g geteilt durch 1000 ergibt kg.
Syntax-Karte 5

Methode, die ein Attribut ändert

class Welle:
    def __init__(self, d, l):
        self.d = d
        self.l = l

    def kuerzen(self, mm):
        """Kürzt die Welle um mm (ändert das Objekt, gibt nichts zurück)."""
        self.l = self.l - mm


w = Welle(20, 100)
w.kuerzen(15)
print(w.l)                  # 85
ergebnis = w.kuerzen(5)
print(ergebnis, w.l)        # None 80: kein return, darum None
  • Eine Methode kann den Zustand des Objekts verändern: self.l = self.l - mm überschreibt das Attribut. Danach hat das Objekt die neue Länge.
  • Solche Methoden haben oft kein return. Der Aufruf w.kuerzen(15) steht dann allein in einer Zeile.
  • Der Unterschied zu einer Funktion mit lokalen Variablen (V07): Das Attribut lebt weiter, solange das Objekt lebt.

Kurzreferenz bauteil3d: aus Maßen ein 3D-Modell

import bauteil3d

  • Das Modul liegt dem Labor bei (data-files). Wie es ein Dreiecksnetz berechnet, musst du nicht wissen; du benutzt es.

PAP: Gültigkeit des Flanschs

Erst den Ablauf planen, dann die Methode schreiben. Du zeichnest den Plan für die Prüfung ist_gueltig aus dem Beispiel, nur mit Meldungstexten statt True und False. Ein Methodenaufruf wäre im PAP ein Unterprogramm; hier zeichnest du die Rechenschritte selbst. Die Prüfung erzeugt aus deinem PAP Python-Code und testet ihn mit mehreren Maßen, auch mit den Grenzfällen.

Bohrung auf dem Lochkreis prüfen

Zeichne einen PAP. Die vier Maße (in mm) werden eingelesen und stehen schon da. Zuerst prüfst du den äußeren Rand der Bohrung: Ist (lochkreis + d_bohrung) / 2 < d_aussen / 2 nicht erfüllt, gibst du "Bohrung ragt über den Rand" aus. Sonst prüfst du den inneren Rand: Ist (lochkreis - d_bohrung) / 2 > d_innen / 2 erfüllt, lautet die Ausgabe "gültig", andernfalls "Bohrung ragt ins Mittelloch". Texte stehen in Anführungszeichen, die Bedingungen schreibst du als Python-Ausdruck. Eine Bohrung, die den Rand genau berührt, ist ungültig.

  1. Nach den vier Eingaben kommt die erste Raute mit (lochkreis + d_bohrung) / 2 < d_aussen / 2. Im „nein“-Zweig steht die Ausgabe "Bohrung ragt über den Rand" (mit Anführungszeichen).
  2. Im „ja“-Zweig kommt die zweite Raute: (lochkreis - d_bohrung) / 2 > d_innen / 2. „ja“: Ausgabe "gültig", „nein“: Ausgabe "Bohrung ragt ins Mittelloch".
  3. Die zweite Raute steckt im „ja“-Zweig der ersten: Der innere Rand ist nur interessant, wenn der äußere in Ordnung ist. Genau so ist and in ist_gueltig aufgebaut.

Erste eigene Aufgabe: Klasse Quader

Jetzt schreibst du selbst, mit Tests als Sicherheitsnetz. Du baust eine Klasse für ein Rohteil: einen Quader aus Stahl oder Aluminium.

Schreibe die Klasse Quader. Der Konstruktor __init__(self, a, b, c) speichert die drei Kantenlängen in mm als Attribute a, b und c. Die Methode volumen() gibt das Volumen in mm³ zurück. Die Methode masse(dichte=7.85) gibt die Masse in kg zurück; die Dichte steht in g/cm³ (Stahl 7,85; Aluminium 2,70). Beide Methoden geben mit return zurück, sie drucken nichts. Die Tests erzeugen mehrere Quader, nicht nur den gezeigten.

Erwartet
Quader(100, 50, 20).volumen()     -> 100000 (mm³)
Quader(100, 50, 20).masse()       -> 0.785 (kg, Stahl)
Quader(100, 50, 20).masse(2.70)   -> 0.27 (kg, Aluminium)

Code-Review: KI-Klasse Bolzen prüfen

Eine KI hat eine Klasse für einen Bolzen geliefert. Sie sieht aufgeräumt aus. Würdest du sie freigeben? Klick die Zeilen an, die du für fehlerhaft hältst, dann lass auflösen.

Szenario: Masse eines Bolzens berechnen

Prompt eines Studierenden

Schreib mir eine Python-Klasse Bolzen. Durchmesser d und Länge l in mm sind Attribute. Methoden: volumen() in mm³, masse() in kg für Stahl und info(), die einen Text wie „Bolzen 10 x 50 mm“ zurückgibt. Erzeuge einen Bolzen M10 x 50 und gib seine Masse aus.

KI-Antwort (Python)

Tipp: Es sind vier Fehler eingebaut, in vier verschiedenen Zeilen. Drei davon lösen einen Fehler aus, einer liefert still eine falsche Zahl. Nicht jede Zeile ist falsch.

Würdest du das freigeben? Markiere die fehlerhaften Zeilen, dann lass auflösen.

Die vier Fehler

Fehler 1: Attribut nicht gespeichert (Zeile 6)

l = l weist dem Parameter sich selbst zu und speichert nichts im Objekt. Das Attribut l existiert nie. Sobald eine Methode self.l liest, kommt ein AttributeError: 'Bolzen' object has no attribute 'l'. Lösung: self.l = l.

Fehler 2: d statt self.d (Zeile 9)

Innerhalb einer Methode ist d nur ein Name, der dort nicht definiert ist. Das gibt einen NameError: name 'd' is not defined. Das Maß gehört dem Objekt, also self.d. Lösung: math.pi / 4 * self.d ** 2 * self.l. Gäbe es zufällig eine globale Variable d, würde der Fehler unsichtbar bleiben und jeder Bolzen mit demselben Wert rechnen.

Fehler 3: Einheitenfehler (Zeile 12, mit der Vorgabe in Zeile 11)

Das Volumen steht in mm³, die Dichte 7850 ist die von Stahl in kg/m³. Wer beides multipliziert, bekommt keine Masse in kg: Ein Kubikmeter hat 10⁹ mm³, das Ergebnis ist um den Faktor 10⁹ zu groß (rund 30,8 Millionen „kg“ statt 0,031 kg). Es gibt keine Fehlermeldung, nur eine absurde Zahl. Lösung: Dichte in g/cm³ (7,85) und umrechnen: self.volumen() / 1000 * dichte / 1000 (mm³ zu cm³, cm³ mal g/cm³ ergibt g, g zu kg).

Fehler 4: self fehlt in der Methode (Zeile 14)

def info(): hat keinen Parameter. Beim Aufruf b.info() setzt Python das Objekt automatisch als ersten Argument ein: TypeError: Bolzen.info() takes 0 positional arguments but 1 was given. Und im Körper käme self ohnehin nicht vor. Lösung: def info(self):.

Korrigierte Klasse

import math


class Bolzen:
    def __init__(self, d, l):
        self.d = d                                          # in mm
        self.l = l                                          # in mm

    def volumen(self):
        return math.pi / 4 * self.d ** 2 * self.l           # in mm³

    def masse(self, dichte=7.85):
        return self.volumen() / 1000 * dichte / 1000        # in kg, Dichte in g/cm³

    def info(self):
        return f"Bolzen {self.d} x {self.l} mm"


b = Bolzen(10, 50)
print(b.info())
print(f"{b.masse():.4f} kg")
Merke

Bei KI-Code mit Klassen prüfst du: Steht self in jeder Methode als erster Parameter? Steht vor jedem Maß self.? Werden im __init__ alle Maße gespeichert? Stimmen die Einheiten (mm, mm³, cm³, g/cm³, kg/m³ nicht vermischen)? Ein Programm, das beim ersten Test läuft, ist noch nicht richtig. Und eine Zahl, die nicht zur Größenordnung passt (30 Millionen Kilogramm für einen Bolzen), prüfst du immer mit einer Überschlagsrechnung.

Jetzt korrigierst du es

Die Klasse unten enthält alle vier Fehler. Repariere sie, bis die Tests grün sind.

  1. Vier Stellen: Zeile mit l = l, die Zeile mit d ** 2, die Methode masse und die Zeile def info():.
  2. Attribute im __init__ speicherst du mit self.l = l. In Methoden liest du self.d.
  3. Dichte als g/cm³ (7.85) und Umrechnung: self.volumen() / 1000 * dichte / 1000.

Typische Fehlermeldungen

Mit Klassen kommen neue Fehlermeldungen. Diese sechs siehst du garantiert. Jedes Beispiel lässt sich ausführen: Schau dir die echte Meldung an und lies sie von unten nach oben (zuerst die letzte Zeile).

TypeError: self fehlt in der Methode

Meldung: TypeError: Welle.volumen() takes 0 positional arguments but 1 was given (bei älteren Python-Versionen ohne den Klassennamen). Du hast volumen() ohne Argument aufgerufen, aber Python übergibt das Objekt heimlich als erstes Argument. In der Definition fehlt der Parameter dafür. Lösung: def volumen(self):. Das Gleiche passiert in __init__, wenn self fehlt.

TypeError: zu wenige Argumente beim Erzeugen

Meldung: TypeError: Welle.__init__() missing 1 required positional argument: 'l'. Welle(20) ruft __init__ auf, und das erwartet außer self noch d und l. Zähle die Parameter ohne self und vergleiche mit deinem Aufruf. Die Meldung nennt sogar, welcher Parameter fehlt.

AttributeError: Attribut gibt es nicht

Meldung: AttributeError: 'Welle' object has no attribute 'laenge'. Das Objekt hat ein Attribut l, aber keins namens laenge. Typische Ursachen: Tippfehler, anderer Name als im __init__, oder das Attribut wurde dort nie mit self.… gespeichert. Mit print(w.__dict__) siehst du alle Attribute eines Objekts.

NameError: d statt self.d

Meldung: NameError: name 'd' is not defined. In der Methode gibt es kein d; das Maß gehört dem Objekt und heißt self.d. Das Muster: In Methoden stehen Maße immer mit self. davor.

Klammern vergessen: <bound method …>

Ausgabe: <bound method Welle.volumen of <__main__.Welle object at 0x…>>. Das ist keine Fehlermeldung, sondern das Methodenobjekt selbst. Ohne runde Klammern wird die Methode nicht ausgeführt, nur genannt. Erscheint in der Ausgabe so ein „bound method“, fehlen die Klammern beim Aufruf. Bei Attributen ist es umgekehrt: w.d hat keine Klammern.

ValueError aus bauteil3d: ungültige Maße

Meldung: ValueError: Die Bohrungen liegen nicht zwischen Innen- und Außenrand. Das Modul prüft die Maße selbst und bricht mit einer verständlichen Meldung ab, bevor ein kaputtes Bauteil entsteht. Mit der Methode ist_gueltig() aus dem Beispiel fragst du vorher ab, statt den Fehler zu riskieren. In V18 hast du gesehen, wie du so einen ValueError mit try und except abfängst.

Schreibe die Klasse Feder. Der Konstruktor speichert die Federrate c in N/mm. Die Methode kraft(s) gibt die Federkraft F = c · s in N zurück, wobei s der Federweg in mm ist. Die Methode gibt zurück, sie druckt nichts.

Erwartet
Feder(12.5).kraft(8)   -> 100.0   (12,5 N/mm · 8 mm = 100 N)
Feder(3).kraft(0)      -> 0
  1. Im __init__ genügt eine Zeile: self.c = c.
  2. In kraft brauchst du die Rate des Objekts: self.c. Der Federweg s ist der Parameter der Methode.
  3. return self.c * s

Rohr: Gültigkeit, Volumen, Masse

Schreibe die Klasse Rohr(d_aussen, d_innen, l) (alle Maße in mm). Die Methode ist_gueltig() gibt True zurück, wenn 0 < d_innen < d_aussen und l > 0 gilt, sonst False. volumen() gibt das Volumen des Hohlzylinders in mm³ zurück (π/4 · (D² − d²) · l). masse(dichte=7.85) gibt die Masse in kg zurück (Dichte in g/cm³).

Erwartet
r = Rohr(40, 30, 1000)
r.ist_gueltig()   -> True
r.volumen()       -> 549778.7... (mm³)
r.masse()         -> 4.3157... (kg, Stahl)
Rohr(30, 40, 100).ist_gueltig()   -> False
  1. Im __init__ speicherst du alle drei Maße: self.d_aussen = d_aussen und so weiter.
  2. ist_gueltig: return 0 < self.d_innen < self.d_aussen and self.l > 0. Python erlaubt die Kette 0 < a < b (V04).
  3. masse ruft self.volumen() auf; mm³ geteilt durch 1000 ergibt cm³, mal dichte ergibt g, geteilt durch 1000 ergibt kg.

Werkzeug: Standzeit verbrauchen

Ein Fräser hat eine Standzeit, nach der er verschlissen ist. Schreibe die Klasse Werkzeug(standzeit_min). Sie speichert die Standzeit als Attribut standzeit_min und die Reststandzeit als Attribut rest_min (zu Beginn gleich der Standzeit). Die Methode benutze(minuten) verringert rest_min um die Minuten, aber nie unter 0, und gibt nichts zurück. ist_verschlissen() gibt True zurück, sobald rest_min gleich 0 ist.

Erwartet
w = Werkzeug(60)
w.benutze(45)
w.rest_min              -> 15
w.ist_verschlissen()    -> False
w.benutze(20)
w.rest_min              -> 0      (nicht -5)
w.ist_verschlissen()    -> True
  1. Im __init__ gibt es zwei Attribute: self.standzeit_min = standzeit_min und self.rest_min = standzeit_min.
  2. benutze: self.rest_min = self.rest_min - minuten. Danach: Wenn self.rest_min < 0 ist, setze es auf 0.
  3. ist_verschlissen: return self.rest_min == 0 (zwei Gleichheitszeichen vergleichen, V04).

Flansch-Baureihe: leichteste gültige Variante

Die Klasse Flansch aus dem Beispiel steht schon da (ohne mesh). Die Baureihe ist eine Liste von Flansch-Objekten, eines davon hat falsche Maße. Schreibe zwei Funktionen: anzahl_ungueltig(liste) gibt zurück, wie viele Flansche der Liste nicht gültig sind. leichtester_gueltiger(liste) gibt das Objekt mit der kleinsten Masse unter allen gültigen Flanschen zurück, oder None, wenn kein Flansch gültig ist. Die Liste darf nicht verändert werden.

Erwartet
anzahl_ungueltig(baureihe)          -> 1
leichtester_gueltiger(baureihe)     -> das Flansch-Objekt mit 0.38 kg (kleinster d_aussen)
leichtester_gueltiger([])           -> None
  1. anzahl_ungueltig: Zähler auf 0, Schleife for f in liste:, dann if not f.ist_gueltig(): erhöht den Zähler. Die Methode braucht Klammern.
  2. leichtester_gueltiger: Merke dir das bisher leichteste Objekt in einer Variable, die mit None startet. Das ist wie die Suche nach dem Maximum in V06, nur mit Objekten.
  3. Ein Objekt ersetzt das bisher beste, wenn es gültig ist und (beste is None oder f.masse() < beste.masse()). Am Ende return beste.

Stufenwelle mit 3D-Vorschau

Eine gestufte Welle besteht aus Absätzen, jeder mit Durchmesser und Länge in mm. Schreibe die Klasse Stufenwelle(absaetze); absaetze ist eine Liste von (d, l)-Tupeln, von unten nach oben, gespeichert als Attribut absaetze. gesamtlaenge() gibt die Summe der Längen zurück (mm). volumen() gibt das Volumen in mm³ zurück, als Summe der Zylindervolumen π/4 · d² · l, ohne bauteil3d. mesh() gibt bauteil3d.welle(self.absaetze) zurück. Am Ende zeigt das Programm die Welle in 3D; die Tests prüfen die Zahlen und vergleichen dein Volumen mit dem des Dreiecksnetzes.

Erwartet
w = Stufenwelle([(30, 40), (20, 60), (25, 30)])
w.gesamtlaenge()   -> 130
w.volumen()        -> 61850.2... (mm³)
  1. self.absaetze = absaetze im __init__. Jeder Absatz ist ein Tupel: for d, l in self.absaetze: packt es in zwei Variablen aus (V08).
  2. gesamtlaenge: Summe von l über alle Absätze. volumen: Summe von math.pi / 4 * d ** 2 * l.
  3. mesh: return bauteil3d.welle(self.absaetze). Danach sollte unter der Ausgabe die 3D-Vorschau erscheinen.

Wiederholung: Teileliste aus Text einlesen

Hier wiederholst du Altes: split, try/except und Funktionen, ganz ohne Klassen. Eine Stückliste liegt als Text vor, eine Zeile je Teil: name;masse_kg, die Masse mit Dezimalkomma oder Dezimalpunkt. Schreibe lese_teile(text): Die Funktion gibt eine Liste von Tupeln (name, masse) zurück (Masse als float). Zeilen, die nicht passen (leer, keine zwei Felder, Masse keine Zahl, zum Beispiel die Kopfzeile), werden übersprungen, ohne dass das Programm abbricht. Dazu gesamtmasse(teile): Summe der Massen in kg.

Erwartet
lese_teile("name;masse_kg\nWelle;2,5\nkaputt\nFlansch;1.12")
    -> [("Welle", 2.5), ("Flansch", 1.12)]
gesamtmasse([("Welle", 2.5), ("Flansch", 1.12)])   -> 3.62
  1. text.splitlines() gibt die Zeilen als Liste. Jede Zeile mit zeile.split(";") in Felder zerlegen; sind es nicht genau zwei, gehst du mit continue zur nächsten Zeile.
  2. Die Masse: float(felder[1].strip().replace(",", ".")) in einem try. Bei except ValueError: überspringst du die Zeile (V09 und V18: gezielt abfangen, nie ein leeres except).
  3. Am Ende teile.append((name, masse)) mit doppelten Klammern: ein Tupel in der Liste.

Auflösung aufdecken und ausführen

Ausgabe: 15 30 Tank. Es gibt zwei Objekte (Tank und Fass) und drei Namen (a, b, c); b = a kopiert nicht, b.fuellen(5) ändert das Objekt, auf das auch a zeigt: 10 + 5 = 15. c.fuellen(10) gibt 20 + 10 = 30 zurück. Eigenes Bauteil: Distanzhülse und Baugruppe

Entwirf ein eigenes parametrisches Bauteil. Schreibe die Klasse Distanzhuelse(d_aussen, d_innen, l) (Maße in mm, als Attribute gespeichert) mit volumen() (mm³, analytisch: π/4 · (D² − d²) · l) und mesh() (bauteil3d.ring(...)). Dazu die Funktion baugruppe(huelsen): Sie stapelt die Hülsen einer Liste in z-Richtung direkt aufeinander (die erste bei z = 0, jede weitere beginnt dort, wo die vorherige endet), indem sie jedes Netz mit bauteil3d.verschiebe an seine Stelle setzt und alle mit bauteil3d.vereinige zu einem Netz zusammenfügt, und gibt das Netz zurück. Am Ende zeigst du die Baugruppe an. Die Tests vergleichen das Volumen des Netzes mit der analytischen Summe (bei Dreiecksnetzen bis etwa 1 % Abweichung) und prüfen die Höhe.

Erwartet
hs = [Distanzhuelse(30, 20, 10), Distanzhuelse(30, 20, 15), Distanzhuelse(30, 20, 5)]
bauteil3d.abmessungen(baugruppe(hs))   -> (30.0, 30.0, 30.0)
  1. __init__ speichert drei Attribute. mesh: return bauteil3d.ring(self.d_aussen, self.d_innen, self.l).
  2. In baugruppe: Starte mit z = 0 und einer leeren Liste. In der Schleife über die Hülsen verschiebst du jedes Netz: bauteil3d.verschiebe(h.mesh(), dz=z), hängst es an die Liste an und erhöhst z um h.l.
  3. Am Ende bauteil3d.vereinige(*teile) (der Stern entpackt die Liste in einzelne Argumente) oder bauteil3d.vereinige(teile); die Funktion akzeptiert auch eine Liste.
