Werkzeugkasten

Heute neu in Python: Kommazahlen (float), Datentypen erkennen und umwandeln, Zahlen einlesen, formatiert ausgeben und das math-Modul. Aus V01 und V02 setzen wir print, Variablen, int und die Operatoren + - * / // % ** voraus. Die Klausur verlangt, dass du Code von Hand schreibst. Darum gehen wir in kleinen Schritten vom Vormachen zum Selberschreiben, und die Hilfen werden dabei weniger.

Merke

Diese fünf Syntax-Karten sind dein Spickzettel, bis es sitzt. Du erreichst sie in jeder Aufgabe über den Knopf „Werkzeugkasten“ oben. Alle Befehle des Kurses stehen außerdem rechts in der Befehls-Bibliothek.

Syntax-Karte 1

Zahlen und Typen

x = 3          # int
y = 2.5        # float
z = 1e-3       # float, 0.001
t = "42"       # str (Text)
print(x, y, z, t)
type(y)        # <class 'float'>
7 / 2          # 3.5, immer float
7 // 2         # 3, int
  • Dezimalpunkt, nie Komma: 2.5.
  • 1e-3 heißt 1 · 10−3.
  • 7 / 2 ist immer float (3.5), 7 // 2 ist int (3).
  • int und float gemischt: das Ergebnis ist float.
  • type(y) ist eine Funktion: Du gibst ihr einen Wert in die Klammern, sie antwortet mit dem Typ.
Syntax-Karte 2

Typ umwandeln

int("42")     # 42
float("3.5")  # 3.5
float(2)      # 2.0
str(3)        # '3'
int(3.9)      # 3 (schneidet ab)
round(3.9)    # 4 (rundet)
  • Drück auf „Schritt für Schritt“: Du siehst jede Umwandlung einzeln und welchen Typ das Ergebnis hat.
  • int() schneidet ab, round() rundet.
  • int("2.5") geht nicht (ValueError, siehe „Typische Fehlermeldungen“). Erst float, dann int.
  • Text und Zahl lassen sich nicht addieren: erst umwandeln.
Syntax-Karte 3

Zahl einlesen

d = float(input("Durchmesser in mm: "))
n = int(input("Anzahl: "))
print(d, n)
print(type(d), type(n))
  • Die Eingabefelder unter dem Code sind vorbelegt, probier andere Werte.
  • input() liefert immer Text. Sofort umwandeln.
  • Eingabe mit Dezimalkomma („2,5“) bricht mit ValueError ab: Tippe den Punkt. Text zurechtschneiden lernst du in V09.
Syntax-Karte 4

f-String und Format

d = 12.3456
print(f"d = {d} mm")
print(f"d = {d:.2f} mm")
print(f"{d:8.3f}|")
print(f"{12345.6:e}")
:.2f2 Nachkommastellen (gerundet)
:8.3fmindestens 8 Zeichen breit, 3 Nachkommastellen, rechtsbündig
:ewissenschaftlich: 1.234560e+04
:.2ewissenschaftlich, 2 Nachkommastellen: 1.23e+04

Das Format ändert nur die Anzeige, nicht den Wert in der Variable.

Syntax-Karte 5

math-Modul und isclose

import math
math.pi        # 3.141592653589793
math.sqrt(2)   # 1.4142135623730951
math.isclose(0.1 + 0.2, 0.3, abs_tol=1e-9)   # True
  • import math steht ganz oben im Programm und holt das Modul math.
  • math.isclose vergleicht mit Toleranz. Gegen 0 brauchst du abs_tol.

Vorgerechnetes Beispiel: Toleranzrechner

Aufgabe: Ein Programm liest das Nennmaß, das Abmaß (±) und einen Messwert ein, gibt die Grenzmaße formatiert aus und prüft, ob der Messwert in der Toleranz liegt. Lies den Code Zeile für Zeile, dann führe ihn aus. Die Eingaben stehen im Feld darunter (Beispiel: der Messwert liegt genau auf der Grenze). Drück danach auf „Schritt für Schritt“: Dann siehst du, wie jede Zeile eine Variable belegt und welchen Typ sie hat.

  1. Zeilen 4 bis 6: input() gibt Text zurück, float() macht daraus eine Zahl. Ohne float() würde nennmass - abmass mit einem TypeError abbrechen.
  2. Zeile 13: :.2f zeigt zwei Nachkommastellen. Die Variablen selbst bleiben unverändert.
  3. Zeile 16: math.isclose mit rel_tol=0.0 und abs_tol prüft, ob der Abstand höchstens abmass beträgt. Das + 1e-9 fängt den Rundungsfehler ab: 25.05 - 25.0 ergibt 0.05000000000000071, also knapp mehr als 0.05. Ohne den Zuschlag würde der Grenzwert fälschlich durchfallen. Probiere es aus: Lösche + 1e-9 und führe nochmal aus.
  4. Selbsterklärung: Setze den Messwert auf 25.06. Was erwartest du? Warum ist das Ergebnis jetzt anders?

Ablauf verfolgen

Bevor du Code schreibst, musst du ihn lesen können. Jede Variable hat zu jedem Zeitpunkt einen Wert. Führe das Programm im Kopf aus: Eine Zeile nach der anderen. Trage ein, was danach in den hervorgehobenen Variablen steht. Achte auf den Typ: Text (String) steht in Anführungszeichen, ein float hat einen Dezimalpunkt. Wenn du unsicher bist, lass den Code vorher einmal im „Vorgerechneten Beispiel“ mit „Schritt für Schritt“ laufen.

Zeilen ordnen

Alle Zeilen sind da, aber durcheinander. Bring sie in die richtige Reihenfolge. Manche Zeilen sind Ablenker: Sie gehören nicht ins Programm.

Grenzmaße ausgeben

Das Programm liest Nennmaß und Abmaß in mm ein und gibt die beiden Grenzmaße mit zwei Nachkommastellen aus.

Summe mit Toleranz prüfen

Das Programm addiert 0.1 und 0.2 und prüft mit math.isclose, ob die Summe 0.3 ergibt.

Lücken füllen

Jetzt tippst du Teile selbst. Ergänze die vier Lücken, sodass das Programm eine Länge von mm in Zoll (inch) umrechnet und mit drei Nachkommastellen ausgibt. 1 Zoll = 25,4 mm. Geprüft wird nicht nur dein Wortlaut, sondern ob das Programm das Richtige tut.

mm = @@float@@(input("Länge in mm: "))
zoll = mm / @@25.4@@
print(f"{mm:.1f} mm = {zoll:@@.3f@@} Zoll")
print(type(@@zoll@@))
  1. Das Ergebnis einer Division mit / hat immer denselben Typ (probiere type(7 / 2)). Welchen? Und in welchen Typ wandelst du die Eingabe um, damit :.1f funktioniert?
  2. Das Format steht hinter dem Doppelpunkt im f-String: drei Nachkommastellen heißen .3f.
  3. Lücke 4: Welche Variable willst du auf ihren Typ prüfen?

Erste eigene Aufgabe: Zugstab

Jetzt schreibst du alles selbst, mit Tests als Sicherheitsnetz. Die Tests laufen mit mehreren Eingaben, auch mit solchen, die du nicht siehst.

Ein Rundstab wird mit der Kraft F (in N) auf Zug belastet. Der Durchmesser d (in mm) ist gegeben. Schreibe ein Programm, das beide Werte einliest und die Spannung σ = F / A in N/mm² ausgibt. Die Querschnittsfläche ist A = π · d² / 4.

Ausgabe genau so:
Spannung: 254.65 N/mm²

Beispiel: F = 20000, d = 10. Zwei Nachkommastellen. Erst F, dann d einlesen.

  1. Zuerst beide Werte einlesen und mit float() umwandeln (Syntax-Karte 3).
  2. Die Fläche: A = math.pi * d ** 2 / 4. Vergiss import math am Anfang nicht (Syntax-Karte 5).
  3. Ausgabe: print(f"Spannung: {sigma:.2f} N/mm²") mit deinem Variablennamen (Syntax-Karte 4).

Code-Review: KI-Code prüfen

Eine KI hat Code geliefert. Er sieht sauber aus und läuft los. Würdest du ihn freigeben? Klick die Zeilen an, die du für fehlerhaft hältst, dann lass auflösen.

Szenario: Prüfprogramm für ein Wellenmaß

Prompt eines Studierenden

Schreib mir ein kleines Python-Programm für ein Prüfprogramm. (1) Liegt ein eingegebenes Maß innerhalb der Toleranz? Nennmaß 25,00 mm, Toleranz ±0,05 mm; die Grenzwerte 24,95 und 25,05 sind noch in Ordnung. (2) Trifft der Mittelwert der fünf Messwerte 24,92 / 24,99 / 25,02 / 25,02 / 25,05 das Nennmaß? (3) Teile eine Messstrecke von 1 mm in n gleiche Abschnitte (n wird eingegeben) und gib die Schrittweite aus.

KI-Antwort (Python)

Tipp: Es sind drei Fehler eingebaut, einer je Teilaufgabe. Nicht jede Zeile ist falsch.

Würdest du das freigeben? Markiere die fehlerhaften Zeilen, dann lass auflösen.

Die drei Fehler

Fehler 1: Grenzwert fällt durch (Zeile 6)

Der Vergleich <= sieht richtig aus, die Grenze gehört ja dazu. Aber abs(25.05 - 25.0) ist 0.05000000000000071, also knapp mehr als 0.05: Der Messwert 25,05 fällt fälschlich durch. An der Grenze entscheiden Rundungsfehler. Lösung: math.isclose mit abs_tol plus winziger Rechentoleranz.

Fehler 2: Gleichheit bei Floats (Zeile 10)

Der Mittelwert der fünf Werte ist mathematisch genau 25.0. Der Rechner liefert aber 24.999999999999996, der ==-Vergleich ist False. Lösung: math.isclose mit passender Toleranz.

Fehler 3: Text statt Zahl (Zeile 13)

input() liefert Text. 1.0 / anzahl teilt eine Zahl durch einen Text und bricht mit einem TypeError ab. Lösung: anzahl = int(input(...)). Dieser Fehler ist der gemeinste: Er zeigt sich erst, wenn jemand etwas eintippt.

Die KI-Version zum Ausprobieren

Die ersten beiden Ausgaben sind falsch. Danach bricht das Programm mit dem TypeError ab. Die Eingaben (25.05 und 10) stehen im Feld unter dem Code. Drück auf „Schritt für Schritt“, um jede Zeile einzeln zu sehen.

import math

nennmass = 25.0
toleranz = 0.05
messwert = float(input("Messwert in mm: "))
in_toleranz = abs(messwert - nennmass) <= toleranz
print("In Toleranz:", in_toleranz)

mittelwert = (24.92 + 24.99 + 25.02 + 25.02 + 25.05) / 5
print("Mittelwert trifft Nennmaß:", mittelwert == nennmass)

anzahl = input("Wie viele Abschnitte? ")
schrittweite = 1.0 / anzahl
print(f"Schrittweite: {schrittweite:.3f} mm")

Korrigierte Version

import math

EPS = 1e-9   # Rechentoleranz, weit unter jeder Messauflösung

nennmass = 25.0
toleranz = 0.05
messwert = float(input("Messwert in mm: "))
in_toleranz = math.isclose(messwert, nennmass, rel_tol=0.0, abs_tol=toleranz + EPS)
print("In Toleranz:", in_toleranz)

mittelwert = (24.92 + 24.99 + 25.02 + 25.02 + 25.05) / 5
print("Mittelwert trifft Nennmaß:", math.isclose(mittelwert, nennmass, abs_tol=EPS))

anzahl = int(input("Wie viele Abschnitte? "))
schrittweite = 1.0 / anzahl
print(f"Schrittweite: {schrittweite:.3f} mm")
Merke

Die KI hat nicht „falsch gedacht“, sie hat das Muster geliefert, das am häufigsten vorkommt. Ob Grenzwerte dazugehören und wie genau „gleich“ sein muss, steht nur in deiner Spezifikation. Und deine Testfälle (Grenzwerte!) hättest du vorher von Hand aufschreiben sollen.

Typische Fehlermeldungen

Fehlermeldungen sind keine Strafe, sondern ein Wegweiser. Diese drei siehst du heute garantiert. Jedes Beispiel lässt sich ausführen: Schau dir die echte Meldung an und lies sie von unten nach oben (zuerst die letzte Zeile).

TypeError: Text plus Zahl

Meldung: TypeError: can only concatenate str (not "int") to str. Gemeint: "3" ist Text, 4 ist eine Zahl. Entweder int("3") + 4 oder "3" + str(4). Tritt meistens auf, wenn du das float() um ein input() vergessen hast (Typumwandlung).

ValueError: Text lässt sich nicht umwandeln

Meldung: ValueError: invalid literal for int() with base 10: '2.5'. int() versteht nur ganze Zahlen im Text. Nimm float("2.5"), oder int(float("2.5")), wenn du abschneiden willst. Ähnlich bei einem Dezimalkomma im Text: float("2,5") meldet could not convert string to float: '2,5'.

SyntaxError: Komma als Dezimaltrenner

Meldung: SyntaxError: leading zeros in decimal integer literals are not permitted; use an 0o prefix for octal integers. Python liest 0,05 als zwei Zahlen getrennt durch ein Komma und stolpert über die führende Null. Heimtückisch: abmass = 2,5 läuft ohne Fehler, macht aber aus 2,5 ein Paar (2, 5) (ein Tupel). Dezimalzahlen schreibst du immer mit Punkt.

Sekunden in Stunden, Minuten, Sekunden

Programmieren lernst du mit den Fingern, nicht mit den Augen. Das Training ist ein fester Teil jedes Termins und gehört zum Selbststudium. Du musst nicht alles an einem Stück machen, aber alles bis zum nächsten Termin. Die Aufgaben laufen komplett im Browser und werden automatisch geprüft.

Achtung

Phase 1: Copilot nur als Erklärer. Erlaubt: „Erkläre mir diese Fehlermeldung“, „Was macht Zeile 3?“, „Warum ist das Ergebnis nicht 0.3?“. Nicht erlaubt: „Schreib mir die Funktion“. Du tippst den Code selbst, denn nur dann lernst du, ihn zu prüfen. Ab V10 darf die KI Code erzeugen, und du prüfst.

Ein Messprogramm liefert die Laufzeit als ganze Sekunden. Zerlege sie mit // und % in Stunden, Minuten und Sekunden.

Ausgabe genau so (Beispiel 3725 Sekunden):
1 h 2 min 5 s
  1. Wie oft passen 3600 Sekunden in sekunden? Das ist die ganzzahlige Division //.
  2. Was nach den vollen Stunden übrig bleibt, liefert %: rest = sekunden % 3600.
  3. Wiederhole das Spiel mit dem Rest und 60: minuten = rest // 60, sek = rest % 60.

Text in Zahlen umwandeln

Aus einer Datei kommen Länge und Stückzahl als Text. Wandle um: laenge soll ein float sein, anzahl ein int. None in der Vorgabe ersetzt du jeweils durch deinen Ausdruck. Prüfe mit „Schritt für Schritt“, welchen Typ jede Variable hat. gesamt ist Länge mal Anzahl. Gib die Gesamtlänge mit einer Nachkommastelle aus.

Ausgabe genau so:
Gesamtlänge: 502.0 mm
  1. Text in Kommazahl: float(...). Text in Ganzzahl: int(...). Der Text kommt in die Klammer.
  2. gesamt = laenge * anzahl. Welchen Typ hat float mal int?
  3. print(f"Gesamtlänge: {gesamt:.1f} mm")

Tabellenzeile mm und Zoll

Gib eine Tabellenzeile aus: links die Länge in mm (Breite 8, zwei Nachkommastellen), dann | , rechts die Länge in Zoll (Breite 8, drei Nachkommastellen). 1 Zoll = 25,4 mm. Die Kopfzeile steht schon da, die Länge in mm liest das Programm ein. Eine ganze Tabelle mit vielen Zeilen baust du in V06 mit einer Schleife.

Ausgabe genau so (Eingabe 5):
      mm |     Zoll
    5.00 |    0.197
  1. Rechne zuerst den Zollwert aus: zoll = mm / 25.4.
  2. Ein f-String kann mehrere Platzhalter haben: f"{a:8.2f} | {b:8.3f}" (Syntax-Karte 4).
  3. Das Muster ist print(f"{mm:8.2f} | {zoll:8.3f}"). Die Breite 8 sorgt dafür, dass mehrere Zeilen rechtsbündig untereinander stehen würden.

Volumen und Masse einer Welle

Eine Welle (Vollzylinder) hat den Durchmesser d in mm und die Länge L in mm; die Dichte ρ ist in g/cm³ gegeben (Stahl: 7,85). Lies d, L und ρ in dieser Reihenfolge ein. Berechne das Volumen in cm³ (V = π · d² / 4 · L, dann mm³ in cm³ umrechnen: 1 cm³ = 1000 mm³) und die Masse in kg (g in kg: durch 1000).

Ausgabe genau so (d = 40, L = 250, ρ = 7.85):
Volumen: 314.16 cm³
Masse: 2.466 kg

Überschlage vorher: Fläche ca. 1250 mm², mal 250 mm gibt ca. 310 000 mm³, das sind ca. 310 cm³. Passt dein Ergebnis zur Größenordnung?

  1. Drei Eingaben, alle mit float(input(...)). Reihenfolge: d, L, ρ.
  2. Volumen in mm³: math.pi * d ** 2 / 4 * laenge. Durch 1000 teilen ergibt cm³.
  3. Masse in g ist Volumen in cm³ mal Dichte in g/cm³. Durch 1000 teilen ergibt kg. Dann zwei print mit :.2f und :.3f.

Toleranzprüfung mit Grenzfällen

Schreibe ein Programm, das den Messwert, das Nennmaß und das Abmaß (in dieser Reihenfolge) einliest und ausgibt, ob der Messwert im Bereich nennmass ± abmass liegt. Die Grenzen gehören dazu: 25,05 bei 25,00 ± 0,05 ist in Ordnung. Denk an die Rundungsfehler (25.05 - 25.0 ist 0.05000000000000071) und nutze math.isclose oder eine kleine Rechentoleranz. Die Vorgabe liest schon alles ein, du ersetzt nur das None.

Ausgabe genau so (Beispiel 25.05, 25.0, 0.05):
In Toleranz: True
  1. Der Messwert liegt in der Toleranz, wenn sein Abstand zum Nennmaß höchstens abmass beträgt: abs(messwert - nennmass) <= abmass. Das schlägt an der Grenze durch Rundungsfehler trotzdem fehl.
  2. math.isclose(a, b, rel_tol=0.0, abs_tol=...) vergleicht den Abstand mit einer absoluten Toleranz. Welche absolute Toleranz brauchst du?
  3. Nimm abs_tol=abmass + 1e-9. Der Zuschlag 1e-9 mm ist die Rechentoleranz, viel kleiner als jede Messauflösung.

Kaufmännisch runden statt round()

Pythons round(2.5) ergibt 2 (Banker's Rounding). Kaufmännisch gilt: Die Hälfte wird immer aufgerundet, also 2,5 → 3. Schreibe ein Programm, das eine positive Kommazahl einliest und zwei Zeilen ausgibt: erst das Ergebnis von round(), dann die kaufmännisch gerundete Zahl. Tipp: int() schneidet ab. Was ergibt int(x + 0.5)? Probiere es mit „Schritt für Schritt“ für 2.5 und 2.4 aus.

Ausgabe genau so (Eingabe 2.5):
round(): 2
kaufmännisch: 3

Für negative Zahlen, beliebige Nachkommastellen und exaktes Dezimalrechnen braucht man mehr (Verzweigungen ab V04, eigene Funktionen ab V07, das Modul decimal im Deep Dive der Lerneinheit).

  1. Erste Zeile: print(f"round(): {round(x)}").
  2. int() schneidet ab. Addierst du vorher 0.5, wird aus 2.5 die Zahl 3.0, und int(3.0) ist 3. Aus 2.4 wird 2.9, und int(2.9) ist 2.
  3. Zweite Zeile: print(f"kaufmännisch: {int(x + 0.5)}").

Knobelaufgabe: Der Zähler, der stehen bleibt

Die Portalachse aus der Lektion zählt mit einem 32-Bit-Float und bleibt bei 224 stehen. Python-Floats haben 64 Bit, dort passiert dasselbe erst bei 253 = 9 007 199 254 740 992. Eine Ganzzahl (int) kennt diese Grenze nicht. Sieh, was passiert, wenn du die Ganzzahl gewollt = 2 ** 53 + 1 in einen float steckst und wieder zurückholst: Wandle gewollt in einen float um (gespeichert), dann gespeichert zurück in einen int (zurueck) und berechne fehler als gewollt - zurueck. Gib den Fehler aus.

Die Ausgabe enthält:
Fehler: 1
  1. Umwandeln in eine Kommazahl: float(...). Zurück in eine Ganzzahl: int(...).
  2. gespeichert = float(gewollt), zurueck = int(gespeichert).
  3. fehler = gewollt - zurueck, dann print(f"Fehler: {fehler}"). Mit „Schritt für Schritt“ siehst du, wo die letzte Stelle verloren geht.

Klausur-Modus: Zugversuch

So wie in der Klausur: Schreibe den Code ohne Ausführen und ohne Auto-Vervollständigung, wenn möglich zuerst auf Papier. Erst danach „Abgeben und prüfen“, dann bewertest du dich selbst.

Bei einem Zugversuch an einem Rundstab werden nacheinander eingelesen: Kraft F in N, Durchmesser d in mm, Messlänge L0 in mm und Verlängerung ΔL in mm. Berechne und gib aus:

  • die Spannung σ = F / A in N/mm² mit A = π · d² / 4 (2 Nachkommastellen),
  • die Dehnung ε = ΔL / L0 in Prozent (3 Nachkommastellen),
  • den E-Modul E = σ / ε mit ε als Verhältnis (nicht in Prozent), in N/mm² in wissenschaftlicher Schreibweise mit 2 Nachkommastellen.
Ausgabe genau so (F = 20000, d = 10, L0 = 100, ΔL = 0.121):
Spannung: 254.65 N/mm²
Dehnung: 0.121 %
E-Modul: 2.10e+05 N/mm²
