V20 · Phase 3 Projekt · Lerneinheit

Objekte & CAD-Automatisierung

Ein Bauteil besteht aus Maßen und aus Regeln, was mit diesen Maßen geschieht. Eine Klasse fasst beides zusammen, und aus ihr entsteht jede Variante mit einer Zeile. So arbeiten CAD-Programme, und so lassen sie sich per Skript steuern.

Nach dieser Lerneinheit kannst du:

  • den Unterschied zwischen Klasse (Bauplan) und Objekt (konkretes Teil) erklären,
  • eine Klasse mit __init__, Attributen und Methoden lesen und eine einfache selbst schreiben,
  • ein Objekt erzeugen, ein Attribut lesen und ändern und eine Methode aufrufen (mit Klammern),
  • vorhersagen, was passiert, wenn zwei Namen auf dasselbe Objekt zeigen,
  • erklären, was self in einer Methode ist,
  • beschreiben, wie ein Skript ein parametrisches Bauteil erzeugt, prüft und als 3D-Netz (STL) exportiert.

Das Schreiben übst du im Programmierlabor. Vorausgesetzt sind V01 bis V19, besonders Funktionen mit Default-Werten (V07), Listen und Referenzen (V08) und Module (V10). Das Projekt läuft parallel weiter: Die Meilensteine stehen auf der Projektseite.

1 Warum?

Ein Kunde bestellt eine Baureihe von Flanschen für sechs Rohrnennweiten. Jede Variante hat andere Durchmesser, eine andere Zahl von Bohrungen und einen anderen Lochkreis. Von Hand im CAD gezeichnet kostet jede Variante Stunden, und ein Tippfehler im Lochkreis fällt erst auf, wenn die Bohrung über den Rand ragt. Im CAD ist ein Bauteil eigentlich ein Satz Parameter plus Regeln: ein parametrisches Modell. Schreibst du dieses Modell als Klasse, erzeugst du jede Variante mit einer Zeile, prüfst die Maße automatisch und exportierst das Ergebnis als 3D-Datei. KI kann dir solche Skripte schreiben. Du musst die Klasse lesen und ihre Regeln prüfen können.

Selbst sehen: Passt die Bohrung noch?

Sag erst voraus. Im Abschnitt Theorie verstellst du die Maße danach selbst.

Ein Flansch hat 120 mm Außendurchmesser. Die Bohrungen (Ø 14 mm) sitzen auf einem Lochkreis mit 110 mm Durchmesser. Passen sie noch auf die Scheibe?

Die Mitte der Bohrung liegt bei 110 / 2 = 55 mm vom Zentrum, ihr Rand bei 55 + 14 / 2 = 62 mm. Die Scheibe endet aber bei 120 / 2 = 60 mm: Die Bohrung ragt 2 mm über den Rand. Genau diese Prüfung steckt später als Methode ist_gueltig() in der Klasse.

  • Lesen & erkennen__str__ und __repr__, Vererbung (class Normflansch(Flansch)), @dataclass, Typ-Hinweise in Klassen. Und dass str, list und dict selbst Klassen sind: Du benutzt Objekte seit V01.
  • DelegierenCAD-Schnittstellen (die Python-Konsole von FreeCAD, CadQuery), das STL-Dateiformat im Detail und Algorithmen für Dreiecksnetze (das erledigt bauteil3d.py). Du musst wissen, dass es sie gibt und wofür, und KI-Code dazu prüfen können.
Warum muss ich das wissen?

Als Ingenieur arbeitest du mit Bauteilfamilien, Stücklisten und Maschinen, die jeweils aus Maßen und Verhalten bestehen. Fast jede Programmierschnittstelle in CAD, Simulation und Messtechnik ist objektorientiert: Du erzeugst ein Objekt, setzt Attribute und rufst Methoden auf. Und wenn die KI dir ein Skript für eine Bauteilreihe schreibt, entscheidest du, ob die Klasse stimmt: Sind die Einheiten richtig, wird jedes Maß als Attribut gespeichert, ist die Gültigkeitsprüfung vollständig?

2 Theorie

Erklärvideo (ca. 3 Min)

Daten und Verhalten gehören zusammen

Bisher hast du Maße in einzelnen Variablen gehalten und Rechnungen in Funktionen verpackt. Für einen Flansch sähe das so aus: d_aussen, d_innen, dicke und weitere Variablen, dazu eine Funktion flansch_masse(d_aussen, d_innen, dicke, lochkreis, n, d_bohrung) mit sechs Parametern. Das geht, hat aber zwei Schwächen. Bei zwei Flanschen brauchst du zwei Sätze Variablen mit Namen wie d_aussen_1 und d_aussen_2. Und beim Aufruf vertauscht man sechs Zahlen leicht, ohne dass Python etwas merkt.

Eine Klasse bündelt beides. Die Maße eines Teils heißen Attribute, die Rechnungen mit diesen Maßen heißen Methoden. Die Klasse ist der Bauplan, ein Objekt ist ein konkretes Teil nach diesem Bauplan, so wie ein Normblatt viele gefertigte Teile beschreibt. Aus einer Klasse entstehen beliebig viele Objekte, jedes mit eigenen Maßen.

Du benutzt Objekte seit V01

Neu ist weniger, als es klingt: Text, Listen und Dictionaries sind selbst Klassen, und deine Werte sind Objekte davon. Wenn du "m10".upper() oder teile.append("Welle") schreibst, rufst du eine Methode auf. Probiere es aus:

print("m10".upper())

teile = []
teile.append("Welle")
teile.append("Flansch")
print(teile, len(teile))

print(type("M10"))
print(type(teile))

Das Muster ist immer objekt.methode(Argumente). Neu in dieser Lerneinheit ist, dass du eigene Klassen schreibst.

Eine kleine Klasse

Eine Klasse beginnt mit dem Schlüsselwort class und einem Namen, den man großschreibt. Darin stehen Methoden, die wie Funktionen mit def geschrieben werden (V07). Die erste, __init__, richtet ein neues Objekt ein. Jede Methode bekommt als ersten Parameter self: das Objekt, mit dem die Methode gerade arbeitet. Maße speicherst du als self.name, und genauso liest du sie wieder.

class Platte:
    def __init__(self, laenge, breite, dicke):
        self.laenge = laenge
        self.breite = breite
        self.dicke = dicke

    def volumen(self):
        return self.laenge * self.breite * self.dicke

    def masse(self, dichte=7.85):
        return self.volumen() / 1000 * dichte / 1000


p1 = Platte(200, 100, 10)
p2 = Platte(300, 150, 5)
print("p1:", p1.volumen(), "mm³,", round(p1.masse(), 2), "kg")
print("p2:", p2.volumen(), "mm³,", round(p2.masse(), 2), "kg")

p1.dicke = 20
print("p1 nach der Änderung:", round(p1.masse(), 2), "kg")
print("p2 unverändert:", round(p2.masse(), 2), "kg")
print("p1 aus Aluminium:", round(p1.masse(2.70), 2), "kg")

Klicke bei diesem Block auf „Schritt für Schritt“: Du siehst, wie p1 und p2 als Objekte mit je eigenen Attributen entstehen. Die Einheiten stimmen: Das Volumen kommt in mm³, durch 1000 sind es cm³, mal Dichte in g/cm³ sind es Gramm, durch 1000 sind es Kilogramm. Beachte auch: p1.volumen() hat keine Argumente, denn das Objekt p1 wird als self automatisch mitgegeben.

Bauplan und Teile

Links steht der Bauplan, rechts der Speicher. Erzeuge zwei Flansche (wähle vorher andere Maße), ändere f1.n, setze f2 = f1 und verfolge dann einen Methodenaufruf Schritt für Schritt. Achte darauf, worauf self zeigt.

Beobachtung: Jedes Objekt hat eigene Attribute. Ändert man f1.n, bleibt ein anderes Objekt unberührt, solange es wirklich ein anderes ist. Nach f2 = f1 gibt es nur noch ein Objekt mit zwei Namen, genau wie bei Listen in V08 (Aliasing). Und self ist immer das Objekt links vom Punkt.

Der parametrische Flansch

Jetzt die Klasse aus der Praxis. Der Flansch hat sechs Maße: Außendurchmesser, Innendurchmesser (Mittelloch), Dicke, Lochkreis, Zahl der Bohrungen und Bohrungsdurchmesser. Die Methode ist_gueltig() prüft zwei Regeln: Die Bohrung darf weder über den Rand ragen noch ins Mittelloch. volumen() rechnet Kreisring minus Bohrungen, masse() verrechnet die Einheiten. Verstelle die Maße und beobachte die Prüfung.

Parametrischer Flansch

Ändere ein Maß und schau, was sich ändert: die Zeichnung, die Prüfung ist_gueltig(), Volumen und Masse. Die vier Knöpfe unter „Maße“ laden Beispiele. „In 3D ansehen“ führt echten Python-Code aus und zeigt das Dreiecksnetz zum Drehen.

Beobachtung: Bei den Standardmaßen (120/40/15/90/6/11) kommt 142,2 cm³ und 1,12 kg heraus; mit acht Bohrungen sind es 1,09 kg. Ein Lochkreis von 110 mm mit Ø 14 mm Bohrung ist ungültig. Eine Gültigkeitsprüfung gehört in die Klasse, damit jede Variante sie automatisch durchläuft.

Hier die vollständige Klasse zum Ausführen. Sie ist dieselbe wie im Explorable, mit dem Hilfsmodul bauteil3d für das Dreiecksnetz. Ändere die Maße im letzten Block, auch f.n, und beobachte, wann ist_gueltig() False liefert.

import math
import bauteil3d


class Flansch:
    """Kreisförmiger Flansch mit Mittelloch und Bohrungen auf einem Lochkreis (Maße in mm)."""

    def __init__(self, d_aussen, d_innen, dicke, lochkreis, n, d_bohrung):
        self.d_aussen = d_aussen
        self.d_innen = d_innen
        self.dicke = dicke
        self.lochkreis = lochkreis
        self.n = n
        self.d_bohrung = d_bohrung

    def ist_gueltig(self):
        """Bohrungen dürfen weder ins Mittelloch noch über den Rand ragen."""
        rand_aussen = (self.lochkreis + self.d_bohrung) / 2 < self.d_aussen / 2
        rand_innen = (self.lochkreis - self.d_bohrung) / 2 > self.d_innen / 2
        return rand_aussen and rand_innen

    def volumen(self):
        """Volumen in mm³ (Kreisring minus Bohrungen)."""
        ring = math.pi / 4 * (self.d_aussen ** 2 - self.d_innen ** 2) * self.dicke
        bohrungen = self.n * math.pi / 4 * self.d_bohrung ** 2 * self.dicke
        return ring - bohrungen

    def masse(self, dichte=7.85):
        """Masse in kg, Dichte in g/cm³ (Standard: Stahl)."""
        return self.volumen() / 1000 * dichte / 1000

    def mesh(self):
        return bauteil3d.flansch(self.d_aussen, self.d_innen, self.dicke,
                                 self.lochkreis, self.n, self.d_bohrung)


f = Flansch(120, 40, 15, 90, 6, 11)
print("Gültig:", f.ist_gueltig())
print(f"Volumen: {f.volumen() / 1000:.1f} cm³, Masse: {f.masse():.2f} kg")
bauteil3d.zeige(f.mesh(), "Flansch DN40")

Der Plan: eine Baureihe prüfen

Sechs Nennweiten, jede soll erzeugt, geprüft und gewogen werden. Der Ablauf als Programmablaufplan: Eine Schleife läuft über die Nennweiten, der Flansch wird erzeugt, und die Methode ist_gueltig() erscheint als Unterprogramm (Rechteck mit Doppellinien). Eine Methode ist im Plan ein Unterprogramm, genau wie eine Funktion in V07. Danach entscheidet eine Raute.

PAP: Baureihe prüfen

Kopfgesteuerte Schleife über die Nennweiten, darin ein Aufruf des Unterprogramms und eine Verzweigung. Gültige Flansche werden gewogen, ungültige bekommen eine Warnung.

Vom Skript zum CAD

Wie speichert ein CAD-Programm ein Bauteil? Nicht als Kamerabild und meistens auch nicht als reine Punktwolke, sondern als Feature-Baum: eine Reihe von Schritten (Scheibe, Mittelloch, Bohrungsbild) mit ihren Parametern. Ändert man einen Parameter, rechnet das Programm das Teil neu. Das ist dieselbe Idee wie unsere Klasse: Parameter plus Regeln.

Viele CAD-Programme bieten eine Skript-Schnittstelle, meist für Python: FreeCAD hat eine eigene Python-Konsole und Makros, und die Bibliothek CadQuery baut CAD-Teile direkt aus Python-Code. Dort schreibst du dieselbe Art Klasse wie hier, nur erzeugt mesh() echte CAD-Geometrie. Der Ausschnitt zeigt das Muster mit CadQuery (läuft nur mit installiertem CadQuery, zum Beispiel im Codespace, nicht im Browser):

import cadquery as cq

flansch = (
    cq.Workplane("XY")
    .circle(60).extrude(15)                 # Scheibe, Ø 120 mm, 15 mm dick
    .faces(">Z").workplane().hole(40)       # Mittelloch Ø 40 mm
)
flansch = (
    flansch.faces(">Z").workplane()
    .polarArray(45, 0, 360, 6).hole(11)     # sechs Bohrungen Ø 11 mm auf Lochkreis-Radius 45 mm
)
cq.exporters.export(flansch, "flansch.step")

Für den Austausch gibt es zwei Arten von Dateien. Ein Dreiecksnetz beschreibt die Oberfläche als viele Dreiecke und wird als STL gespeichert. Das reicht für 3D-Druck und Vorschau. Für die Fertigung brauchst du exakte Geometrie, etwa als STEP-Datei: Ein Zylinder ist dort wirklich rund, im Netz nur ein Vieleck. Zähle selbst nach:

import bauteil3d

fein = bauteil3d.zylinder(100, 20, segmente=96)
grob = bauteil3d.zylinder(100, 20, segmente=12)
print("Dreiecke (fein):", len(fein["faces"]))
print("Dreiecke (grob):", len(grob["faces"]))
print("Volumen fein:", round(bauteil3d.volumen(fein)), "mm³")
print("Volumen grob:", round(bauteil3d.volumen(grob)), "mm³")
print("Exakt:", round(3.14159265 / 4 * 100 ** 2 * 20), "mm³")
bauteil3d.zeige(grob, "Zylinder grob")

Je mehr Dreiecke, desto genauer die Rundung, desto größer die Datei. Das bauteil3d-Modul rechnet das Netz für dich; wie die Dreiecke im Einzelnen entstehen, delegierst du. Die CAD-Schnittstellen schaust du dir bei Bedarf in der Dokumentation an, oder du lässt sie dir von Copilot erklären (V11).

3 Ausprobieren

Erst tippen, was herauskommt, dann ausführen. Jeder Block hat einen Editor, und „Schritt für Schritt“ zeigt die Objekte mit ihren Attributen. Das Schreiben eigener Klassen übst du im Labor.

Zwei Objekte, getrennte Attribute

Was gibt das Programm aus?

a und b sind zwei verschiedene Objekte der Klasse Teil, jedes mit eigenem Attribut n. a.n = 8 ändert nur das Objekt, auf das a zeigt: Ausgabe 8 4.
class Teil:
    def __init__(self, n):
        self.n = n


a = Teil(4)
b = Teil(4)
a.n = 8
print(a.n, b.n)

Zwei Namen, ein Objekt

Was gibt print(f1.n, f3.n) aus?

f2 = f1 kopiert nichts: f2 und f1 zeigen auf dasselbe Objekt (wie zwei Namen für eine Liste in V08). f2.n = 8 ändert deshalb auch f1.n. f3 ist ein eigenes Objekt und bleibt bei 6.
class Teil:
    def __init__(self, n):
        self.n = n


f1 = Teil(6)
f2 = f1
f3 = Teil(6)
f2.n = 8
print(f1.n, f3.n)

Klammern vergessen

Was gibt print(p.volumen) aus, also ohne Klammern?

Ohne Klammern wird die Methode nicht aufgerufen, sondern nur als Wert benannt. Python gibt sie als „gebundene Methode“ aus. Es gibt keinen Fehler, aber auch keine Zahl. Das ist der häufigste Anfängerfehler: Methoden brauchen Klammern, Attribute nicht.
class Platte:
    def __init__(self, laenge, breite, dicke):
        self.laenge = laenge
        self.breite = breite
        self.dicke = dicke

    def volumen(self):
        return self.laenge * self.breite * self.dicke


p = Platte(200, 100, 10)
print(p.dicke)
print(p.volumen)
print(p.volumen())

Eine Methode verändert das Objekt

Ein Fräser hat 60 Minuten Standzeit. Er wird 45 und dann 20 Minuten benutzt. Was gibt das Programm aus?

Jeder Aufruf von benutze zieht die Minuten von self.rest ab und speichert das Ergebnis wieder im Objekt: 60 − 45 = 15, dann 15 − 20 = −5. Das Objekt „merkt“ sich seinen Zustand zwischen den Aufrufen. ist_verschlissen() liefert True, weil −5 ≤ 0.
class Werkzeug:
    def __init__(self, standzeit):
        self.rest = standzeit

    def benutze(self, minuten):
        self.rest = self.rest - minuten

    def ist_verschlissen(self):
        return self.rest <= 0


fraeser = Werkzeug(60)
fraeser.benutze(45)
fraeser.benutze(20)
print(fraeser.rest, fraeser.ist_verschlissen())

Typische Stolperstellen

Achtung
  • self in der Methodendefinition vergessen: def masse(): statt def masse(self):. Python übergibt das Objekt trotzdem, und es kommt TypeError: Flansch.masse() takes 0 positional arguments but 1 was given.
  • d statt self.d in einer Methode: NameError, denn die Variable gibt es nur als Attribut des Objekts.
  • Im __init__ einen Parameter nicht als self.… gespeichert: später AttributeError: 'Flansch' object has no attribute 'dicke'.
  • Klammern vergessen: f.masse gibt die Methode aus, f.masse() die Masse.
  • Falsche Zahl Argumente beim Erzeugen: TypeError: Flansch.__init__() missing 1 required positional argument. Das self zählt dabei nicht mit.

Löse die Fehler einmal selbst aus. Der Block fängt sie mit try/except ab (V09), damit du alle vier Meldungen siehst:

class Flansch:
    def __init__(self, d_aussen, dicke):
        self.d_aussen = d_aussen
        # self.dicke wird nicht gespeichert

    def masse(self):
        return self.d_aussen * dicke

    def umfang():
        return 3.14


f = Flansch(120, 15)

for aufruf in ["f.umfang()", "f.dicke", "f.masse()", "Flansch(120)"]:
    try:
        eval(aufruf)
    except Exception as fehler:
        print(aufruf, "->", type(fehler).__name__ + ":", fehler)

4 Selbstcheck

Acht Quizaufgaben im Stil der Probeklausur (22 Punkte) und eine Code-Schreib-Aufgabe (6 Punkte, T9). Plane etwa 15 Minuten für das Quiz und 10 Minuten für T9 ein, ohne Hilfsmittel. Quiz-Punkte gibt es für den ersten Versuch; danach darfst du es nochmal probieren.

T1 · Begriffe zuordnen2 Punkte
Welche Zuordnung stimmt?
  • Klasse = ein konkretes Teil, Objekt = der Bauplan
  • Klasse = der Bauplan, Objekt = ein konkretes Teil nach diesem Bauplan
  • Attribut = eine Funktion der Klasse, Methode = ein Maß
  • Attribut = ein Aufruf mit Klammern, Methode = eine Variable
Die Klasse beschreibt, wie ein Teil aufgebaut ist, das Objekt ist ein einzelnes Teil davon. Attribute sind die Maße und Eigenschaften (Variablen des Objekts), Methoden sind die Funktionen der Klasse, die man mit Klammern aufruft.

Was gibt das Programm aus?

T3 · Fehler finden3 Punkte
Was passiert beim Ausführen?
class Platte:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def flaeche():
        return self.a * self.b


p = Platte(4, 5)
print(p.flaeche())
  • Es wird 20 ausgegeben.
  • TypeError: flaeche() bekommt ein Argument, hat aber keinen Parameter dafür (self fehlt).
  • NameError: Platte ist nicht definiert.
  • AttributeError: p hat kein Attribut a.
Beim Aufruf p.flaeche() übergibt Python das Objekt p automatisch als erstes Argument. Die Methode ist aber ohne self definiert und nimmt kein Argument an: TypeError: Platte.flaeche() takes 0 positional arguments but 1 was given. Richtig wäre def flaeche(self):.

        ________ = d
        self.l = l

  • Rohr.d

T5 · Masse einer Welle3 Punkte
Eine Stahlwelle (7,85 g/cm³) hat 20 mm Durchmesser und 100 mm Länge. Wie viele Gramm wiegt sie? (auf ganze Gramm gerundet, nur die Zahl)
Volumen: π/4 · 20² · 100 = 31 416 mm³. Durch 1000 sind das 31,4 cm³. Mal 7,85 g/cm³ ergibt 246,6 g, gerundet 247 g. Als Methode: self.volumen() / 1000 * dichte in Gramm, nochmal durch 1000 in Kilogramm (0,247 kg).
T6 · Methode aufrufen2 Punkte
Das Objekt f der Klasse Flansch hat eine Methode masse(self). Welche Zeile gibt die Masse aus?
  • print(f.masse)
  • print(f.masse())
  • print(masse(f))
  • print(f.masse(self))
f.masse() ruft die Methode auf, und Python setzt f selbst als self ein. Ohne Klammern bekommst du nur die Methode als Objekt. masse(f) sucht eine Funktion namens masse, die es nicht gibt (NameError). self übergibst du nie selbst.
T7 · Klassen und Objekte (mehrere richtig)4 Punkte
Welche Aussagen stimmen? Alle richtigen ankreuzen.
  • Aus einer Klasse kann man beliebig viele Objekte erzeugen.
  • Jedes Objekt hat seine eigenen Attribute.
  • Ändert man f1.n, ändert sich n bei allen Objekten der Klasse.
  • Man muss self beim Aufruf einer Methode als erstes Argument angeben.
Die Klasse ist der Bauplan: beliebig viele Objekte, jedes mit eigenen Attributwerten. Ein Attribut zu ändern betrifft nur dieses Objekt (außer ein zweiter Name zeigt auf dasselbe Objekt). self setzt Python beim Aufruf selbst ein.
T8 · Du benutzt Objekte schon3 Punkte
Was ist teile.append("Welle") für eine Zeile, wenn teile eine Liste ist?
  • Der Aufruf einer Funktion namens append, der die Liste als Parameter bekommt.
  • Der Aufruf der Methode append des Objekts teile, einer Instanz der Klasse list.
  • Eine Zuweisung an das Attribut append.
  • Die Definition einer neuen Klasse.
Eine Liste ist ein Objekt der Klasse list, und append ist eine ihrer Methoden. Das Muster objekt.methode(argumente) ist dasselbe wie bei f.masse(), nur ist die Klasse list schon in Python eingebaut.

5 Deep Dive (freiwillig)

Für Neugierige. Nichts davon kommt in der Klausur dran, erkennen sollst du es aber, wenn die KI es schreibt.

Schöne Ausgabe mit __str__

Gibt man ein Objekt mit print aus, erscheint nur eine Adresse. Definierst du die Methode __str__, bestimmst du den Text selbst. Python ruft sie automatisch bei print und str() auf.

class Flansch:
    def __init__(self, d_aussen, n):
        self.d_aussen = d_aussen
        self.n = n

    def __str__(self):
        return f"Flansch Ø{self.d_aussen} mm mit {self.n} Bohrungen"


f = Flansch(120, 6)
print(f)
Vererbung: ein Blindflansch ist ein Flansch ohne Bohrungen

Eine Klasse kann die Attribute und Methoden einer anderen übernehmen und erweitern. Die neue Klasse steht in Klammern hinter dem Namen. So spart man, Code zu kopieren. Du musst das nicht schreiben können, aber lesen: class Blindflansch(Flansch) heißt „ein Blindflansch ist ein Flansch mit Änderungen“.

class Flansch:
    def __init__(self, d_aussen, dicke, n):
        self.d_aussen = d_aussen
        self.dicke = dicke
        self.n = n

    def beschreibung(self):
        return f"Ø{self.d_aussen} x {self.dicke} mm, {self.n} Bohrungen"


class Blindflansch(Flansch):
    def __init__(self, d_aussen, dicke):
        super().__init__(d_aussen, dicke, 0)


b = Blindflansch(120, 15)
print(b.beschreibung())
@dataclass: die Kurzschreibweise für reine Maße

Besteht eine Klasse fast nur aus Attributen, schreibt die KI oft einen @dataclass. Das __init__ und eine lesbare Ausgabe entstehen dann automatisch. Die Angaben hinter dem Doppelpunkt (float, int) sind Typ-Hinweise: Sie helfen beim Lesen, Python erzwingt sie nicht.

from dataclasses import dataclass


@dataclass
class Flansch:
    d_aussen: float
    d_innen: float
    dicke: float
    n: int = 6

    def masse(self, dichte=7.85):
        v = 3.14159265 / 4 * (self.d_aussen ** 2 - self.d_innen ** 2) * self.dicke
        return v / 1000 * dichte / 1000


f = Flansch(120, 40, 15)
print(f)
print(round(f.masse(), 2), "kg")
