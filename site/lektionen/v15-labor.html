Werkzeugkasten

Heute neu in Python: Tabellen mit pandas. Du lädst eine Datei mit pd.read_csv in einen DataFrame, wählst Spalten aus, filterst Zeilen mit einer Maske, bildest Kennzahlen (mean, std, describe) und rechnest je Gruppe mit groupby. Damit bestimmst du die Prozessfähigkeit (Cp, Cpk) deiner Drehmaschinen. Beim ersten Ausführen lädt Python pandas nach (ca. 16 MB, einmalig). Die Messdatei wellen.csv liegt für jeden Lauf im Arbeitsordner bereit: 250 Wellendurchmesser von zwei Drehmaschinen D1 und D2, Soll 20,000 mm, Toleranz ± 0,020 mm.

Merke

Diese sechs Syntax-Karten sind dein Spickzettel, bis es sitzt. Du erreichst sie in jeder Aufgabe über den Knopf „Werkzeugkasten“ oben. Alle Befehle des Kurses stehen außerdem rechts in der Befehls-Bibliothek. Führe jede Python-Karte aus und lies die Ausgabe. Karte 6 ist eine Textkarte ohne Ausführen.

Datei laden und ansehen

import pandas as pd

df = pd.read_csv("wellen.csv")      # Datei laden: df ist jetzt eine Tabelle (DataFrame)
print(df.head())                    # die ersten fünf Zeilen
print(len(df), "Zeilen")            # Zahl der Zeilen
print(df.shape)                     # (Zeilen, Spalten)
print(list(df.columns))             # die Spaltennamen
import pandas as pd

# Eine deutsche CSV-Datei (Semikolon, Dezimalkomma), wie sie phyphox liefert (V09):
df = pd.read_csv("bremsen.csv", sep=";", decimal=",")
print(df.shape)
print(df[["Time (s)", "Linear Acceleration y (m/s^2)"]].head(3))
  • import pandas as pd holt das Tabellen-Paket unter dem Kurznamen pd (wie import matplotlib.pyplot as plt in V14). Ohne diese Zeile gibt es einen NameError.
  • pd.read_csv("name.csv") liest die Datei und erkennt die Kopfzeile selbst. Die Zahlen sind danach Zahlen, kein Text (kein float() und kein replace mehr).
  • Bei deutschen Dateien gibst du das Trennzeichen mit sep=";" und das Dezimalzeichen mit decimal="," an. Mit dem falschen Trennzeichen entsteht nur eine Spalte.
  • df.shape ist ein Tupel (Zeilen, Spalten), ohne Klammern am Ende, denn es ist keine Funktion. len(df) zählt die Zeilen.
Syntax-Karte 2

Spalten und Kennzahlen

import pandas as pd

df = pd.read_csv("wellen.csv")
d = df["durchmesser_mm"]                   # eine Spalte (eine Series): ein Name in eckigen Klammern
print(round(d.mean(), 4), round(d.std(), 4))
print(d.min(), d.max(), d.count())
print(d.idxmin())                          # Zeilennummer des kleinsten Werts
print(df[["maschine", "durchmesser_mm"]].head(3))   # mehrere Spalten: eine Liste in den Klammern
print(d.describe().round(4))               # Kennzahlen auf einen Blick
print(df["maschine"].value_counts())       # wie oft kommt jeder Wert vor?
  • df["spalte"] liefert eine Spalte als Series. Auf ihr rechnen mean(), std(), min(), max() und count() ohne Schleife.
  • std() ist die Stichproben-Standardabweichung (geteilt durch n − 1), so wie es die Qualitätssicherung verlangt.
  • df[["a", "b"]] mit doppelten eckigen Klammern wählt mehrere Spalten und ergibt wieder eine Tabelle.
  • describe() fasst eine Spalte zusammen (Anzahl, Mittelwert, Streuung, kleinster und größter Wert, Quartile). round(4) kürzt die Ausgabe auf vier Nachkommastellen.
  • value_counts() zählt, wie oft jeder Wert in einer Spalte vorkommt.
Syntax-Karte 3

Filtern mit einer Maske

import pandas as pd

df = pd.read_csv("wellen.csv")
maske = df["maschine"] == "D2"      # eine Reihe aus True und False, eine pro Zeile
d2 = df[maske]                      # nur die Zeilen mit True bleiben
print(len(d2))

spaet_d2 = df[(df["maschine"] == "D2") & (df["schicht"] == "Spät")]      # und: &
print(len(spaet_d2))
ausser = df[(df["durchmesser_mm"] > 20.02) | (df["durchmesser_mm"] < 19.98)]   # oder: |
print(len(ausser))
nicht_d1 = df[~(df["maschine"] == "D1")]                                  # nicht: ~
print(len(nicht_d1))
  • Ein Vergleich auf einer Spalte (df["maschine"] == "D2") rechnet für jede Zeile und ergibt eine Maske. df[maske] behält die Zeilen mit True.
  • Mehrere Bedingungen verknüpfst du mit & (und), | (oder) und ~ (nicht) und setzt jede Bedingung in Klammern.
  • Nicht and, or, not: Die kennen nur ein einzelnes Ja oder Nein. Bei einer ganzen Reihe aus True und False kommt der ValueError „truth value of a Series is ambiguous“.
  • Ein Gleichheitszeichen ist eine Zuweisung, zwei (==) sind ein Vergleich. Bei Text steht der Wert in Anführungszeichen.
Syntax-Karte 4

Neue Spalte und Gruppen

import pandas as pd

df = pd.read_csv("wellen.csv")
df["abw_um"] = (df["durchmesser_mm"] - 20) * 1000      # neue Spalte: Abweichung vom Soll in µm
print(df["abw_um"].head(3).round(1))

print(df.groupby("maschine")["durchmesser_mm"].mean().round(4))     # ein Mittelwert je Maschine
print(df.groupby("schicht")["durchmesser_mm"].agg(["mean", "std", "count"]).round(4))
  • df["neu"] = … legt eine neue Spalte an. Die Rechnung läuft für alle Zeilen auf einmal.
  • groupby("maschine") teilt die Tabelle in Gruppen. Dahinter wählst du die Spalte in eckigen Klammern und sagst, was du rechnen willst: .mean(), .std(), .count().
  • .agg(["mean", "std", "count"]) rechnet mehrere Kennzahlen auf einmal. Das Ergebnis ist wieder eine Tabelle: eine Zeile je Gruppe, eine Spalte je Kennzahl.
  • Die Gruppennamen stehen danach als Zeilenbeschriftung (index) links, sortiert nach Alphabet oder Zahl.
Syntax-Karte 5

Eine Regelkarte zeichnen

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("wellen.csv")
d1 = df[df["maschine"] == "D1"]
mittel = d1.groupby("stichprobe")["durchmesser_mm"].mean()      # ein Mittelwert je Stichprobe

plt.plot(mittel.index, mittel.values, marker="o")               # Stichprobe Nr. (x), Mittelwert (y)
plt.axhline(20.000, color="gray", linestyle="--")               # Mittellinie
plt.axhline(20.006, color="black", linestyle=":")               # obere Eingriffsgrenze
plt.axhline(19.994, color="black", linestyle=":")               # untere Eingriffsgrenze
plt.xlabel("Stichprobe Nr.")
plt.ylabel("Mittelwert d in mm")
plt.title("Regelkarte D1")                                      # der Titel ist auch der Alt-Text des Bildes
plt.show()
print(len(mittel), "Stichproben gezeichnet")
  • Eine Regelkarte ist ein Diagramm aus V14 mit Daten aus pandas: Die Werte stammen aus mittel.index (die Stichprobennummern) und mittel.values (die Mittelwerte).
  • axhline(y) zeichnet eine waagerechte Hilfslinie für die Mittellinie und die beiden Eingriffsgrenzen. Die Linien unterscheiden sich im Stil (linestyle), nicht nur in der Farbe.
  • Die Eingriffsgrenzen sind nicht die Toleranzgrenzen der Zeichnung: Sie hängen von der Streuung des Prozesses ab (Mittellinie ± 3 · s/√n) und warnen früher.
  • Immer plt.title(…) setzen und die Achsen mit Größe und Einheit beschriften (Checkliste aus V14).
Syntax-Karte 6

Prozessfähigkeit: die Formeln (nur lesen)

Cp  = (OSG - USG) / (6 * s)                         Toleranzbreite im Vergleich zur Streuung
Cpk = min(OSG - mittel, mittel - USG) / (3 * s)     zusätzlich: Liegt der Prozess mittig?

Cpk >= 1,33          fähig
1,0 <= Cpk < 1,33    bedingt fähig
Cpk < 1,0            nicht fähig

Regelkarte (Mittelwerte von n Teilen):
  Mittellinie = Mittelwert einer ruhigen Anfangsphase
  Eingriffsgrenzen = Mittellinie +/- 3 * s / wurzel(n)
  • OSG und USG sind die Spezifikationsgrenzen aus der Zeichnung, mittel und s kommen aus den Messwerten des Prozesses.
  • Cp sagt, ob die Streuung klein genug wäre, Cpk sagt, ob der Prozess tatsächlich sicher in der Toleranz liegt. Cpk ist nie größer als Cp. Ist der Cpk viel kleiner, ist der Prozess verschoben.
  • min(…) nimmt den kleineren Abstand zur nächsten Grenze. Mit max wäre der Wert zu gut, das ist ein häufiger Fehler in KI-Code.
  • Die Schwellen 1,33 und 1,0 sind gebräuchliche Richtwerte. Welche Zahl für ein Bauteil gilt, legt der Kunde oder die Norm fest.

Bevor du Tabellen filterst, musst du lesen können, was eine Maske tut. Führe das Programm im Kopf aus, Zeile für Zeile, so wie Python es tut. Die Reihe abw ist eine Series, du schreibst sie wie eine Liste (zum Beispiel [5, 12, -3, 7]). Das ist das Filtern aus dem Beispiel, in klein: vier Abweichungen in µm.

Zweiter Ablauf: die Run-Regel der Regelkarte in reinem Python (keine Tabelle nötig). Gezählt wird, wie viele Stichprobenmittel in Folge über der Mittellinie liegen. Die Mittelwerte stehen als Abweichung vom Soll in µm in einer Liste.

Zeilen ordnen

Alle Zeilen sind da, aber durcheinander. Bring sie in die richtige Reihenfolge und rücke die Zeilen im Schleifenrumpf ein (Pfeil nach rechts oder Mausziehen). Manche Zeilen gehören nicht ins Programm.

Zu große Wellen zählen

Das Programm liest wellen.csv und zählt die Wellen, die größer als die obere Spezifikationsgrenze 20,020 mm sind. Überlege vorher: Was muss vor dem Lesen der Datei stehen, was entsteht zuerst, die Maske oder die gefilterte Tabelle, und was steht ganz am Ende?

Streuung je Maschine in einer Schleife

Für jede der beiden Maschinen wird die Tabelle gefiltert und die Standardabweichung auf vier Stellen gerundet ausgegeben. Der Rumpf der Schleife besteht aus zwei Zeilen.

Lücken füllen

Jetzt tippst du Teile selbst. Ergänze die vier Lücken, sodass das Programm die Datei lädt, nur die Wellen der Maschine D2 behält, nach Schicht gruppiert und den Mittelwert je Schicht ausgibt. Geprüft wird nicht dein Wortlaut, sondern ob das Programm bei der Messdatei und bei einer anderen Datei das Richtige tut.

import pandas as pd

df = pd.@@read_csv@@("wellen.csv")
d2 = df[df["maschine"] @@==@@ "D2"]
je_schicht = d2.@@groupby@@("schicht")["durchmesser_mm"]
print(je_schicht.@@mean@@().round(4))
  1. Lücke 1: Die Funktion, die eine CSV-Datei in eine Tabelle lädt, steht in Syntax-Karte 1. Sie gehört zu pd.
  2. Lücke 2: Ein Vergleich, der für jede Zeile True oder False ergibt, braucht zwei Gleichheitszeichen (Syntax-Karte 3).
  3. Lücke 3: Die Tabelle wird in Gruppen geteilt. Das Wort steht in Syntax-Karte 4.
  4. Lücke 4: Der Mittelwert einer Spalte heißt mean, auch je Gruppe.

Erste eigene Aufgabe: Cp und Cpk für Maschine D1

Jetzt rechnest du selbst, mit Tests als Sicherheitsnetz. Die Tests laufen mit der Messdatei und mit anderen Dateien, in denen andere Werte stehen: Ein Programm, das nur die Zahlen aus dem Beispiel ausgibt, besteht nicht.

Lies wellen.csv, behalte nur die Zeilen der Maschine D1, berechne Mittelwert und Standardabweichung der Spalte durchmesser_mm und daraus Cp und Cpk. Die Spezifikationsgrenzen stehen im Code. Gib vier Zeilen mit je vier Nachkommastellen aus.

Ausgabe genau so (für die mitgelieferte Datei):
Mittelwert: 20.0001 mm
Standardabweichung: 0.0042 mm
Cp: 1.5905
Cpk: 1.5809
  1. Erst die Maske, dann die gefilterte Tabelle: d1 = df[df["maschine"] == "D1"] (Syntax-Karte 3). Danach rechnest du nur noch mit d1.
  2. mittel = d1["durchmesser_mm"].mean() und s = d1["durchmesser_mm"].std(). Cp ist (OSG - USG) / (6 * s), die Formeln stehen in Syntax-Karte 6.
  3. Cpk braucht den kleineren der beiden Abstände: min(OSG - mittel, mittel - USG) / (3 * s). Ausgabe mit vier Stellen: print(f"Cp: {cp:.4f}").

Code-Review: KI-Auswertung prüfen

Eine KI hat ein Programm zur Prozessfähigkeit der beiden Drehmaschinen geliefert. Es sieht ordentlich aus und enthält vier Fehler: drei davon liefern falsche Zahlen ohne Fehlermeldung, einer bricht ab. Würdest du es freigeben? Klick die Zeilen an, die du für fehlerhaft hältst, dann lass auflösen.

Szenario: Cp, Cpk und Regelkarte auswerten

Prompt eines Studierenden

Schreib mir ein Python-Programm mit pandas: Lies wellen.csv (Spalten stichprobe, maschine, schicht, teil, durchmesser_mm). Berechne für jede Maschine getrennt Cp und Cpk mit USG 19,98 mm und OSG 20,02 mm. Zähle die Teile der Maschine D2 in der Spätschicht. Bestimme für D2 mit einer Regelkarte der Stichprobenmittel, welche Stichproben auffällig sind. Die Eingriffsgrenzen sind die Mittellinie plus/minus 3 mal s/√5, bestimmt aus den Stichproben 1 bis 15.

KI-Antwort (Python)

Tipp: Es sind vier Fehler eingebaut. Nicht jede Zeile ist falsch. Drei Fehler siehst du erst, wenn du die Zahlen mit dem Beispiel vergleichst.

Würdest du das freigeben? Markiere die fehlerhaften Zeilen, dann lass auflösen.

Die vier Fehler

Fehler 1: Standardabweichung über beide Maschinen gemischt (Zeile 11)

In der Schleife wird der Mittelwert aus teil (eine Maschine) gebildet, die Standardabweichung aber aus df (alle 250 Teile). Cp und Cpk beider Maschinen bekommen dasselbe s von 0,0064 mm: Sie sehen fast gleich aus (Cp 1,04 für beide), obwohl D1 mit 1,59 deutlich besser ist als D2 mit 1,07. Es gibt keine Fehlermeldung, und die Zahlen wirken plausibel. Lösung: s = teil["durchmesser_mm"].std(). Jede Kennzahl einer Maschine gehört in die Tabelle dieser Maschine.

Fehler 2: max statt min im Cpk (Zeile 13)

Cpk braucht den Abstand zur nächsten Grenze, das ist das Minimum. Mit max wird der Abstand zur weiter entfernten Grenze genommen, und der Wert wird zu gut: D2 hätte Cpk 1,45 und gälte als fähig, richtig sind 0,68, also nicht fähig. Der Fehler fällt nicht auf, denn der Wert ist eine plausible Zahl. Lösung: min(OSG - mittel, mittel - USG). Als Gegenprobe gilt immer: Cpk ist nie größer als Cp.

Fehler 3: and statt & (Zeile 16)

Bei Tabellen verknüpfst du Bedingungen mit &, | und ~, nicht mit and, or, not. Die Wörter wollen ein einziges Ja oder Nein, hier stehen aber zwei ganze Reihen aus True und False. Das Programm bricht mit ValueError: The truth value of a Series is ambiguous ab. Lösung: df[(df["maschine"] == "D2") & (df["schicht"] == "Spät")], jede Bedingung in Klammern.

Fehler 4: Toleranzgrenzen als Eingriffsgrenzen (Zeile 21)

Der Prompt verlangt Eingriffsgrenzen aus der Streuung der Stichprobenmittel (Mittellinie ± 3 · s/√5). Die KI hat stattdessen die Grenzen der Zeichnung genommen. Kein Stichprobenmittel erreicht 20,020 mm, die Liste der Auffälligen ist leer, und die Regelkarte meldet „alles in Ordnung“, obwohl D2 ab Stichprobe 18 nach oben driftet. Eine Regelkarte soll warnen, bevor Teile die Toleranz verlassen. Lösung: Mittellinie und Grenzen wie im Beispiel aus den Stichproben 1 bis 15 berechnen.

Die Fehler einzeln zum Ausprobieren

Je ein kleines Programm mit dem Fehler und der Korrektur nebeneinander. Führe sie aus und vergleiche die Zahlen.

df = pd.read_csv("wellen.csv")
d1 = df[df["maschine"] == "D1"]
s_falsch = df["durchmesser_mm"].std()       # Fehler 1: alle 250 Teile, beide Maschinen gemischt
s_richtig = d1["durchmesser_mm"].std()      # richtig: nur D1
print("s gemischt:", round(s_falsch, 4), "mm   Cp:", round(0.04 / (6 * s_falsch), 2))
print("s nur D1:  ", round(s_richtig, 4), "mm   Cp:", round(0.04 / (6 * s_richtig), 2))

USG = 19.980

print("Cpk mit min (richtig): ", round(min(OSG - mittel, mittel - USG) / (3 * s), 2))
import pandas as pd

df = pd.read_csv("wellen.csv")
# Fehler 3: "and" bricht mit einem ValueError ab. Ersetze es durch & und führe noch einmal aus.
spaet = df[(df["maschine"] == "D2") and (df["schicht"] == "Spät")]
print(len(spaet), "Teile aus der Spätschicht von D2")

mitte = anfang["durchmesser_mm"].mean()
sigma_x = anfang["durchmesser_mm"].std() / 5 ** 0.5
richtig = mittel[(mittel > mitte + 3 * sigma_x) | (mittel < mitte - 3 * sigma_x)]
print("Mit Eingriffsgrenzen auffällig:", list(richtig.index))

Korrigierte Version

import pandas as pd

OSG = 20.020
USG = 19.980

df = pd.read_csv("wellen.csv")

for name in ["D1", "D2"]:
    teil = df[df["maschine"] == name]
    mittel = teil["durchmesser_mm"].mean()
    s = teil["durchmesser_mm"].std()                        # nur diese Maschine
    cp = (OSG - USG) / (6 * s)
    cpk = min(OSG - mittel, mittel - USG) / (3 * s)         # der kleinere Abstand
    print(name, round(cp, 2), round(cpk, 2))

spaet = df[(df["maschine"] == "D2") & (df["schicht"] == "Spät")]     # & mit Klammern
print(len(spaet), "Teile aus der Spätschicht von D2")

d2 = df[df["maschine"] == "D2"]
mittel2 = d2.groupby("stichprobe")["durchmesser_mm"].mean()
anfang = d2[d2["stichprobe"] <= 15]                        # ruhige Anfangsphase
mitte = anfang["durchmesser_mm"].mean()
sigma_x = anfang["durchmesser_mm"].std() / 5 ** 0.5
oeg = mitte + 3 * sigma_x                                   # Eingriffsgrenzen, nicht OSG und USG
ueg = mitte - 3 * sigma_x
auffaellig = mittel2[(mittel2 > oeg) | (mittel2 < ueg)]
print("Auffällige Stichproben:", list(auffaellig.index))

Typische Fehlermeldungen

Mit pandas siehst du neue Fehlermeldungen, und einen Fehler, der keine auslöst. Diese sechs siehst du garantiert. Jedes Beispiel lässt sich ausführen: Schau dir die echte Meldung an und lies sie von unten nach oben (zuerst die letzte Zeile).

KeyError: Spaltenname falsch

Meldung: KeyError: 'durchmesser'. Die Spalte heißt durchmesser_mm. Python sucht genau den Namen, den du schreibst, mit Groß- und Kleinschreibung und Unterstrich. Schau die Namen mit print(list(df.columns)) nach. Steht in der Datei ein Leerzeichen am Rand des Namens, erscheint es in dieser Liste mit.

ValueError: and statt &

Meldung: ValueError: The truth value of a Series is ambiguous. Use a.empty, a.bool(), a.item(), a.any() or a.all(). („Der Wahrheitswert einer Reihe ist nicht eindeutig.“) and kann nur ein einziges Ja oder Nein verknüpfen, du hast aber eine ganze Reihe aus True und False. Schreibe & (und), | (oder) und ~ (nicht), jede Bedingung in Klammern.

Falsches Trennzeichen: nur eine Spalte, keine Fehlermeldung

Hier gibt es keine Fehlermeldung, aber df.shape zeigt (400, 1): eine Spalte statt fünf, und ihr Name ist eine lange Zeile mit Semikolons (in der Ausgabe von list(df.columns)). Die Datei ist ein deutscher Export (Semikolon und Dezimalkomma), read_csv erwartet aber Kommas. Erst mit pd.read_csv("bremsen.csv", sep=";", decimal=",") stimmt die Tabelle. Die Form (shape) und die Spaltenliste immer direkt nach dem Laden ansehen.

FileNotFoundError: Datei nicht gefunden

Meldung: FileNotFoundError: [Errno 44] No such file or directory: 'wellen.csv' (auf anderen Rechnern steht [Errno 2]). Dieser Block hat die Datei nicht bekommen, also gibt es sie im Arbeitsordner nicht. In echt: Name falsch geschrieben, Endung versteckt oder die Datei liegt in einem anderen Ordner als das Programm. Die Meldung nennt den Namen, den Python gesucht hat (V09).

TypeError: Text statt Zahlen (Dezimalkomma vergessen)

Das Trennzeichen stimmt, das Dezimalzeichen nicht: Ohne decimal="," bleiben „-6,397007E-02“ und alle anderen Werte Text (die erste Ausgabe zeigt dtype: object). Rechnen mit Text geht nicht. Die Meldung beginnt mit TypeError: Could not convert string '-6,397007E-02-7,876711E-022,779793E-01' to numeric: pandas hat die Texte hintereinandergeklebt und kann daraus keine Zahl machen. (Bei der ganzen Spalte wäre die Meldung 400 Werte lang, deshalb hier nur drei. Je nach pandas-Version lautet der Text etwas anders.) Lösung: pd.read_csv("bremsen.csv", sep=";", decimal=","). Der Fehler ist dem aus V14 verwandt, wo Text-Werte die Achse durcheinanderbrachten.

TypeError: Mittelwert über Spalten mit Text

Die Tabelle hat auch die Textspalte schicht, und einen Mittelwert über „Früh“ und „Spät“ gibt es nicht. Die Meldung lautet TypeError: agg function failed [how->mean,dtype->object] („die Rechenfunktion ist bei einer Textspalte gescheitert“), je nach pandas-Version etwas anders. Wähle die Spalte, die du meinst: df.groupby("maschine")["durchmesser_mm"].mean(). So rechnest du nur, was gemeint ist.

PAP zeichnen: Cpk bewerten

Aus Mittelwert und Streuung wird ein Urteil: Ist die Maschine fähig? Das zeichnest du als Plan. Die vier Eingaben stehen schon da. Ergänze die Rechnung für den Cpk, die zwei Rauten und die drei Ausgaben. Der Text einer Ausgabe steht in Anführungszeichen, zum Beispiel "fähig". Die Prüfung erzeugt aus deinem PAP Python-Code und testet ihn, auch am Grenzfall.

Prozessfähigkeit bewerten

Zeichne einen PAP: Eingaben sind der Mittelwert mittel, die Standardabweichung s und die Grenzen usg und osg (alles Kommazahlen in mm). Berechne cpk als den kleineren der beiden Abstände zu den Grenzen, geteilt durch 3 · s (in Python min(osg - mittel, mittel - usg) / (3 * s)). Dann: Ist cpk mindestens 1,33, gib „fähig“ aus. Sonst: Ist cpk mindestens 1,0, gib „bedingt fähig“ aus. Sonst gib „nicht fähig“ aus. Es wird nur der Text ausgegeben.

  1. Nach den vier Eingaben kommt ein Rechteck (Operation) mit cpk = min(osg - mittel, mittel - usg) / (3 * s). Das min nimmt den kleineren Abstand zu den Grenzen.
  2. Danach eine Raute mit der Bedingung cpk >= 1.33. Im „ja“-Zweig die Ausgabe "fähig". Im „nein“-Zweig kommt die zweite Raute: cpk >= 1.0, „ja“: "bedingt fähig", „nein“: "nicht fähig".
  3. Achte auf >=: Genau 1,0 ist noch „bedingt fähig“. Das testet der Grenzfall.

Funktion cp_cpk für eine Messreihe

Cp und Cpk brauchst du für jede Maschine, jede Schicht und jedes Maß: Das gehört in eine Funktion (V07). Schreibe cp_cpk(serie, usg, osg). Der Parameter serie ist eine Spalte (Series) mit Messwerten. Die Funktion gibt das Paar (cp, cpk) zurück, beide auf vier Nachkommastellen gerundet. Die Grenzen kommen als Parameter, nicht aus dem Programm: Die Funktion muss für jedes Maß funktionieren. Die Tests rufen sie mit den Maschinen aus der Datei und mit anderen Messreihen auf.

Erwartet

cp_cpk(D2-Spalte, 19.98, 20.02)  ergibt  (1.0682, 0.6838)
  1. Im Rumpf der Funktion rechnest du mit serie.mean() und serie.std(). Alles, was du brauchst, kommt aus den drei Parametern. Kein df und keine festen Zahlen 19.98 oder 20.02 im Rumpf.
  2. Cp ist (osg - usg) / (6 * s), Cpk ist min(osg - mittel, mittel - usg) / (3 * s) (Syntax-Karte 6).
  3. Zurückgeben: return round(cp, 4), round(cpk, 4). Ein return mit Komma gibt ein Paar (Tupel) zurück (V08). print im Rumpf wäre keine Rückgabe.
