Werkzeugkasten

Heute neu in Python: eigene Funktion mit def. Du gibst ihnen Parameter, sie geben ihr Ergebnis mit return zurück. Sieben Karten zeigen alles, was du dafür brauchst. Jedes Beispiel ist ausführbar: Probiere es aus, ändere etwas und beobachte mit „Schritt für Schritt“ den Aufrufstapel.

Merke

Diese sieben Syntax-Karten sind dein Werkzeugkasten. Du blendest sie bei jeder Aufgabe über den Knopf „Werkzeugkasten“ oben ein. Das Wichtigste in einem Satz: def legt an, der Aufruf führt aus, return gibt zurück, und alles in der Funktion ist lokal.

Syntax-Karte 1

def und Aufruf: eine Funktion anlegen und benutzen

import math

def widerstandsmoment(d):
    return math.pi * d ** 3 / 16

w = widerstandsmoment(30)
print(w)
print(widerstandsmoment(40) / widerstandsmoment(20))
  • Der Kopf: def, der Name, die Parameter in Klammern und ein Doppelpunkt. Der Rumpf steht eingerückt (4 Leerzeichen). Was nicht mehr eingerückt ist, gehört zum Hauptprogramm.
  • def führt nichts aus, es legt die Funktion nur an. Probiere es: Lösche die drei Zeilen darunter, dann gibt es keine Ausgabe. Der Rumpf läuft erst beim Aufruf widerstandsmoment(30).
  • Der Aufruf ist ein Ausdruck: Sein Wert steht dort, wo du ihn schreibst, in einer Zuweisung (w = ...), in print oder mitten in einer Rechnung. Die letzte Zeile zeigt das: doppelter Durchmesser, achtfaches Widerstandsmoment (d hoch drei).
  • Die Funktion muss vor dem Aufruf definiert sein. Namen wählst du wie bei Variablen (V01): klein, mit Unterstrich, am besten eine Größe oder ein Verb.
Syntax-Karte 2

Parameter und Argumente: positionell und mit Namen

def tau(T, d):
    return T * 1000 / (3.1416 * d ** 3 / 16)

print(tau(98.8, 30))
print(tau(d=30, T=98.8))
print(tau(98.8, d=30))
print(tau(30, 98.8))
  • Ein Parameter steht in der Klammer bei def (T, d), ein Argument ist der Wert beim Aufruf (98.8, 30).
  • Positionell: Das erste Argument geht an den ersten Parameter, das zweite an den zweiten. Mit Namen: d=30 sagt selbst, wohin der Wert gehört, die Reihenfolge ist dann egal. Beides darf gemischt werden, die positionellen kommen zuerst.
  • Die letzte Zeile hat die Argumente vertauscht: T = 30 und d = 98.8. Python meldet nichts, es sind ja zwei Zahlen. Das Ergebnis ist trotzdem falsch (0.16 MPa statt 18.6, schon ein Überschlag zeigt, dass das nicht stimmen kann). Bei mehreren Parametern lohnt sich der Aufruf mit Namen.
  • Zu wenige oder zu viele Argumente gibt einen TypeError (siehe „Typische Fehlermeldungen“).
Syntax-Karte 3

return und print: zurückgeben oder nur anzeigen

def verdopple_a(x):
    print(2 * x)

def verdopple_b(x):
    return 2 * x

a = verdopple_a(5)
b = verdopple_b(5)
print("a =", a, " b =", b)
print(b + 1)
  • return gibt den Wert an den Aufrufer zurück und beendet die Funktion sofort. Zeilen danach im Rumpf laufen nicht mehr. print zeigt den Wert nur auf dem Bildschirm an.
  • Die erste Funktion zeigt 10 an, gibt aber nichts zurück. Darum ist a gleich None, der Python-Wert für „nichts“. Rechne mit a + 1, dann kommt ein TypeError. Das ist der häufigste Anfängerfehler und ein klassischer KI-Fehler.
  • Faustregel: Funktionen rechnen und geben zurück, das Hauptprogramm gibt aus. Dann kannst du jede Funktion in anderen Rechnungen weiterverwenden.
  • Mit if und else braucht jeder Weg ein return. Läuft eine Funktion ans Ende, ohne dass ein return erreicht wurde, gibt sie still None zurück.
Syntax-Karte 4

Default-Werte: Standardwert für einen Parameter

def pruefe(tau_vorh, tau_zul=40.0):
    if tau_vorh <= tau_zul:
        return "ok"
    else:
        return "zu hoch"

print(pruefe(30))
print(pruefe(30, 25.0))
print(pruefe(30, tau_zul=35.0))
  • Mit tau_zul=40.0 im Kopf legst du einen Default-Wert fest. Beim Aufruf pruefe(30) fehlt das zweite Argument, dann gilt 40.0. Wer es angibt, überschreibt den Standard, nur für diesen Aufruf.
  • Parameter mit Default-Wert stehen immer hinter den Parametern ohne: def f(a, b=1) geht, def f(a=1, b) ist ein SyntaxError.
  • Sinnvoll sind Defaults für Werte, die fast immer gleich sind: ein Grenzwert, eine Dichte, ein Sicherheitsbeiwert. Wer sie ändern will, nennt den Parameter beim Aufruf: tau_zul=35.0.
  • Default-Werte sind Zahlen, Texte oder Wahrheitswerte. Listen als Default kommen nicht vor (Listen lernst du in V08).
Syntax-Karte 5

Docstring und Typ-Hinweise: das Datenblatt (Hinweise nur lesen)

def tau(T: float, d: float) -> float:
    """Torsionsspannung in MPa aus Moment T in N·m und Durchmesser d in mm."""
    return T * 1000 / (3.14159 * d ** 3 / 16)

help(tau)
print(tau(98.8, 30))
  • Der Docstring steht direkt unter dem def in dreifachen Anführungszeichen. Er sagt, was die Funktion tut und in welchen Einheiten. Einheitenfehler (kW statt W) fallen so früher auf. help(tau) zeigt ihn an.
  • Die Zeichen T: float und -> float heißen Typ-Hinweise: T und d sind Kommazahlen, das Ergebnis auch. Python prüft sie beim Ausführen nicht. Du musst sie nur lesen können: KI-Code ist voll davon. In den Aufgaben schreibst du sie nicht.
  • Ein Kommentar mit # erklärt eine Zeile, ein Docstring beschreibt die ganze Funktion.
Syntax-Karte 6

Lokale Variablen und Gültigkeitsbereich

def quadrat(x):
    ergebnis = x * x
    return ergebnis

x = 3
a = quadrat(7)
print(a, x)
print(ergebnis)
  • x und ergebnis in der Funktion sind lokal: Sie entstehen beim Aufruf und sind danach weg. Das x = 3 im Hauptprogramm ist eine andere Variable mit demselben Namen: print(a, x) zeigt 49 und 3.
  • Die letzte Zeile gibt einen NameError, denn das Hauptprogramm kennt ergebnis nicht. Wer den Wert braucht, nimmt den Rückgabewert (a).
  • Gewöhnung: Eine Funktion bekommt alles, was sie braucht, als Parameter und gibt ihr Ergebnis mit return ab. Dann kannst du sie ohne Nebenwirkungen überall benutzen und einzeln prüfen.
  • Der Visualisierer („Schritt für Schritt“) zeigt jeden Aufruf als eigenen Frame mit seinen Variablen. Beobachte, wie die Frames beim return verschwinden.
Syntax-Karte 7

Funktion ruft Funktion: der Aufrufstapel

import math

def widerstandsmoment(d):
    return math.pi * d ** 3 / 16

def tau(T, d):
    return T * 1000 / widerstandsmoment(d)

spannung = tau(98.8, 30)
print(f"{spannung:.1f} MPa")
  • tau ruft widerstandsmoment auf. Beim Aufruf von tau liegt ein Frame auf dem Aufrufstapel, beim Aufruf von widerstandsmoment ein zweiter darauf. Mit „Schritt für Schritt“ siehst du den Stapel wachsen und schrumpfen.
  • So baust du große Programme aus kleinen Bausteinen: Jede Funktion hat eine Aufgabe, die übergeordnete verknüpft sie. Das Hauptprogramm erzählt dann die Geschichte in wenigen Zeilen.
  • Jede Funktion prüfst du einzeln mit einem Wert, den du von Hand nachrechnen kannst: widerstandsmoment(30) muss 5301.4 sein, tau(98.8, 30) muss 18.6 sein. Erst dann vertraust du dem Zusammenspiel.

Vorgerechnetes Beispiel: Wellen-Rechner aus Bausteinen

Aufgabe: Ein Motor mit 15 kW treibt bei 1450 1/min eine Getriebewelle an. Welches Torsionsmoment liegt an, und hält die Welle bei 20, 25 und 30 mm Durchmesser eine Torsionsspannung von 40 MPa aus? Statt eines langen Skripts schreibst du vier kleine Funktion und ein kurzes Hauptprogramm. Lies den Code Zeile für Zeile, führe ihn aus und folge dem Aufrufstapel mit „Schritt für Schritt“.

  1. Zeilen 8 bis 11, torsionsmoment: Die erste Funktion hat zwei Parameter, P in kW und n in 1/min. Der Docstring in Zeile 9 nennt die Einheiten. omega ist die Winkelgeschwindigkeit in 1/s und eine lokale Variable: Außerhalb der Funktion gibt es sie nicht. Die Zeile mit return rechnet P * 1000 / omega: Das * 1000 macht aus kW Watt (genau der Faktor, der in KI-Code gern fehlt).
  2. Zeilen 14 bis 16, widerstandsmoment: Ein Parameter, eine Zeile. Das polare Widerstandsmoment einer Vollwelle ist π · d³ / 16 in mm³. Weil die Funktion nur das tut, lässt sie sich mit einem Wert prüfen: widerstandsmoment(30) ergibt 5301.4.
  3. Zeilen 19 bis 21, tau: Die dritte Funktion ruft die zweite auf. T * 1000 rechnet N·m in N·mm um, dann geteilt durch das Widerstandsmoment: N/mm², also MPa. Beim Aufruf liegen zwei Frames auf dem Aufrufstapel (probiere „Schritt für Schritt“).
  4. Zeilen 24 bis 29, pruefe: Die vierte Funktion hat einen Default-Wert: tau_zul=40.0. Beide Zweige der Verzweigung enden mit return: Jeder Weg liefert ein Ergebnis, sonst käme None heraus. Die Funktion gibt nichts aus, sie bewertet nur.
  5. Zeilen 32 und 33, Hauptprogramm: T = torsionsmoment(15.0, 1450) ruft die erste Funktion mit den Motordaten auf: 98.8 N·m. Rechne zur Probe von Hand: 15 000 W / (2π · 1450 / 60) = 98.8 N·m. Die Ausgabe passiert hier, nicht in der Funktion.
  6. Zeilen 35 bis 37, die Schleife: range(20, 35, 5) liefert 20, 25 und 30 (V06). Für jeden Durchmesser rechnet tau(T, d) die Spannung, pruefe(t) bewertet sie. Ergebnis: 20 mm ist mit 62.9 MPa zu hoch, 25 mm (32.2 MPa) und 30 mm (18.6 MPa) sind ok. Plausibel: Mehr Durchmesser, weniger Spannung.
  7. Zeile 39, Aufruf mit Namen: pruefe(tau(T, 25), tau_zul=25.0) überschreibt den Default-Wert nur für diesen Aufruf. Aus „ok“ wird „zu hoch“: Dieselbe Funktion, anderer Grenzwert.
  8. Selbsterklärung: Entferne in Zeile 11 das * 1000 und führe aus. Was erwartest du? (Das Moment fällt auf 0.1 N·m, alle Spannungen werden winzig, und alles meldet „ok“. Das Programm läuft fehlerfrei und liefert falsche Ergebnisse.) Dann ändere in Zeile 27 return in print: Welche Fehlermeldung kommt, und warum?

Ablauf verfolgen

Bevor du Funktionen schreibst, musst du sie lesen können. Führe das Programm im Kopf aus, Zeile für Zeile, so wie Python es tut. Die Zeilen mit def übergehst du: Sie legen die Funktion nur an. Bei einem Aufruf springst du in die Funktion, rechnest dort und kehrst zur Aufrufzeile zurück. In der Tabelle stehen die Variablen des Hauptprogramms und die der Funktion (ihr Frame). Die Zeile mit dem Aufruf kommt zweimal vor: beim Hineinspringen und beim Zuweisen des Rückgabewerts.

Zweiter Ablauf: Eine Funktion ruft eine andere auf. Jetzt liegen zwei Frames gleichzeitig auf dem Aufrufstapel. Die Parameter heißen u (in f) und v (in g), damit die Spalten eindeutig bleiben.

Zeilen ordnen

Alle Zeilen sind da, aber durcheinander. Bring sie in die richtige Reihenfolge und rücke die Zeilen im Rumpf der Funktion ein (Pfeil nach rechts oder Mausziehen). Manche Zeilen sind Ablenker: Sie gehören nicht ins Programm.

Volumen eines Zylinders als Funktion

Die Funktion volumen_zylinder(d, h) berechnet das Volumen in mm³ (Durchmesser und Höhe in mm). Danach wird sie mit d = 30 und h = 100 aufgerufen und das Ergebnis ausgegeben. Überlege: Wo steht import, was ist Rumpf, was Hauptprogramm?

Bewerten mit Default-Wert

Die Funktion pruefe gibt 'ok' zurück, wenn die vorhandene Spannung nicht über der zulässigen liegt, sonst 'zu hoch'. Die zulässige Spannung hat den Default-Wert 40.0. Zum Schluss wird pruefe(18.6) ausgegeben. Beide Zweige brauchen ein return.

Lücken füllen

Jetzt tippst du Teile selbst. Ergänze die vier Lücken, sodass die Funktion torsionsmoment angelegt, mit return ein Ergebnis zurückgibt und aufgerufen wird. Geprüft wird nicht nur dein Wortlaut, sondern ob das Programm das richtige Moment (98.8 N·m) ausgibt.

import math

@@def@@ torsionsmoment(P, n):

    @@return@@ P * @@1000@@ / omega

T = @@torsionsmoment@@(15.0, 1450)

  2. Lücke 2: Das Ergebnis soll zum Aufrufer zurück, nicht nur angezeigt werden. Welches Wort?
  3. Lücke 3: Leistung in kW, die Formel braucht Watt. Welcher Faktor macht aus kW Watt?
  4. Lücke 4: Wie heißt die Funktion, die oben angelegt wurde? Sie wird hier aufgerufen.

Erste eigene Aufgabe: Schnittgeschwindigkeit als Funktion

Jetzt schreibst du die Funktion selbst, mit Tests als Sicherheitsnetz. Die Tests rufen deine Funktion mit mehreren Werten auf, auch mit solchen, die du nicht siehst. Die Schnittgeschwindigkeit kennst du aus V03 und V06: Dort stand die Formel in einer Schleife, jetzt wird sie ein wiederverwendbarer Baustein.

Schreibe die Funktion schnittgeschwindigkeit(d, n). Sie bekommt den Durchmesser d in mm und die Drehzahl n in 1/min und gibt die Schnittgeschwindigkeit vc = π · d · n / 1000 in m/min zurück (kein print in der Funktion). Probiere sie danach mit einer eigenen print-Zeile im Hauptprogramm aus.

Erwartet (Rückgabewerte)
schnittgeschwindigkeit(60, 1000)  ->  188.4956 (m/min)
schnittgeschwindigkeit(25, 2000)  ->  157.0796 (m/min)

Code-Review: KI-Code prüfen

Eine KI hat Code geliefert. Er sieht sauber aus, hat Funktionen, Namen und läuft los. Würdest du ihn freigeben? Klick die Zeilen an, die du für fehlerhaft hältst, dann lass auflösen.

Szenario: Wellen-Rechner aus Funktionen

Prompt eines Studierenden

Schreib mir Python-Funktionen für eine Getriebewelle: Torsionsmoment aus Leistung in kW und Drehzahl in 1/min, Torsionsspannung aus Moment in N·m und Durchmesser in mm, und eine Bewertung gegen 40 MPa mit „ok“, „kritisch“ (bis 20 % darüber) und „zu hoch“. Dann eine Ausgabe für d = 20, 25 und 30 mm bei 15 kW und 1450 1/min.

KI-Antwort (Python)

Tipp: Es sind drei Fehler eingebaut. Nicht jede Zeile ist falsch. Überschlag: Welche Spannung erwartest du bei 30 mm? Etwa 19 MPa. Was würdest du bei 1e8 MPa denken?

Würdest du das freigeben? Markiere die fehlerhaften Zeilen, dann lass auflösen.

Die drei Fehler

Fehler 1: kW statt W, es fehlt * 1000 (Zeile 5)

return P / omega teilt die Leistung in Kilowatt durch die Winkelgeschwindigkeit. Das Moment in N·m braucht aber Watt: P * 1000 / omega. Ohne den Faktor ist das Moment um den Faktor 1000 zu klein (0.1 statt 98.8 N·m). Das Programm läuft fehlerfrei: Einheitenfehler findest du nur durch Überschlag und mit dem Docstring (Einheiten hineinschreiben!).

Fehler 2: Argumente vertauscht (Zeile 21)

tau(d, T) übergibt den Durchmesser als Moment und das Moment als Durchmesser, denn die Funktion erwartet tau(T, d). Beides sind Zahlen, Python meldet nichts. Heraus kommen absurde Spannungen. Gegenmittel: Aufruf mit Namen (tau(T=T, d=d)) und den Überschlag im Kopf. Hier hängen die zwei Fehler zusammen: Weil beide Werte falsch sind, sehen die Ergebnisse noch unsinniger aus, und trotzdem läuft alles durch.

Fehler 3: Zweig ohne return (Zeilen 16 und 17)

Die Funktion bewerte kennt „ok“ und „kritisch“, aber für alles darüber (also „zu hoch“) gibt es keinen Zweig. Python erreicht das Ende der Funktion ohne return und gibt still None zurück: In der Ausgabe steht „-> None“. Lösung: ein else: mit return "zu hoch". Jeder Weg durch die Funktion braucht ein return.

Die KI-Version zum Ausprobieren

Alle drei Ausgaben sind falsch: Spannungen im Bereich von 1e8 MPa und „None“ statt eines Urteils.

import math

def torsionsmoment(P, n):
    omega = 2 * math.pi * n / 60
    return P / omega

def widerstandsmoment(d):
    return math.pi * d ** 3 / 16

def tau(T, d):
    return T * 1000 / widerstandsmoment(d)

def bewerte(tau_vorh, tau_zul=40.0):
    if tau_vorh <= tau_zul:
        return "ok"
    elif tau_vorh <= 1.2 * tau_zul:
        return "kritisch"

T = torsionsmoment(15.0, 1450)
for d in range(20, 35, 5):
    t = tau(d, T)
    print(f"d = {d} mm: tau = {t:.1f} MPa -> {bewerte(t)}")

Korrigierte Version

Mit den drei Korrekturen stimmt die Ausgabe mit dem vorgerechneten Beispiel überein.

import math

def torsionsmoment(P, n):
    omega = 2 * math.pi * n / 60
    return P * 1000 / omega

def widerstandsmoment(d):
    return math.pi * d ** 3 / 16

def tau(T, d):
    return T * 1000 / widerstandsmoment(d)

def bewerte(tau_vorh, tau_zul=40.0):
    if tau_vorh <= tau_zul:
        return "ok"
    elif tau_vorh <= 1.2 * tau_zul:
        return "kritisch"
    else:
        return "zu hoch"

T = torsionsmoment(15.0, 1450)

    t = tau(T, d)
    print(f"d = {d} mm: tau = {t:.1f} MPa -> {bewerte(t)}")
Merke

Bei KI-Funktionen prüfst du vier Dinge: Einheiten (Docstring lesen, Faktoren nachrechnen), Reihenfolge der Argumente (am besten mit Namen aufrufen), jeder Weg ein return und einzeln testen mit einem Wert, den du von Hand nachgerechnet hast. Wer nur prüft, ob das Programm läuft, übersieht alle drei Fehler.

Typische Fehlermeldungen

Fehlermeldungen sind keine Strafe, sondern ein Wegweiser. Bei Funktionen gibt es allerdings auch Fehler, die keine Meldung auslösen. Diese sechs siehst du garantiert. Jedes Beispiel lässt sich ausführen: Schau dir die echte Meldung an und lies den Traceback von unten nach oben. Die letzte Zeile nennt die Art des Fehlers.

TypeError: ein Argument fehlt

Meldung: TypeError: tau() missing 1 required positional argument: 'd'. Die Funktion verlangt zwei Argumente, beim Aufruf steht nur eins. Die Meldung nennt den fehlenden Parameter. Gib beide an, oder gib dem Parameter einen Default-Wert (d=30), wenn es einen sinnvollen Standard gibt. Zu viele Argumente melden: takes 2 positional arguments but 3 were given.

TypeError: None in der Rechnung

Meldung: TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'. NoneType ist der Typ von None. Die Funktion hat print statt return benutzt, y ist deshalb None, und mit None kann man nicht rechnen. Hinweis auf das Muster: Die Ausgabe zeigt zuerst 10 (von print), dann kommt der Fehler. Ersetze print(2 * x) durch return 2 * x.

NameError: lokale Variable von außen

Meldung: NameError: name 'ergebnis' is not defined. ergebnis ist lokal in quadrat und nach dem Aufruf weg. Nimm den Rückgabewert: e = quadrat(7), dann print(e). Dieselbe Meldung kommt, wenn du eine Funktion aufrufst, bevor sie definiert ist, oder den Funktionsnamen falsch schreibst.

SyntaxError: Doppelpunkt vergessen

Meldung: SyntaxError: expected ':' in Zeile 1. Der Kopf der Funktion endet mit einem Doppelpunkt. Ebenso bei if, else und while. Fehlt die Einrückung des Rumpfs, meldet Python einen IndentationError: expected an indented block after function definition.

Keine Ausgabe: Funktion nie aufgerufen

Das Programm läuft ohne Fehler und zeigt nichts an. Der Aufruf tau(98.8, 30) in der letzten Zeile berechnet 18.6, aber das Ergebnis wird nirgends hingeschrieben, in einem Programm (Datei) wird es verworfen. Gib den Wert mit print(tau(98.8, 30)) aus oder speichere ihn mit einer Zuweisung (t = tau(98.8, 30)), dann siehst du ihn. Der Editor merkt es sich und sagt: „keine Ausgabe – hast du print() benutzt?“

Falsches Ergebnis ohne Meldung: Argumente vertauscht

Ausgabe: 0.16 MPa. Python meldet nichts, denn 30 und 98.8 sind beide Zahlen. Gemeint war tau(98.8, 30) mit 18.6 MPa. Solche Fehler fängst du nur mit einer Gegenprobe von Hand (Überschlag!) und mit dem Aufruf per Namen: tau(T=98.8, d=30).

Masse eines Zylinders mit Default-Wert

Programmieren lernst du mit den Fingern, nicht mit den Augen. Das Training ist ein fester Teil jedes Termins und gehört zum Selbststudium. Du musst nicht alles an einem Stück machen, aber alles bis zum nächsten Termin. Die Aufgaben laufen komplett im Browser und werden automatisch geprüft.

Achtung

Phase 1: Copilot nur als Erklärer. Erlaubt: „Erkläre mir diese Fehlermeldung“, „Was macht Zeile 3?“, „Warum liefert meine Funktion None?“. Nicht erlaubt: „Schreib mir die Funktion“. Du tippst den Code selbst, denn nur dann lernst du, ihn zu prüfen. Ab V10 darf die KI Code erzeugen, und du prüfst.

Schreibe die Funktion masse_zylinder(d, l, rho=7.85). Sie bekommt Durchmesser d und Länge l in mm und die Dichte rho in kg/dm³ (Standard: Stahl mit 7.85) und gibt die Masse in kg zurück. Das Volumen in dm³ ist π · d² / 4 · l / 1 000 000.

Erwartet (Rückgabewerte)
masse_zylinder(30, 200)        ->  1.1098 (kg, Stahl)
masse_zylinder(30, 200, 2.7)   ->  0.3817 (kg, Aluminium)

Gegenprobe von Hand: d = 30 mm, l = 200 mm: V = 0.1414 dm³, mal 7.85 ergibt 1.11 kg.

  1. Der Kopf: def masse_zylinder(d, l, rho=7.85):. Der Default-Wert steht hinten (Syntax-Karte 4).
  2. Erst das Volumen in einer lokalen Variablen: volumen = math.pi * d ** 2 / 4 * l / 1e6.
  3. Dann return volumen * rho. Kein print in der Funktion.

Fehler finden: print statt return

Dieses Programm bricht mit einer Fehlermeldung ab. Die Funktion kreisflaeche soll die Kreisfläche in mm² zurückgeben, druckkraft rechnet damit die Kolbenkraft in N. Finde den Fehler und behebe ihn. Es ist genau eine Zeile.

Erwartet (nach der Reparatur)
1178.0971...

Toleranzprüfung als Funktion

Wiederholung V03 bis V04: Ein Maß liegt in Toleranz, wenn es höchstens tol vom Nennmaß abweicht. Schreibe die Funktion toleranz_ok(mass, nenn, tol), die True oder False zurückgibt (Wahrheitswert, kein Text). Nutze abs für die Abweichung und ein if oder direkt den Vergleich.

Erwartet (Rückgabewerte)
toleranz_ok(25.03, 25.0, 0.05)  ->  True
toleranz_ok(25.1, 25.0, 0.05)   ->  False
toleranz_ok(24.9, 25.0, 0.05)   ->  False

Beide Richtungen zählen: 25.03 und 24.96 sind bei Nennmaß 25 und tol 0.05 in Toleranz, 25.1 und 24.9 nicht.

Ausgabe unverändert

PAP und Funktion: zeichnen, dann umsetzen

a) PAP zeichnen: bewerte_vc

In der Klausur zeichnest du PAPs von Hand. Nimm Papier und Stift und zeichne den Plan dieses Unterprogramms. Erst danach klappst du die Musterlösung auf und vergleichst. Dein Plan muss nicht gleich aussehen, aber dieselben Pfade, Fragen und Rückgaben haben.

def bewerte_vc(vc):
    if vc < 80:
        return "zu langsam"
    elif vc > 250:
        return "zu schnell"
    else:
        return "ok"

print(bewerte_vc(60))
print(bewerte_vc(150))
print(bewerte_vc(300))
  1. Der Start trägt den Funktionsnamen mit Parameter: bewerte_vc(vc).
  2. Jedes elif ist eine neue Raute im Weg „nein“ der vorigen. Das letzte else ist der letzte Weg „nein“ ohne eigene Raute.
  3. Jedes return ist ein eigenes Ende mit der Rückgabe („Rückgabe: ...“), nicht ein gemeinsames.

b) PAP gegeben → Code. Setze diesen Plan um. Die Funktion schnittgeschwindigkeit steht schon im Editor (du hast sie in Station 6 geschrieben). Schreibe das Hauptprogramm darunter: Das Unterprogramm-Symbol ist ein Aufruf.

Ausgabe (Beispiel d = 60, n = 1000)
vc = 188.50 m/min

Eingabe d = 60, n = 1000: vc = 188.50 m/min. Eingabe d = 100, n = 1000: zu schnell.

  1. Zwei Eingaben mit float(input(...)), dann vc = schnittgeschwindigkeit(d, n): Das Rechteck mit Doppellinien ist ein Aufruf.
  2. Die Raute vc > 250? ist ein if. Bei „ja“ print("zu schnell"), bei „nein“ gibst du vc mit zwei Nachkommastellen aus.
  3. Format: print(f"vc = {vc:.2f} m/min") (V03).

Funktion ruft Funktionen: Wellenprüfung

Im Editor stehen die vier Funktionen des Vorgerechneten Beispiels. Schreibe die fünfte: wellenpruefung(P, n, d, tau_zul=40.0). Sie ruft torsionsmoment, tau und pruefe auf und gibt einen Text zurück: die Spannung mit einer Nachkommastelle, ein Doppelpunkt, das Urteil. Der Grenzwert tau_zul wird an pruefe weitergereicht.

Erwartet (Rückgabewerte)

wellenpruefung(15, 1450, 25, tau_zul=25.0)    ->  "32.2 MPa: zu hoch"

Schreibe die Spannung in eine lokale Variable, du brauchst sie zweimal (im Text und für die Prüfung).

  2. Erst t = tau(torsionsmoment(P, n), d): ein Aufruf, der das Ergebnis eines anderen als Argument nimmt.

Knobelaufgabe: Newton als Funktion

Wiederholung V06 mit Funktionen: Das Newton-Verfahren für die Quadratwurzel wird ein Baustein. Schreibe wurzel(a, tol=1e-9) mit einer while-Schleife: Starte mit x = a und wiederhole x = (x + a / x) / 2, solange abs(x * x - a) größer als tol ist. Die Funktion gibt die Wurzel zurück (nicht die Zahl der Schritte, und kein print).

Erwartet (Rückgabewerte)
wurzel(2)     ->  1.414213562373...
wurzel(9)     ->  3.0000000000...
wurzel(0.25)  ->  0.5000000000...

Das return steht nach der Schleife (nicht eingerückt): Steht es im Rumpf, endet die Funktion nach dem ersten Durchlauf.

  1. Beginne mit dem Kopf def wurzel(a, tol=1e-9): und x = a im Rumpf.
  2. Die Schleife: while abs(x * x - a) > tol:, darin x = (x + a / x) / 2.
  3. return x steht nach der Schleife auf der Ebene von while, nicht im Rumpf der Schleife.

Klausur-Modus: Wellenprüfung als Programm

So wie in der Klausur: Schreibe den Code ohne Ausführen und ohne Auto-Vervollständigung, wenn möglich zuerst auf Papier. Erst danach „Abgeben und prüfen“, dann bewertest du dich selbst.

Schreibe ein Programm für die Welle eines Motors. Es liest P in kW, n in 1/min und d in mm (Kommazahlen, in dieser Reihenfolge) ein. Das Programm besteht aus drei Funktionen und einem Hauptprogramm: eine Funktion für das Torsionsmoment in N·m, eine für die Torsionsspannung in MPa (aus Moment und Durchmesser, Moment in N·m umrechnen) und eine für das Urteil „ok“ oder „zu hoch“ mit dem Default-Wert 40.0 MPa für die zulässige Spannung.
