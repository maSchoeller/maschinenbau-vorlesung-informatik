Syntax-Karte 1

NumPy laden und ein Array erzeugen

import numpy as np

liste = [2.0, 4.0, 6.0]
a = np.array(liste)            # Liste -> Array
print(a)
print(a.shape, len(a))         # Form (3,) und Länge 3
print(liste * 2)               # Liste: wird zweimal hintereinander gehängt
print(a * 2)                   # Array: jeder Wert wird verdoppelt
  • import numpy as np steht ganz oben im Programm. np ist der übliche Kurzname. Ohne diese Zeile gibt es NameError: name 'np' is not defined.
  • np.array(liste) macht aus einer Liste ein Array: ein Zahlenfeld mit lauter Werten gleichen Typs. print zeigt es ohne Kommas: [2. 4. 6.] (der Punkt zeigt: Kommazahlen).
  • a.shape ist die Form als Tupel, bei einer Zahlenreihe (3,). len(a) liefert die Länge wie bei Listen.
  • Liste und Array verhalten sich verschieden: liste * 2 hängt die Liste an sich selbst, a * 2 verdoppelt die Werte, und liste + liste hängt aneinander, a + a addiert Paar für Paar.
Syntax-Karte 2

Zahlenreihen: np.arange und np.linspace

import numpy as np

print(np.arange(5))                  # 0 bis 4, wie range
print(np.arange(0, 1, 0.25))         # Start, Stopp (nicht dabei), Schritt
print(np.linspace(0, 1, 5))          # 5 Werte von 0 bis 1, beide Enden dabei

N = 8
fs = 100                             # Abtastrate in Hz
t = np.arange(N) / fs                # Zeitachse in s: 0, 0.01, 0.02, ...
print(t)
  • np.arange(stopp) oder np.arange(start, stopp, schritt) arbeitet wie range, liefert aber ein Array und erlaubt auch Kommazahlen als Schritt. Der Stopp gehört nicht mehr dazu.
  • np.linspace(start, ende, anzahl) liefert anzahl gleichmäßig verteilte Werte, beide Enden eingeschlossen. Praktisch, wenn du die Punktzahl vorgibst.
  • Eine Zeitachse aus Abtastrate: np.arange(N) / fs. Die Division wirkt auf jedes Element (Karte 3).
Syntax-Karte 3

Elementweise rechnen

import numpy as np

a = np.array([1.0, 2.0, 3.0])
b = np.array([10.0, 20.0, 30.0])
print(a * 2)               # jedes Element mal 2
print(a + b)               # Paar für Paar addieren
print(a ** 2)              # jedes Element quadrieren
print(np.sin(a))           # Funktion wirkt auf jedes Element
print(a / 1000)            # z. B. mm -> m

c = np.array([1.0, 2.0, 3.0, 4.0])
print(a + c)               # Fehler: Längen passen nicht
  • Rechenzeichen und NumPy-Funktionen wie np.sin, np.cos, np.sqrt wirken auf jedes Element. Du schreibst keine Schleife. Das ist die Vektorisierung.
  • Zwei Arrays werden Paar für Paar verrechnet und müssen gleich lang sein. Sonst: ValueError: operands could not be broadcast together with shapes (3,) (4,). Mit einer einzelnen Zahl geht es immer.
  • Der Winkel in np.sin ist im Bogenmaß (rad). Für f = 50 Hz: np.sin(2 * np.pi * 50 * t) mit der Konstante np.pi.
Syntax-Karte 4

Kennwerte: mean, max, min, sum, sqrt

import numpy as np

v = np.array([3.0, -4.0, 5.0])        # Schwinggeschwindigkeit in mm/s
print(np.mean(v), np.max(v), np.min(v), np.sum(v))
print(np.sqrt(np.array([4.0, 9.0])))  # Wurzel jedes Elements

quadrate = v ** 2
print(np.mean(quadrate))
print(np.sqrt(np.mean(v ** 2)))       # Effektivwert: Wurzel aus dem Mittelwert der Quadrate
print(np.sqrt(np.mean(v) ** 2))       # FALSCH: erst mitteln, dann quadrieren
  • np.mean (Mittelwert), np.max, np.min und np.sum fassen ein ganzes Array zu einer Zahl zusammen. Vorher mussten es sum(liste) / len(liste) und max(liste) tun.
  • Effektivwert (RMS): erst jedes Element quadrieren, dann mitteln, dann die Wurzel: np.sqrt(np.mean(v ** 2)). Die Reihenfolge ist entscheidend. Bei Schwingungen mit wechselndem Vorzeichen ist np.mean(v) fast null.
  • Rechne einen Wert immer von Hand gegen: für 3, −4, 5 sind die Quadrate 9, 16, 25, der Mittelwert 50/3 ≈ 16,67, die Wurzel ≈ 4,08.
Syntax-Karte 5

Masken: Werte nach Bedingung auswählen

import numpy as np

a = np.array([1, 5, 2, 8, 3])
print(a > 2)                         # Wahr/Falsch je Element: die Maske
print(a[a > 2])                      # nur die Werte, bei denen die Maske wahr ist
print(len(a[a > 2]))                 # wie viele
print(len(a[a > 2]) / len(a))        # Anteil von 0 bis 1
print(np.mean(a > 2))                # Kurzform: Mittelwert von Wahr(1)/Falsch(0)

grenze = 4
auswahl = a[(a > 1) & (a < grenze)]  # zwei Bedingungen: & statt and, Klammern setzen
print(auswahl)
  • Ein Vergleich wie a > 2 wirkt auf alle Elemente und ergibt ein Wahr/Falsch-Array (die Maske). a[maske] behält die Elemente, bei denen sie wahr ist, in ihrer Reihenfolge.
  • Das ersetzt die Schleife mit if und append aus V10: len(a[a > 2]) zählt, len(...) / len(a) gibt den Anteil. np.mean(a > 2) ist dieselbe Zahl als Kurzform (wahr zählt als 1, falsch als 0).
  • Zwei Bedingungen verbindest du mit & (und) bzw. | (oder), jede in Klammern. Das Wort and funktioniert hier nicht.
Syntax-Karte 6

Messdaten laden: np.loadtxt

import numpy as np

tabelle = np.loadtxt("waschmaschine.csv", delimiter=",", skiprows=1)
print(tabelle.shape)                          # (Zeilen, Spalten)
spalte = tabelle[:, 4]                        # alle Zeilen, Spalte mit Index 4
print(len(spalte), spalte[:3])

a = np.loadtxt("waschmaschine.csv", delimiter=",", skiprows=1, usecols=4)
print(a.shape, np.max(a))                     # nur diese Spalte als einfaches Array
  • np.loadtxt(datei, delimiter=",", skiprows=1) liest eine Textdatei mit Zahlen direkt als Array: delimiter ist das Trennzeichen, skiprows=1 überspringt die Kopfzeile. Ein Dezimalkomma und ein Semikolon als Trenner müsstest du erst umbauen (V09). Die phyphox-Datei aus V09 hat Punkte und Kommas als Trenner und passt.
  • Das Ergebnis ist eine Tabelle (zweidimensionales Array). tabelle[:, 4] heißt „alle Zeilen, Spalte 4“ (gezählt ab 0). Mit usecols=4 bekommst du gleich nur diese Spalte.
  • Bei einer Datenzeile liefert loadtxt kein Array mit Länge, sondern eine einzelne Zahl. Prüfe .shape, wenn du Fehlermeldungen wie „len() of unsized object“ siehst.
Syntax-Karte 7

Zeit messen: perf_counter, mehrfach, Minimum

import time
import numpy as np

def messe(f):
    start = time.perf_counter()
    f()                                       # nur das Gemessene zwischen Start und Ende
    return time.perf_counter() - start

def schleife():
    summe = 0
    for i in range(200_000):
        summe = summe + i * i

def vektor():
    a = np.arange(200_000.0)                  # .0: Kommazahlen, sonst läuft a * a über (siehe unten)
    np.sum(a * a)

zeiten_s = [messe(schleife) for versuch in range(5)]
zeiten_v = [messe(vektor) for versuch in range(5)]
print(f"Schleife: Minimum {min(zeiten_s) * 1000:.2f} ms, Median {np.median(zeiten_s) * 1000:.2f} ms")
print(f"Vektor:   Minimum {min(zeiten_v) * 1000:.2f} ms, Median {np.median(zeiten_v) * 1000:.2f} ms")
  • messe(schleife) übergibt die Funktion selbst, ohne Klammern: Eine Funktion ist auch ein Wert, den man weiterreichen kann. Erst f() mit Klammern ruft sie in messe auf.
  • time.perf_counter() liefert Sekunden. Erst die Differenz aus zwei Aufrufen (nach minus vor) ist die Dauer. Reihenfolge ende - start, nicht umgekehrt.
  • Mehrfach messen und min(zeiten) oder np.median(zeiten) berichten, nicht den Mittelwert und nicht eine einzelne Messung.
  • np.arange(200_000.0) mit .0 liefert Kommazahlen. Mit ganzen Zahlen rechnet NumPy im Browser mit 32 Bit, und a * a würde ab etwa 46 341 still überlaufen, ohne Fehlermeldung (wie der Encoder-Zähler aus V02). Prüfe große Summen darum gegen einen Überschlag.
  • Zwischen Start und Ende steht nur die Rechnung: kein print, kein Laden einer Datei. Die Werte hängen von Rechner und Browser ab, schreibe nie „NumPy ist immer genau n-mal schneller“.

Vorgerechnetes Beispiel: Effektivwert, Schleife gegen NumPy

Aufgabe: Eine Schwingung mit 50 Hz und 2 mm/s Amplitude wurde 10 Sekunden lang mit 100 kHz abgetastet, das sind 1 Million Messpunkte. Das Programm berechnet den Effektivwert zweimal: mit einer Schleife über eine Liste und mit einer NumPy-Rechnung auf dem ganzen Array. Es misst dabei jeweils die Zeit und vergleicht mit der Theorie A/√2. Lies den Code Zeile für Zeile, dann führe ihn aus. Das dauert ein paar Sekunden (und beim ersten Mal kommt das Laden von NumPy dazu). Welche Zeiten bei dir herauskommen, weißt du vorher nicht: Sie hängen von Rechner und Browser ab. Der Effektivwert muss aber bei beiden Wegen 1.4142 sein.

Links die Schleifen-Variante als Programmablaufplan (Zählschleife über alle Messpunkte, Summe der Quadrate), rechts die NumPy-Variante ohne Schleife im Plan. Das Rechteck „v = A * np.sin(…)“ steht für eine Million Rechnungen.

  1. Zeilen 4 bis 6: Drei Module werden geladen: math für sin und sqrt der Schleife, time für die Stoppuhr und numpy unter dem Kurznamen np. Beim ersten Lauf lädt der Browser NumPy nach.
  2. Zeilen 8 bis 10: Die Daten der Messung. N = 1_000_000 sind eine Million Punkte (die Unterstriche sind nur Lesehilfe). Bei 100 kHz Abtastrate sind das 10 s. f ist die Frequenz in Hz, A die Amplitude in mm/s.
  3. Zeilen 13 bis 22: Variante 1 mit Schleife. Zeile 13 liest die Stoppuhr (start). Die erste Schleife (Zeilen 15 bis 17) berechnet für jeden der N Punkte die Zeit t in s und den Messwert A * sin(2 π f t) und hängt ihn an die Liste werte. Die zweite Schleife (Zeilen 19 und 20) summiert die Quadrate. Zeile 21: Wurzel aus dem Mittelwert der Quadrate, das ist der Effektivwert. Zeile 22 liest die Stoppuhr erneut: nachher minus vorher ist die Dauer.
  4. Zeilen 25 bis 29: Variante 2 mit NumPy. Zeile 26: np.arange(N) / 100_000 erzeugt die ganze Zeitachse als Array (eine Million Werte) in einem Befehl. Zeile 27 berechnet alle Messwerte auf einmal: np.sin wirkt auf jedes Element, das Rechenzeichen * ebenso. Zeile 28 ist der Effektivwert in einer Zeile: v ** 2 quadriert jedes Element, np.mean mittelt, np.sqrt zieht die Wurzel. Zeile 29: Stoppuhr.
  5. Zeilen 31 bis 34: Die Ausgabe. Beide Effektivwerte müssen 1.4142 sein, die Theorie liefert A/√2 = 2/1,4142 = 1,4142 (für eine Sinusschwingung über ganze Perioden). Die Zeilen mit den Zeiten sind bei jedem Lauf anders. Die letzte Zeile teilt die beiden Zeiten: Der Faktor hängt von Rechner und Browser ab und ist nur ein Messwert, keine Naturkonstante.
  6. Selbsterklärung: Führe das Programm dreimal aus und schreib die beiden Zeiten auf. Wie stark schwanken sie, und welche Zeit würdest du berichten (Minimum oder Median)? Ändere dann N auf 100 000 und auf 10 Millionen (Achtung, dauert länger) und prüfe: Wächst die Schleifenzeit etwa linear mit N? Und was ändert sich beim Faktor?

Effektivwert als Funktion

Die Funktion bekommt eine Liste von Messwerten und gibt den Effektivwert zurück: erst ein Array bauen, dann elementweise quadrieren, dann mitteln und die Wurzel ziehen. Überlege: Was muss zuerst passieren, und in welcher Reihenfolge stehen Mittelwert und Wurzel?

Eine Laufzeit messen

Das Programm misst, wie lange eine Schleife für 100 000 Durchläufe braucht, und gibt die Dauer in Sekunden aus. Achte darauf, dass die Stoppuhr vor der Schleife gestartet und nach der Schleife abgelesen wird, und auf die Reihenfolge bei der Differenz.

Lücken füllen

Jetzt tippst du Teile selbst. Ergänze die fünf Lücken, sodass das Programm Messwerte einliest (durch Leerzeichen getrennt, in mm/s), ein Array daraus baut und den Effektivwert, den größten Wert und die Zahl der Werte über 2 mm/s ausgibt. import numpy as np

eingabe = input("Messwerte in mm/s: ")
a = np.@@array@@([float(x) for x in eingabe.split()])
rms = np.@@sqrt@@(np.@@mean@@(a ** 2))
print(f"Effektivwert: {rms:.3f} mm/s")
print(f"Größter Wert: {np.@@max@@(a)} mm/s")
print(f"Werte über 2 mm/s: {@@len@@(a[a > 2])}")

  2. Lücke 2 und 3: Der Effektivwert ist die Wurzel aus dem Mittelwert der Quadrate. Von außen nach innen: erst die Wurzel, dann der Mittelwert (Karte 4).
  3. Lücke 4: Welche Funktion liefert den größten Wert eines Arrays (Karte 4)?
  4. Lücke 5: Die Maske a > 2 wählt die Werte aus, gesucht ist deren Anzahl. Welche Funktion zählt Elemente (Karte 5)?

Code-Review: KI-Antworten prüfen

Die KI erzeugt, du prüfst. Zwei Szenarien. Erst ein NumPy-Programm mit drei typischen Fehlern, dann eine Text-Antwort zu Laufzeit und NumPy mit vier falschen Aussagen. Klick die Zeilen an, die du für fehlerhaft hältst, dann lass auflösen.

Szenario 1: Schwingungsmessung auswerten

Prompt eines Studierenden

Schreib mir ein kleines Python-Programm mit NumPy für die Schwingungsmessung [1.2, -0.8, 2.0, -1.5, 0.9, -1.1, 1.7, -2.0] in mm/s: (1) den Effektivwert berechnen, (2) die dafür nötige Zeit messen, (3) alle Werte in µm/s umrechnen (1 mm = 1000 µm).

KI-Antwort (Python)

Tipp: Es sind drei Fehler eingebaut, einer je Teilaufgabe. Nicht jede Zeile ist falsch. Zeile 4 allein ist kein Fehler, aber sie hat Folgen.

Würdest du das freigeben? Markiere die fehlerhaften Zeilen, dann lass auflösen.

Die drei Fehler

Fehler 1: erst mitteln, dann quadrieren (Zeile 7)

np.sqrt(np.mean(messung) ** 2) bildet zuerst den Mittelwert (0,05 mm/s) und quadriert ihn danach. Das Ergebnis ist der Betrag des Mittelwerts, also fast null, nicht der Effektivwert. Gefragt war die Wurzel aus dem Mittelwert der Quadrate: np.sqrt(np.mean(messung ** 2)) ergibt 1,468 mm/s. Das Programm läuft ohne Fehlermeldung. Gegenprobe von Hand: Quadrate 1,44 + 0,64 + 4 + 2,25 + 0,81 + 1,21 + 2,89 + 4 = 17,24, geteilt durch 8 ist 2,155, die Wurzel 1,468. Dazu kommt ein Folgefehler: messung ** 2 funktioniert nur mit einem Array. Mit der Liste aus Zeile 4 gäbe es einen TypeError.

Fehler 2: Zeitmessung nur einmal, mit Ausgabe im gemessenen Bereich (Zeile 8)

Zwischen start und dauer steht ein print. Die Ausgabe dauert oft länger als die Rechnung selbst, die „Dauer“ misst also vor allem das Drucken. Dazu wurde nur einmal gemessen: Bei so einer kurzen Rechnung (Mikrosekunden) schwankt das stark. Besser: nur die Rechnung zwischen die beiden Zeitstempel, mehrfach wiederholen, das Minimum berichten, ausgeben erst danach.

Fehler 3: Liste statt Array, die Umrechnung vervielfacht die Liste (Zeile 12)

messung ist eine Liste (Zeile 4). messung * 1000 hängt die Liste tausendmal hintereinander: 8000 Werte statt 8, und keine einzige Zahl ist umgerechnet. Die Ausgabe in Zeile 13 verrät es („8000 Werte“), wenn man hinsieht. Lösung: messung = np.array([...]) in Zeile 4, dann wirkt * 1000 elementweise und die Länge bleibt 8.

Die KI-Version zum Ausprobieren

Die Ausgaben sind falsch: Effektivwert 0.05 statt 1.468, eine Dauer, die vor allem das print misst, und 8000 statt 8 Werte.

import time
import numpy as np

messung = [1.2, -0.8, 2.0, -1.5, 0.9, -1.1, 1.7, -2.0]      # mm/s

start = time.perf_counter()
rms = np.sqrt(np.mean(messung) ** 2)
print("Effektivwert:", round(rms, 3), "mm/s")
dauer = time.perf_counter() - start
print("Dauer:", dauer, "s")

in_um = messung * 1000
print(len(in_um), "Werte in µm/s")

Korrigierte Version

import time
import numpy as np

messung = np.array([1.2, -0.8, 2.0, -1.5, 0.9, -1.1, 1.7, -2.0])      # mm/s

zeiten = []
for versuch in range(7):
    start = time.perf_counter()
    rms = np.sqrt(np.mean(messung ** 2))
    zeiten.append(time.perf_counter() - start)
print("Effektivwert:", round(rms, 3), "mm/s")
print("Beste Zeit:", min(zeiten), "s")

in_um = messung * 1000
print(len(in_um), "Werte in µm/s")
Merke

Bei NumPy-Code fragst du: „Liste oder Array? Stimmt die Reihenfolge von Quadrat, Mittelwert und Wurzel? Wurde die Länge geprüft?“ Beim Zeitmessen: „Steht nur die Rechnung zwischen den Zeitstempeln, und wurde mehrfach gemessen?“ Rechne einen Wert von Hand nach, und prüfe len und .shape. Deine Testfälle schreibst du vorher von Hand auf, die KI liefert den Fall aus ihrem Beispiel, nicht den aus deiner Anlage.

Szenario 2: Schleife oder NumPy? (reine Text-Antwort)

Prompt eines Studierenden

Ich muss 5 Millionen Messwerte auswerten und die Reihe verdoppeln. Soll ich eine Schleife oder NumPy nehmen, und wie viel schneller ist NumPy genau?

KI-Antwort (Text, einige Aussagen sind im Szenario falsch)

Tipp: Es sind vier Fehler eingebaut. Nicht jede Zeile ist falsch. Die Sprache klingt überall gleich sicher.

Würdest du das freigeben? Markiere die fehlerhaften Zeilen, dann lass auflösen.

Die vier Fehler

Fehler 1: eine feste Zahl für etwas, das man messen muss (Zeile 2)

Der Faktor hängt von Rechner, Browser, Datenmenge und Rechnung ab. Er kann 5, 20 oder 200 sein. „Immer genau 100“ hat die Form einer Tatsache, ist aber erfunden: ein Sprachmodell erzeugt wahrscheinlich klingende Zahlen. Richtig: „oft deutlich schneller, in der Größenordnung von zehn bis hundert, miss selbst“.

Fehler 2: kleine Arrays (Zeile 3)

Bei 10 Elementen ist die Schleife genauso schnell, oft schneller, denn schon der NumPy-Aufruf kostet etwas. Der Vorteil wächst mit der Datenmenge und ist bei Millionen von Werten groß.

Fehler 3: Liste statt Array (Zeile 4)

liste * 2 hängt die Liste zweimal hintereinander (10 Millionen Elemente statt 5 Millionen verdoppelter Werte) und gibt keine Fehlermeldung. Gemeint war np.array(liste) * 2.

Fehler 4: eine einzelne Messung genügt nicht (Zeile 5)

Messungen schwanken (andere Programme, Takt, Zwischenspeicher). Ein einzelner Wert kann ein Ausreißer sein. Mehrfach messen und Minimum oder Median berichten. Die Zeilen 1 und 6 sind in Ordnung: Das Prinzip ist richtig beschrieben, und das Gegenprüfen der Ergebnisse ist guter Stil.

Merke

Vier Prüffragen an KI-Aussagen zur Laufzeit: Steht da eine feste Zahl, die nur Messung liefern kann? Gilt die Aussage für kleine und große Datenmengen? Verwechselt sie Liste und Array? Wurde mehrfach gemessen? Die KI ist ein schneller Entwurf, die Messung machst du.

Typische Fehlermeldungen

Fehlermeldungen sind keine Strafe, sondern ein Wegweiser. Bei NumPy gibt es allerdings auch Fehler, die keine Meldung auslösen. Diese fünf siehst du garantiert. Jedes Beispiel lässt sich ausführen: Schau dir die echte Meldung an und lies sie von unten nach oben (zuerst die letzte Zeile).

NameError: np nicht importiert

Meldung: NameError: name 'np' is not defined. Python kennt den Namen np nicht, weil die Zeile import numpy as np fehlt. Sie steht immer ganz oben im Programm. Füge sie ein und führe erneut aus.

ValueError: Arrays verschieden lang

Meldung: ValueError: operands could not be broadcast together with shapes (3,) (4,). Elementweise Rechnung braucht Arrays gleicher Länge: drei Werte hier, vier dort. Die Meldung nennt die beiden Formen in Klammern. Prüfe mit len(a) und len(b), woher die Längen kommen (falscher Bereich, eine Zeile zu viel in der Datei).

TypeError: Liste mal Kommazahl

Meldung: TypeError: can't multiply sequence by non-int of type 'float'. Mit einer ganzen Zahl wüsste Python, was liste * 3 bedeutet (dreimal hintereinander), mit einer Kommazahl nicht. Wandle erst in ein Array um: np.array(messung_mm) * 0.001.

TypeError: Liste hoch 2

Meldung: TypeError: unsupported operand type(s) for ** or pow(): 'list' and 'int'. Eine Liste kann man nicht hochnehmen, ein Array schon. Die Meldung nennt die beteiligten Typen: 'list' und 'int'. Lösung: np.array(werte) ** 2 oder eine List Comprehension [w ** 2 for w in werte] (V10).

Falsches Ergebnis ohne Meldung: Liste verdoppelt sich

Ausgabe: [1.0, 2.0, 3.0, 1.0, 2.0, 3.0] zweimal und die Länge 6. Python meldet nichts, denn bei Listen bedeuten * und + „wiederholen“ und „aneinanderhängen“. Solche Fehler fängst du nur mit einer Gegenprobe: Stimmt die Länge (len), stimmt ein Wert von Hand?

Wiederholung: Schleife und NumPy im Vergleich

Eine Messreihe Bohrungsdurchmesser (Sollmaß 12,000 mm, Toleranz ±0,015 mm, also gut von 11,985 bis 12,015) wird ausgewertet, wie in V08, und jetzt zweimal: pruefe_schleife(werte) arbeitet mit einer Liste, for und sum, len, max, min. pruefe_numpy(werte) macht dasselbe mit NumPy ohne Schleife. Beide geben ein Tupel (mittelwert, spannweite, anzahl_ausserhalb) zurück: Mittelwert, Spannweite (größter minus kleinster Wert) und die Zahl der Werte außerhalb der Toleranz (kleiner als 11,985 oder größer als 12,015).

Beispiel (Rückgabewert, beide Funktionen):
pruefe_schleife([12.004, 11.998, 12.019, 12.011, 11.980])

  1. Schleife: Mittelwert sum(werte) / len(werte), Spannweite max(werte) - min(werte), und ein Zähler, den die Schleife bei jedem Wert außerhalb um 1 erhöht (V06, V08).

  3. Anzahl außerhalb als Maske: a[(a < 11.985) | (a > 12.015)] mit | (oder) und Klammern um jede Bedingung (Karte 5). Die Anzahl ist len(...) davon. Rückgabe als Tupel: return (x, y, z).

PAP zeichnen: Effektivwert mit Schleife

Effektivwert von n Messwerten (Schleifen-Variante)

Zeichne den Programmablaufplan der Schleifen-Variante aus dem Hook: Der Plan liest erst die Anzahl n (ganze Zahl) ein, setzt die Summe auf 0 und liest dann in einer Zählschleife n Messwerte nacheinander ein (Kommazahlen). In jedem Durchlauf kommt das Quadrat des Messwerts zur Summe. Nach der Schleife gibt der Plan den Effektivwert (summe / n) ** 0.5 aus.

Beispiele (Eingaben nacheinander):
n = 3, Werte 3, 4, 5   ->  4.0825 (Wurzel aus 50/3)
n = 2, Werte -3, 3     ->  3.0

Tipp: Die Zählschleife ist eine Raute mit Rückführung. Im Rumpf stehen die Eingabe eines Messwerts und eine Operation. Die Wurzel ziehst du als Potenz ** 0.5, dann brauchst du kein import.

  1. Reihenfolge der Symbole: Eingabe n, Operation summe = 0, die Zählschleife, danach die Ausgabe.
  2. Die Zählschleife ist das Symbol „Zählschleife“ mit dem Text i in range(n). Im Rumpf: Eingabe x (Typ Kommazahl) und die Operation summe = summe + x * x.
  3. Die Ausgabe steht nach der Schleife und enthält (summe / n) ** 0.5. Die Wurzel gehört nicht in die Schleife.

Zeit messen: die beste Zeit

Schreibe die Funktion beste_zeit(f, wiederholungen). Sie bekommt eine Funktion f (ohne Parameter, du rufst sie mit f() auf) und eine Zahl wiederholungen. Sie ruft f() genau so oft auf, misst jeden Aufruf einzeln mit time.perf_counter() und gibt die kleinste gemessene Dauer in Sekunden zurück. Zwischen den beiden Zeitstempeln steht nur der Aufruf f().

Beispiel:
def arbeit():
    return sum(range(100000))

beste_zeit(arbeit, 5)   ->  die kleinste von fünf Messungen, z. B. 0.0021 (s)

Wichtig für die Prüfung: Schreibe import time und rufe time.perf_counter() auf (nicht from time import perf_counter). Pro Wiederholung genau zwei Aufrufe: einen vor, einen nach f().

  1. Leere Liste zeiten = [], dann eine Schleife for versuch in range(wiederholungen):.
  2. In der Schleife: start = time.perf_counter(), dann f(), dann time.perf_counter() - start an die Liste anhängen. Nach minus vor, nicht umgekehrt.
  3. Nach der Schleife das Minimum zurückgeben: return min(zeiten).

Kollisionsprüfung: Schritte zählen und überschlagen

Auf einem Lochblech liegen Bohrungen als Punkte (x, y) in mm. Schreibe drei Funktionen. (a) zu_dicht(bohrungen, mindestabstand) bekommt eine Liste von Punkten und gibt die Zahl der Paare zurück, deren Abstand kleiner als mindestabstand ist. Jedes Paar zählt einmal: die innere Schleife beginnt bei i + 1. Der Abstand zweier Punkte ist ((x1 - x2) ** 2 + (y1 - y2) ** 2) ** 0.5. (b) anzahl_paare(n) liefert die Zahl der Paare bei n Bohrungen mit der Formel n·(n−1)/2 (als ganze Zahl, //). (c) schaetze_sekunden(n, ns_je_paar) überschlägt die Dauer in Sekunden, wenn ein Paarvergleich ns_je_paar Nanosekunden braucht (1 ns = 10−9 s).

Beispiele (Rückgabewerte):
zu_dicht([(0, 0), (3, 0), (3, 4), (10, 10)], 4.5)   ->  2    (Abstände 3 und 4)
anzahl_paare(1000)                                  ->  499500
schaetze_sekunden(100000, 100)                      ->  499.995   (rund 8 Minuten)

Die Gegenfrage danach: Wie lange würde (a) für 100 000 Bohrungen dauern, wenn ein Vergleich in Python 100 ns braucht? Und warum nützt dir ein hundertfach schnellerer Rechner kaum, wenn die Bohrungen zehnmal mehr werden?

  1. zu_dicht: zwei geschachtelte Schleifen for i in range(n) und for j in range(i + 1, n) (Syntax-Karte in V06, hier wie im Beispiel der Lerneinheit). Die Punkte holst du mit x1, y1 = bohrungen[i] (Tupel entpacken, V08).
  2. Der Abstand ist ((x1 - x2) ** 2 + (y1 - y2) ** 2) ** 0.5. Gezählt wird bei abstand < mindestabstand (kleiner als, nicht kleiner gleich). Der Zähler startet bei 0, nach den Schleifen return anzahl.
  3. anzahl_paare: n * (n - 1) // 2. schaetze_sekunden: Paare mal ns_je_paar mal 1e-9 (das ist 10−9 in Python). Du darfst anzahl_paare darin aufrufen.
