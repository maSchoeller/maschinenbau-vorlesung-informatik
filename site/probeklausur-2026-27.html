A1 · Zahlensysteme und Datentypen

10 Punkte

a) Wandeln Sie die Binärzahl 1011 01102 in eine Dezimalzahl und in eine Hexadezimalzahl um. Geben Sie den Rechenweg an. (3 P.)

Musterlösung und Punkte

Stellenwerte: 1·128 + 0·64 + 1·32 + 1·16 + 0·8 + 1·4 + 1·2 + 0·1 (1 P.) = 182 (1 P.). Hexadezimal: 4er-Gruppen 1011 = B, 0110 = 6, also B616 (1 P.).

b) Ein Drehgeber liefert Werte als 8-Bit-Zahl mit Vorzeichen (Zweierkomplement). Stellen Sie −100 als 8-Bit-Zweierkomplement dar. Geben Sie den Rechenweg an. (3 P.)

Musterlösung und Punkte

100 = 0110 01002 (1 P.). Alle Bits invertieren: 1001 1011 (1 P.). Plus 1: 1001 11002 (1 P.).

c) Python gibt für 0.1 + 0.2 == 0.3 den Wert False aus. Erklären Sie die Ursache und geben Sie an, wie man zwei Kommazahlen in Python richtig vergleicht. (2 P.)

Musterlösung und Punkte

0,1 und 0,2 sind im Binärsystem periodisch und werden als float nur gerundet gespeichert; die Rundungsfehler addieren sich (0.30000000000000004) (1 P.). Vergleich mit Toleranz: math.isclose(a, b) oder abs(a - b) < 1e-9 (1 P.).

d) Ein Stückzähler speichert den Wert in einem Byte ohne Vorzeichen (0 bis 255). Er steht auf 250, dann kommen 10 Teile hinzu. Welcher Wert steht danach im Zähler, und wie heißt der Effekt? (2 P.)

Musterlösung und Punkte

260 passt nicht in ein Byte; es bleibt 260 − 256 = 4 (1 P.). Effekt: Überlauf (Overflow) (1 P.).

A3 · Netzwerk, Sicherheit und Datenbanken

9 Punkte

Die Fertigungszelle FZ-3 hängt im Netz 192.168.30.0/24.

a) Wie viele Geräte-Adressen sind in diesem Netz nutzbar? Gehören die Adressen 192.168.30.12 (Drehmaschine D2) und 192.168.31.20 (Roboter R1) zum Netz? Begründen Sie kurz. (3 P.)

Musterlösung und Punkte

/24: 24 Bit Netzanteil, 8 Bit für Geräte, also 256 Adressen, minus Netzadresse (.0) und Broadcast (.255), also 254 nutzbar (1 P.). 192.168.30.12: ja, die ersten drei Blöcke 192.168.30 stimmen überein (1 P.). 192.168.31.20: nein, dritter Block 31 ≠ 30, also ein anderes Netz; R1 ist falsch konfiguriert (1 P.).

b) Vor dem Einspielen einer Firmware berechnet ein Techniker die SHA-256-Prüfsumme der Datei und vergleicht sie mit dem Wert des Herstellers. Was zeigt eine übereinstimmende Prüfsumme? Warum hilft der Vergleich nichts, wenn Datei und Prüfsumme vom selben, manipulierten USB-Stick stammen? (3 P.)

Musterlösung und Punkte

Gleiche Prüfsumme: Die Datei ist Bit für Bit identisch mit der Datei, aus der der Hersteller die Prüfsumme berechnet hat – nicht beschädigt, nicht verändert; schon ein geändertes Bit ergibt eine völlig andere Prüfsumme (2 P.). Kommen beide vom selben manipulierten Stick, kann der Angreifer die Prüfsumme passend zur manipulierten Datei neu berechnet haben; die Soll-Prüfsumme muss aus einer vertrauenswürdigen Quelle stammen (Herstellerseite über HTTPS, digitale Signatur) (1 P.).

c) Die Tabelle auftraege hat die Spalten nr, teil, maschine, menge, status. Schreiben Sie eine SQL-Abfrage, die nr und menge aller Aufträge der Maschine D2 mit Status offen liefert (2 P.). Warum setzt man in Python die Werte mit Platzhaltern ? ein statt mit einem f-String? (1 P.)

Musterlösung und Punkte

SELECT nr, menge FROM auftraege WHERE maschine = 'D2' AND status = 'offen';

SELECT/FROM (1 P.), WHERE mit AND (1 P.). Platzhalter: Die Eingabe wird nur als Wert behandelt, nie als SQL-Befehl; das schützt vor SQL-Injection (z. B. Eingabe x' OR '1'='1) (1 P.).

A4 · KI, Testen und Laufzeit

8 Punkte

a) Beschreiben Sie in zwei bis drei Sätzen, wie ein Sprachmodell (LLM) einen Antworttext erzeugt, und erklären Sie damit, warum es „selbstbewusst falsch“ liegen kann (Halluzination). (3 P.)

Musterlösung und Punkte

Das Modell wurde mit sehr vielen Texten trainiert und sagt Token für Token (Wortteil für Wortteil) das wahrscheinlich nächste Token voraus (1 P.), hängt es an und wiederholt das (1 P.). Es prüft dabei keine Fakten, sondern erzeugt plausible, flüssige Sprache; darum klingt auch eine falsche Antwort überzeugend (Halluzination) (1 P.).

b) Spezifikation: Eine Welle ist „gut“, wenn für den Durchmesser d gilt 19,98 mm ≤ d ≤ 20,02 mm. Nennen Sie vier sinnvolle Testfälle (Eingabe und erwartetes Ergebnis) und begründen Sie Ihre Auswahl in einem Satz. (3 P.)

Musterlösung und Punkte

Zum Beispiel: 19,98 → gut, 20,02 → gut (die Grenzen selbst), 19,97 → nicht gut, 20,03 → nicht gut (knapp außerhalb); zusätzlich sinnvoll: 20,00 → gut. Je zwei richtige Testfälle (1 P., höchstens 2 P.). Begründung: Fehler passieren meist an den Grenzen (< statt <=), deshalb jede Grenze von beiden Seiten testen (1 P.).

c) Eine Python-Schleife über 1 Million Messwerte braucht 0,4 s, dieselbe Rechnung mit NumPy (np.mean(werte ** 2)) etwa 0,005 s. Nennen Sie zwei Gründe für den Unterschied. (2 P.)

Musterlösung und Punkte

NumPy rechnet die ganze Operation in vorkompiliertem C-Code auf einem zusammenhängenden Speicherblock gleichartiger Zahlen (1 P.); die Python-Schleife interpretiert jede Anweisung einzeln und prüft für jeden Wert erneut den Datentyp (Overhead je Element) (1 P.).

abweichungen = 0

B4 · Code-Review: Fehler finden und korrigieren

10 Punkte

Beide Funktionen hat eine KI erzeugt. Sie laufen ohne Fehlermeldung, liefern aber falsche Ergebnisse. Benennen Sie den Fehler, erklären Sie, warum das Ergebnis falsch ist, und geben Sie die Korrektur an.

a) Die Funktion soll den Mittelwert aller gültigen Zahlen einer Textdatei liefern (eine Zahl pro Zeile); Zeilen, die keine Zahl enthalten, sollen übersprungen werden. (5 P.)

def mittelwert(dateiname):
    summe = 0
    anzahl = 0
    with open(dateiname, encoding="utf-8") as datei:
        for zeile in datei:
            try:
                summe = summe + float(zeile.strip())
            except ValueError:
                print("Zeile übersprungen:", zeile.strip())
            anzahl = anzahl + 1
    return summe / anzahl

Geben Sie zusätzlich an, welchen Wert die Funktion für eine Datei mit den Zeilen 20.0, 22.0, FEHLER, 24.0 liefert und welcher richtig wäre.

Musterlösung und Punkte

anzahl = anzahl + 1 steht nach dem try/except und zählt auch übersprungene Zeilen (2 P.). Korrektur: die Zeile in den try-Block direkt nach summe = … verschieben (2 P.). Beispiel: geliefert wird 66/4 = 16.5, richtig wäre 66/3 = 22.0 (1 P.).

def mittelwert(dateiname):
    summe = 0
    anzahl = 0
    with open(dateiname, encoding="utf-8") as datei:
        for zeile in datei:
            try:
                summe = summe + float(zeile.strip())
                anzahl = anzahl + 1
            except ValueError:
                print("Zeile übersprungen:", zeile.strip())
    return summe / anzahl

# Kontrolle
with open("temperaturen.txt", "w", encoding="utf-8") as f:
    f.write("20.0\n22.0\nFEHLER\n24.0\n")
print(mittelwert("temperaturen.txt"))

b) Die Funktion soll das Torsionsmoment T = P / ω mit ω = 2π·n/60 berechnen. P wird in kW übergeben, n in 1/min, T soll in N·m herauskommen. (5 P.)

import math

def torsionsmoment(P, n):
    """P in kW, n in 1/min, Ergebnis T in N·m"""
    return P / (2 * math.pi * n / 60)

Schreiben Sie außerdem einen Testfall mit assert für P = 15 kW und n = 1450 1/min; das richtige Ergebnis ist etwa 98,8 N·m.

Musterlösung und Punkte

Einheitenfehler: kW wurde nicht in W umgerechnet, das Ergebnis ist um den Faktor 1000 zu klein (15 kW, 1450 1/min ergibt 0.0988 statt 98.8 N·m) (2 P.). Korrektur: return P * 1000 / (2 * math.pi * n / 60) (1 P.). Testfall: assert abs(torsionsmoment(15, 1450) - 98.8) < 0.1 (2 P.: assert 1 P., Vergleich mit Toleranz statt == 1 P.).

import math

def torsionsmoment(P, n):
    """P in kW, n in 1/min, Ergebnis T in N·m"""
    return P * 1000 / (2 * math.pi * n / 60)

# Kontrolle
assert abs(torsionsmoment(15, 1450) - 98.8) < 0.1
print(torsionsmoment(15, 1450))
